# 逐題統計（答對率、鑑別度、選項分析）抽取報告

由 `python3 tools/extract_item_stats.py` 產生，請勿手改；資料在 `data/exams/item-stats.json`。
來源是大考中心「各科答對率及鑑別度表」與「各科選擇題選項分析」（manifest 的 `pd_table`、`option_analysis`），學測 91–115、指考 91–110 英文科，共 45 個考試年度。

## 摘要

- 抽出 2420 題，2420 題對上題本 JSON（100%）；2420 題有選項分析，2420 題有五等分組 Pa–Pe，多選題 5 題。
- 與題本 JSON 不一致：0 筆（0 題）；原表內部不一致：68 筆；缺口 118 筆。
- 官方評論對照：11/11 通過。
- 高分組／低分組是**前 33%／後 33%**，不是常見說法的 27%：45 個年度中有 45 個年度的註腳寫明 33%，寫 27% 的有 0 個。Pa–Pe 是依總分分成各占 20% 的五組。

## 欄位定義

數值一律是 0–1 的小數（原表整數百分比 ÷ 100），原表空白為 `null`。

| 欄位 | 意義 | 說明 |
|---|---|---|
| `P` | 全體到考考生答對率 | 多選題（題號前有「*」）為得分率 |
| `Ph` | 高分組答對率 | 依總分排序的前 33% 考生 |
| `Pl` | 低分組答對率 | 依總分排序的後 33% 考生 |
| `Pa` | 五等分組第 1 組（最高 20%）答對率 |  |
| `Pb` | 五等分組第 2 組答對率 |  |
| `Pc` | 五等分組第 3 組（中間 20%）答對率 |  |
| `Pd` | 五等分組第 4 組答對率 |  |
| `Pe` | 五等分組第 5 組（最低 20%）答對率 |  |
| `T` | 多選題全對率 | 單選題空白（null） |
| `D` | 鑑別度 | D = Ph − Pl |
| `D1` | 五等分組鑑別度 | D1 = Pa − Pb |
| `D2` | 五等分組鑑別度 | D2 = Pb − Pc |
| `D3` | 五等分組鑑別度 | D3 = Pc − Pd |
| `D4` | 五等分組鑑別度 | D4 = Pd − Pe |
| `options` | 各選項畫記比例 | 畫記該選項人數 ÷ 該組到考人數；T＝全體到考考生、H＝高分組（前 33%）、L＝低分組（後 33%） |
| `omit` | 未答比例 | 未畫記任一選項人數 ÷ 該組到考人數 |
| `key` | 選項分析中數字前標「*」的選項（正確或最適當的選項） |  |

原表註腳（各年寫法略有不同，完整原文與出現年度見 JSON `meta.footnotes`）：

- `Ph`：「Ph=高分組(前33%)考生答對率」（45 個年度同寫法，共 1 種寫法）
- `Pl`：「Pl=低分組(後33%)考生答對率」（45 個年度同寫法，共 1 種寫法）
- `Pa-Pe`：「Pa~Pe=依成績高低分為各佔20%的五種能力組考生答對率」（23 個年度同寫法，共 2 種寫法）
- `T`：「T=多選題全對率」（23 個年度同寫法，共 2 種寫法）
- `D`：「D=全體到考考生鑑別度Ph-Pl」（34 個年度同寫法，共 2 種寫法）
- `D1-D4`：「D1-D4=五種能力組考生鑑別度(D1=Pa-Pb...D4=Pd-Pe)」（22 個年度同寫法，共 3 種寫法）
- `option_groups`：「T,H,L 分別為全部到考考生,高分組考生(前33%),低分組考生(後33%)之答案百分比」（30 個年度同寫法，共 5 種寫法）
- `omit_rate`：「未答百分比=未畫記任一選項人數÷該組(全體,高分組,低分組)到考考生人數」（10 個年度同寫法，共 2 種寫法）

多選題（學測 111–115 第 49 題）：P、Ph、Pl、Pa–Pe 是得分率，T 是全對率，選項比例是各選項被畫記的比例（加總不是 100%）。
