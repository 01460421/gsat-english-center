## 1. 摘要

- 大考中心「歷年試題及答題卷 > 一般試題」列表上，**學測 83–115 每一年、指考 91–110 每一年**的英文試題 PDF、選擇題答案都有，而且都已下載。另外也下載了 4 個補考場次：學測 91、92 補考，指考 93 敏督利颱風補救考試，以及指考 109 補考。出處：[gsat-list]、[ast-list]
- 非選擇題評分原則：**學測 95–115、指考 94–110** 有。學測 83–94、指考 91–93 的列表上沒有這類檔案。
- 試題統計（各題答對率／鑑別度、選項分析）：**學測 91–115、指考 91–110** 有。學測 83–90 的統計頁只有級分分布等總表，沒有逐題統計。出處：[gsat-stats-83-89]、[gsat-stats-90]
- **成績標準與級分對照（2026-10-08 補收）**：各科成績標準一覽表（頂標／前標／均標／後標／底標等）學測 84–115（84–91 為一份合併表）、指考 91–110；學測原始分數（111 起稱「原得總分」）與級分對照表 83–115。這是「穩定基礎／進階練習／超越頂標」難度分級與練習成績換算級分的校準依據。出處：各學年統計頁，例如 [gsat-stats-83-89]、[gsat-stats-115]、[ast-stats-110]；細節見 5.5。
- 另外也收了這些資料：
  - 參考試卷：學測 98、102、107、111、115；指考 98、102、107
  - 110 年試辦考試（108 課綱）英文
  - 各版英文考科「考試說明」（內含 108 課綱混合題示例）
  - **英文作文佳作原卷**：學測 98–115 共 213 篇、指考 98–110 共 153 篇。這些是考生手寫原卷的掃描檔，附官方評分說明，可作為手寫 OCR 與範文的測試資料。

## 3. 檔案分類與命名

manifest 每一筆都有以下欄位：`exam`、`year`、`kind`、`title`、`url`、`local_path`、`bytes`、`sha256`、`text_extractable`、`note`。此外還有這些補充欄位：

| 欄位 | 說明 |
|---|---|
| `session` | `regular`；或 `makeup`（補考、補救考試） |
| `subkind` | 細分類（見下表） |
| `target` | 只用於 reference，值為 `gsat` 或 `ast` |
| `label` | 官網連結文字，例如「試題內容」「非選擇題評分原則」 |
| `official_filename` | 官方檔名 |
| `source_page` | 這個檔案是在哪一個列表頁或條目頁找到的 |
| `list_date` | 列表上顯示的日期 |
| `text_quality` | `ok`、`none`（掃描影像，沒有文字層）或 `garbled`（有文字層，但字型對應錯亂或缺 Unicode 對應，擷取結果是亂碼或空白） |
| `text_chars` | 擷取到的有效字元數 |
| `subjects_detected` | 只用於答案與評分檔，是啟發式偵測到的科目 |
| `duplicate_of` | 只在內容與另一筆完全相同時才有 |

| kind | subkind | 內容 |
|---|---|---|
| paper | `paper` / `paper_word` | 試題本 PDF／官方 Word 版（.doc/.docx）。Word 版也是不可信檔案，只能用解析器讀取，不能用 Office 巨集開啟 |
| answer | `answer` | 選擇題答案 |
| scoring | `scoring` | 非選擇題評分原則／評分標準說明（含中譯英參考答案、作文評分原則） |
| stats | `pd_table` | 選擇題答對率（P）及鑑別度／鑑別指數（D）表 |
| stats | `option_analysis` | 選擇題選項分析 |
| stats | `nonmc_score_dist` | 非選擇題（各題）分數人數統計表 |
| stats | `score_standard` | 各科成績標準一覽表（2026-10-08 補收；標準名稱依年度不同，見 5.5） |
| stats | `score_conversion` | 學測原始分數／原得總分與級分對照表（2026-10-08 補收；指考採原始分數，沒有這類表） |
| other | `essay_sample` | 英文作文佳作原卷（note 內含官方評分說明全文） |
| other | `cover` / `answer_sheet` / `answer_sheet_a4` | 試題封面、答題卷（混合題作答區） |
| other | `paper_note` / `analysis` / `exam_spec` | 參考試卷說明、試題解析、考試說明 |

命名規則：同一個 (exam, year, kind) 只有 1 個檔案時，檔名就是 `{kind}.{副檔名}`；有多個檔案時，依「正式場次在前、subkind、PDF 在前、官網順序」編號為 `-1`、`-2`、…。例如 `gsat/91/paper-1.pdf` 是正式場次的試題，`paper-3.pdf` 是補考試題。實際對應以 manifest 為準，**不要從檔名推測**。

## 5. 覆蓋表

符號說明：

- 「有」：已下載。
- 「有（掃描）」：PDF 沒有可擷取的文字層，需要用 Claude 視覺或 OCR 讀取。
- 「有（亂碼）」：有文字層，但字型對應錯亂，pdftotext 擷取出來是亂碼，也要用視覺讀取。
- 「×2」：同一類有兩份檔案。
- 「—」：官方沒有公布（原因見第 8 節）。

各欄的資料來源：

- 試題、Word 版、答案、評分原則：[gsat-list]、[ast-list]
- 統計三欄：各學年統計頁，例如 [gsat-stats-115]、[ast-stats-110]
- 作文佳作：[gsat-essay]、[ast-essay]

統計檔多半是「各科」合併的 .xls，英文只是其中一個工作表或區段。只有學測 91 與指考 91 是英文科專屬 PDF。另外，學測 97 起有「英文科非選擇題分數人數統計表」，指考 97 起則是「各科非選擇題各題分數人數統計表」。

## 6. 文字層狀況（掃描檔與亂碼檔）

判斷方式：用 `pdftotext` 擷取前兩頁，有效字元（英數、漢字）達 80 個以上，且不是亂碼，就判為 `text_extractable=true`。如果前兩頁的有效字元不足，就擴大到前五頁再判斷一次，以免把只有封面＋目錄的考試說明誤判成掃描檔。

- **掃描或無文字層（`text_quality=none`），共 337 個**：
  - 作文佳作 PDF 327 個（另有 39 個 JPG，不是 PDF）
  - 學測 83–89 答案 7 個
  - 指考 91 的答對率表、選項分析共 2 個
  - 指考 91 封面 1 個
- **亂碼（`garbled`），共 5 個**：學測 90、91、91 補考的答案，以及指考 91、92 的答案。這些檔案都能正常顯示畫面，但字型缺少 Unicode 對應，所以擷取出來是亂碼。後續請用 Claude 視覺讀頁面影像，**不要用 pdftotext 的結果**。
- **其餘 204 個 PDF 判為 `ok`**。所有歷屆試題 PDF（學測 83–115、指考 91–110，含補考）都是 `ok`。但要注意以下例外：
  - 學測 92、92 補考、93，指考 92、93 的試題，以及學測 94 答案：中文字會被擷取成「㈻」「㆗」這類圈字或括號字（例如「大㈻入㈻考試㆗心」），需要做正規化。英文本文不受影響。
  - 指考 91 試題：第 1 頁的中文說明與題型標題是亂碼，第 2 頁之後的英文題目正常。
  - 參考答案、評分原則裡的大括號選項（例如 `reference/107/answer-2.pdf` 的翻譯參考答案）會被擷取成 U+F0xx 的 Symbol 字型字元。判斷品質時已把這些字元排除在亂碼之外，但後續解析需要另外處理。
- **環境需求**：舊 PDF 使用的是 Adobe-CNS1 CID 字型。沒有安裝 `poppler-data` 時，pdftotext 會出現「Missing language pack for 'Adobe-CNS1'」，擷取結果是空的（本次學測 92 與 92 補考的答案，在安裝前就是這樣）。安裝 `poppler-data` 之後就能正確擷取。GitHub Actions 或其他機器請安裝 `poppler-utils poppler-data`。

## 10. 使用與更新

```bash
# 重新爬官網、更新清單（會保留已下載檔的 sha256；路徑若改變會自動搬檔）
python3 tools/fetch_ceec.py discover
# 下載（已存在且 sha256 相符就略過；指數退避重試；回寫 bytes/sha256/text_extractable）
python3 tools/fetch_ceec.py fetch --workers 2
python3 tools/fetch_ceec.py fetch --exam gsat --year 116      # 只抓新年度
python3 tools/fetch_ceec.py fetch --skip-essays               # 不抓作文佳作（省約 269 MiB）
python3 tools/fetch_ceec.py fetch --reprobe                   # 安裝 poppler-data 後重判文字層
python3 tools/fetch_ceec.py verify                            # 只驗雜湊、不連網
```

- 116 學測的檔案公布後，執行 `discover` 就會自動納入。各列表的 `xsmsid` 寫在 `SITES` 常數裡；如果官網改版，需要更新這些常數。
- 安全方面：
  - 下載檔一律視為不可信資料。工具只做三件事：寫檔、計算 sha256、呼叫 pdftotext。
  - 每個檔案都會檢查檔頭是否符合副檔名（PDF、OLE、ZIP、JPEG）。不符時會寫入 `error` 欄位。本次 761 個檔案都沒有錯誤。
- 憑證：Python 3.13 起預設開啟 `VERIFY_X509_STRICT`，會拒絕本環境代理 CA 的憑證鏈（錯誤訊息是「Missing Subject Key Identifier」）。工具只關閉這一項嚴格檢查，憑證鏈與主機名稱驗證照常進行，行為與 curl、requests 一致。
