## 3. 作法

### 3.1 兩位獨立解題者

- **解題者 A**（撰寫詳解的一方）：只讀「去除答案後的題目文字」（`render` 時移除 `answer`、`answer_cells`、`answer_latex`），先解出答案、寫完整詳解，**之後**才和官方答案比對。
- **解題者 B**：每份試卷另開一個**獨立的工作階段**（不在同一個對話、看不到 A 的詳解、看不到官方答案、沒有讀取本 repo 的權限），提示中只有題目文字（含圖的替代文字與表格）、規則（不得使用工具、不得查詢或回想官方解答與補習班解析），只回報最終答案；選填題逐格回報。共 10 個工作階段，回覆全部在 1–2 分鐘內完成。
  - 備註：撰寫時使用的工作環境沒有同對話的子代理工具，因此以「另開工作階段」達成同等的隔離；B 的提示由程式從歷屆試題 JSON 產生、只人工濃縮了參考公式與少數圖說的措辭。
- **比對**：選擇（填）題由 `build` 程式自動比較 A、B、官方三者（選填逐格）；非選擇題由人工比較兩位解題者的最終結果（數值、坐標、範圍、方程式）。
- **SymPy**：設計文件 §6.2 建議以 SymPy 抽查；本環境未安裝 SymPy，非選擇題改以「兩位解題者一致＋詳解內附的代回驗算」（例如鞋帶公式、內積為 0、代入原式）處理。上線前若要補 SymPy 抽查，建議從 20 題非選擇題開始。

### 3.2 D8 與授權

- 生成與驗算全程**沒有**讀取或引用官方的非選擇題參考答案、評分原則、試題解析或電子報（`data/raw` 中的 `scoring.pdf` 未開啟）。
- 非選擇題的「評分重點（本站整理）」是本站依解題步驟自行歸納的自評要點，不是官方評分原則。
- 官方**答對率**（`stats-1.xls`，各科答對率及鑑別度表）用於難度分級：這是統計資料，不是解答。

### 3.3 難度

- `difficulty.official_p`：官方全體考生答對率（多選題為得分率），取自 111–115 `stats-1.xls`「數學A／數學B」工作表，第 1–18 題都有（含混合題的單選題與選填題）。
- 分級沿用 `math.md` §8.2 的設計值：P ≥ 0.60 穩定基礎、0.30 ≤ P < 0.60 進階練習、P < 0.30 超越頂標。
- 非選擇題（每卷第 19、20 題）官方表中沒有答對率，`basis` 標「本站估計」。

## 4. 輸出格式

`data/exams/math-solutions/{paper-id}.json`（`gsat-math-solutions/v1`）：

```jsonc
{
  "schema": "gsat-math-solutions/v1",
  "paper_id": "gsat-matha-115",
  "note": "…",
  "items": [
    {
      "no": 13, "type": "fill",
      "unit": "機率（條件機率）",            // 本站單元名稱（中文，給學生看）
      "unit_tags": ["probability"],          // 同歷屆試題 tags.units
      "difficulty": { "level": "穩定基礎", "official_p": 0.73, "basis": "官方答對率" },
      "solution_md": "**解題關鍵**：…\n\n**詳解**\n\n1. …\n\n**答案**：…",
      "answer_display": "$\\frac{9}{10}$",
      "check": {
        "official": {"13-1": "9", "13-2": "1", "13-3": "0"},
        "solver_a": {"13-1": "9", "13-2": "1", "13-3": "0"},
        "solver_b": {"13-1": "9", "13-2": "1", "13-3": "0"},
        "agree": true
        // "solver_a_initial": 只有解題者 A 初解有誤並改正時才出現
      },
      "flags": []   // [{ "severity": "resolved" | "owner_review", "detail": "…" }]
    }
  ]
}
```

- `solution_md` 段落：**解題關鍵**、**詳解**（編號步驟）、**答案**；多選題另有 **選項分析** 逐項說明 (1)–(5) 對錯；選填題在答案中寫出每一格填什麼；適當處加 **常見錯誤**、**另解**、**補充**；非選擇題另有 **評分重點（本站整理）**。
- 公式：行內 `$…$`、獨立 `$$…$$`，只用 KaTeX 支援的指令。**前端注意**：Markdown 與公式要先切開（例如 remark-math／markdown-it-texmath），避免 Markdown 把公式內的 `\\`、`_`、`*` 當成跳脫或強調。
- 非選擇題的 `check.official` 固定為 `null`，`solver_a`／`solver_b` 為兩位解題者最終結果的文字摘要，`agree` 為人工比對結果。

## 5. Validator

`python3 tools/validate_math_solutions.py --all [--katex <node_modules/katex>] [--require-katex]`（`npm run validate:math-solutions`）：

- 每份歷屆試卷都有詳解檔，題號、題型與歷屆試題一致，不缺、不多、不重複。
- `check.official` 與歷屆試題 JSON 的官方答案（選擇、選填逐格）一致；選擇（填）題 `agree` 必須等於「A＝B＝官方」；`agree` 不是 `true` 的題目必須有 flag。
- 段落齊全（多選逐項、非選擇題評分重點），難度欄位合法。
- 禁止字詞：官方機構名稱、「評分原則」「參考答案」、模型名稱（規則與 `packages/shared` 的文案測試一致）。
- KaTeX：`$`／`$$` 成對、公式內中文須包 `\text{}`；有 KaTeX 時逐段以 `throwOnError` 實際排版（自動尋找 `apps/web/node_modules/katex`、`node_modules/katex`；目前 repo 尚未安裝，需以 `--katex` 指定）。
