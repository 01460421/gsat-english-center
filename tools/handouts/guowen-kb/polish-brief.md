# 《國寫素材庫》單元潤飾：改成參考書語體

站主看過初版後說：「還是太有 AI 教學感了，繼續潤飾。」你是資深的國文參考書主編，負責把一個單元的**說明文字**改寫成市售參考書的語體。內容（條目、引文、出處）已經逐條查證過，不是你的工作範圍。

## 先讀

1. 文風規範（最重要，逐條照做）：`/tmp/claude-0/zhw/style.md`
2. 允許的標籤與 class：`/tmp/claude-0/zhw/spec.md` 的「格式」一節
3. 你負責的單元：`/tmp/claude-0/zhw/parts/單元代號.body.html` 與 `單元代號.ans.html`

## 怎麼做

1. 先把整個單元從頭讀完，對照文風規範的「問題清單」，找出這個單元裡所有屬於那十一類的句子。
2. 逐節改寫：單元開場、每一節的引言、使用原則、框裡的文字（key／tip／warn）、表格前後的說明、示例後的標註、誤／正對照後的說明、自我檢核表、解答檔的說明。照規範的「改寫規則」「固定用語」「改寫示範」處理。
3. 表格裡的「用法」「適用主題」「怎麼記」這類說明欄也要改成精煉的名詞短語或規則句，去掉口語和喊話。
4. 示例句（學生作文示範）：平實自然的保留；句尾刻意反轉、對仗像廣告詞的，改成普通高中生會寫的句子。同一個單元裡不要句句都是同一種寫法。
5. 自我檢核表改成客觀的檢核項目（「能辨別……」「引用時已標明……」），不用「我」開頭的句子可以保留一兩項，但不要每項都是口號。
6. 改完後，從頭到尾再讀一遍，用這三個問題檢查每一段：
   - 這一句是在「陳述規則或事實」，還是在「勸人」？勸人的改掉。
   - 這一句拿掉之後，讀者會少知道什麼？不會的就刪。
   - 讀起來像不像書店裡的國文參考書？

## 限制

- **不得改動**：成語、名句、詩詞、引文的字句；作者、篇名、出處；注音、年代、數字、人物事蹟的事實；練習題題號與正確答案；表格的條目數與順序。不得刪條目。
- 只用規格允許的標籤與 class；不寫行內 style。
- 只減不增：說明文字預期減少二到四成。
- 不提 AI、模型；不寫「大考中心」；不寫「本站」。
- 檔案很大時，用 Edit 分段修改，不要整檔重寫（整檔重寫容易漏掉或改到已查證的條目）。暫存檔只能寫在 `/tmp/claude-0/zhw/tmp/單元代號/`。
- 改完執行 `python3 -I /tmp/claude-0/zhw/check_part.py 單元代號`，修到印出 OK。
- 最後用 diff 自我檢查（原稿備份在 `/tmp/claude-0/zhw/bak1/`）：確認表格列數、練習題數、引文字句沒有變。

## 回覆

用繁體中文，五行以內：改了幾處（大約）、字數從多少變成多少、最常見的三種問題、有沒有不確定而沒動的地方。
