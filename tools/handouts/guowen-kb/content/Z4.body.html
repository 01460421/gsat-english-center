一、古今異義

（一）考點與判斷

定義：字形相同而古今意義或用法不同的詞語。考法：解釋「」內詞語、判斷古今意義是否相同、同一詞語在不同文句中的意義比較。

  1. 先拆後合：文言以單音詞為主，兩字連用多為詞組。先分別解釋兩字，再合看文意。如「妻子」指妻與子女，「地方」指土地方圓，「祖父」指祖輩與父輩。
  2. 代入驗證：以今義代入原句，文意不通、與上下文矛盾或詞性不合者，即為古今異義。如「璧有瑕，請指示王」，今義「命令」代入不通，當解為「指出來給人看」。
  3. 判斷詞性與結構：「所以」「可以」「以為」「於是」「因為」「從而」等，古代是「介詞（或動詞）＋代詞（或連詞）」的組合，不宜逕以今日的連詞、助動詞解釋。
  4. 留意方位與地名：「河」專指黃河，「江」專指長江，「山東」「河北」「河南」「河內」「中國」所指範圍均與今不同。
  5. 同一詞語多義並存：如「可憐」有可愛、可羨、可惜三義，「其實」有果實、實際數量二義，須依語境判定。

（四）深究：詞義演變的類型

古今異義是詞義演變的結果。演變的方向可歸為下列六類，判斷時比較古義與今義所指範圍、對象、褒貶與程度。

類型說明示例

深究：引申與假借

  • 引申：由本義推衍出相關的新義，古今義之間有脈絡可尋。如「兵」由兵器引申為持兵器的人，再引申為戰爭；「朝」由早晨引申為朝見，再引申為朝廷、朝代。擴大、縮小、轉移三類多由引申造成。
  • 假借：借用同音字記錄另一個詞，古今義之間沒有意義關聯。如《莊子・秋水》的「望洋」，教育部辭典釋為看遠、遠視，並注也作「望羊」「望陽」；字形不定，可知以字記音，不可拆字解釋。
  • 雙音化：漢語詞彙由單音詞為主演變為複音詞為主，原來的詞組凝固成詞，是「古為兩詞、今為一詞」一類古今異義的成因。判斷法：兩字之間可插入其他成分，或可分別對譯者，為詞組。如「今齊地方千里」可說成「地，方千里」；「率妻子邑人」的「妻」「子」「邑人」三者並列。

二、通同字

（一）考點與判斷

定義：古書中以甲字代替乙字使用的現象，課本注釋寫作「通『乙』」或「同『乙』」。甲字稱借字（或古字），乙字稱本字（或今字）。考法：指出本字、判斷意義、判斷讀音、比較同一字在不同文句所通之字。

  1. 依字面不可解，改從聲音求之：字面意義代入不通時，尋找讀音相同或相近、代入後文意通順的字。如「旦日不可不蚤自來謝項王」，「蚤」為跳蚤，不可通，改以同音的「早」解之。
  2. 聲符相同者優先：通同字多共用聲符或互為聲符，如 說—悅—脫、責—債、反—返、舍—捨、知—智、共—供、辟—避—僻、直—值、禽—擒、莫—暮。
  3. 讀音原則：通同字多改讀本字之音，如 說（ㄩㄝˋ）、女（ㄖㄨˇ）、亡（ㄨˊ）、被（ㄆㄧ）、信（ㄕㄣ）、內（ㄋㄚˋ）、矜（ㄍㄨㄢ）、繆（ㄌㄧㄠˊ）、莫（ㄇㄨˋ）、暴（ㄆㄨˋ）、責（ㄓㄞˋ）、歸（ㄎㄨㄟˋ）、拂（ㄅㄧˋ）、蓋（ㄏㄜˊ）。括號內注音依教育部《重編國語辭典修訂本》；辭典未另立讀音者不標。
  4. 一字可通多字：須依語境判定，見下表。

（四）深究：通假字、古今字、異體字

課本注釋通稱「通同字」，文字學上則分為三類。三者成因不同，判斷依據亦異。

類別定義與成因判斷依據示例
通假字本有其字而不用，借用音同或音近的字代替。借字與本字意義無關（1）借字的本義、引申義皆不可通；（2）兩字古音相同或相近；（3）古書另有用本字的例證蚤—早、矢—屎、信—伸、倍—背、畔—叛、由—猶、匪—非、拂—弼
古今字同一個詞義，先後用不同的字記錄。古字兼表數義，後世另造今字分擔其中一義，今字多由古字加形符而成（1）兩字有時代先後；（2）字形相承，今字多含古字；（3）古字本來就有該義（本義、引申義或假借義）莫—暮、然—燃、要—腰、責—債、反—返、舍—捨、知—智、見—現、弟—悌、取—娶、縣—懸、賈—價、孰—熟、景—影、禽—擒、共—供、辟—避
異體字音義完全相同，僅字形不同，任何語境均可互換（1）音義全同；（2）差別在偏旁位置、形符或聲符的替換桮—杯、徧—遍、歎—嘆、雞—鷄、羣—群、峯—峰、裏—裡、覩—睹、詠—咏

深究一：本無其字的假借與本有其字的通假

  • 本無其字：許慎《說文解字・敘》：「假借者，本無其字，依聲託事，令、長是也。」語言中已有某詞而尚無專字，遂借同音字記錄，久借不歸。如「其」本為畚箕之形，借為代詞；「莫」本義日暮，借為否定詞；「然」本義燃燒，借為指示代詞與詞尾；「而」本義頰毛，借為連詞；「自」本義鼻子，借為自己；「北」本義相背，借為方位；「來」本為麥名，借為往來之來。此為六書之假借，屬造字（用字）之法。
  • 本有其字：本字已經存在，書寫者仍用同音字代替，即通假。如已有「早」而寫「蚤」，已有「屎」而寫「矢」。
  • 二者的關聯：本無其字的假借往往導致古今字的產生。「莫」被借為否定詞後，本義另加「日」作「暮」；「然」被借走後，本義另加「火」作「燃」；「其」被借走後，本義另加「竹」作「箕」。故「莫—暮」「然—燃」是古今字，不宜稱通假。

深究二：為何以聲音為線索

  • 通假的條件是音同或音近，所據為上古音。「信—伸」「內—納」「矜—鰥」今音相差甚遠，古音則相近；反之，今音相同而古音不近者，不能任意說成通假。
  • 清代學者據此建立「因聲求義」之法：不受字形拘限，從聲音線索求得本字，再定詞義。高中階段不必推求古音，以「聲符相同或相關」作為線索即可，如 責—債、舍—捨、直—值、孰—熟、反—返。
  • 忌濫言通假：字的本義或引申義可以講通時，不必說成通假。如「信臣」的「信」、「陳利兵」的「陳」。

深究三：課本注釋的「通」與「同」

  • 嚴格的用法：通假字注「通」；古今字、異體字注「同」。
  • 各版課本與辭典的標注並不一致。教育部辭典於「知」（ㄓˋ）注「同『智』」，於「說」（ㄩㄝˋ）注「通『悅』」，於「反」注「通『返』」。測驗重點在本字、讀音與意義，不在「通」「同」二字的區別。

三、偏義複詞

定義：兩個意義相反、相對或相關的詞素並列成詞，只取其中一個詞素的意義，另一個詞素僅作陪襯，不表義。

判斷法

  1. 代入法：將兩個詞素的意義分別代入原句，僅一義合於文意者為偏義複詞。如「晝夜勤作息」，「勤」可修飾「作」，不可修飾「息」，偏「作」。
  2. 看支配它的動詞、修飾語或並列成分：「備……出入」，所防備者為「入」；「不宜異同」，所不宜者為「異」；「危急存亡」，與「危急」並列者為「亡」。
  3. 看事理與上下文：「便可白公姥」，焦仲卿僅有母親；「我有親父兄」，劉蘭芝僅有母與兄。
  4. 刪除法：刪去陪襯的詞素，句意不變；兩義兼取者刪去一字則句意殘缺。

深究：偏義複詞的成因與學說

  • 最早的系統論述：顧炎武《日知錄》卷二十七：「愚謂愛憎，憎也。言憎而並及愛，古人之辭寬緩不迫故也。」其下舉得失、利害、緩急、成敗、同異、贏縮、禍福七例，各引史傳為證，上表進階各條即出於此。
  • 連類而及：因說甲而連帶及於相關的乙。《禮記・玉藻》「大夫不得造車馬」為常引之例：車可造，馬不可造，言「車」而連及「馬」。
  • 音節的需要：漢語詞彙趨向雙音節，詩文又講求句式整齊。「晝夜勤作息」為五言句，「作息」湊足音節；「去來江口守空船」為七言句，「來」字為襯。
  • 委婉與避忌：言凶事而連及吉事，語氣較和緩。如「存亡」偏「亡」、「緩急」偏「急」、「禍福」偏「禍」、「好歹」偏「歹」，所偏者多為負面的一方。
  • 名稱：「偏義複詞」一名為近代學者所定；顧炎武未立專名，僅以「言憎而並及愛」說明。

四、同義複詞

定義：兩個意義相同或相近的詞素並列成詞，又稱「同義連用」。

判斷與運用

  1. 兩字可以互相訓釋，解釋時合為一義，不必分釋。如「拔擢」即提拔，「乏困」即缺乏。
  2. 已知其中一字的意義，可據以推知另一字。如「逋慢」，由「慢」（怠慢）推知「逋」亦為拖延、怠忽之類；「裨補」，由「補」推知「裨」為增益。此法可用於課外文言的詞義推斷。
  3. 與偏義複詞的區別：偏義複詞的兩個詞素意義相反或相對，只取一義；同義複詞的兩個詞素意義相同，二者並取而合為一義。

深究：渾言與析言

  • 同義詞連用時統言其同，稱「渾言」；單用而強調彼此的差別，稱「析言」。訓詁學概括為「渾言則同，析言則異」。
  • 饑、饉：《爾雅・釋天》：「穀不熟為饑，蔬不熟為饉。」析言有別；連用為「饑饉」，泛指荒年。
  • 崩、殂：《禮記・曲禮下》：「天子死曰崩。」「崩」專用於天子，「殂」泛指死亡；「崩殂」連用，指帝王之死。
  • 道、路，財、貨，封、閉，修、葺，謗、議等，析言各有側重，連用時不必強分。
  • 同義複詞的大量產生，與偏義複詞相同，均為漢語詞彙雙音化的結果；駢文與詩賦為求句式整齊，尤多用之。

五、聯綿詞

定義：由兩個音節連綴成義而不可分割的單純詞，又稱「連綿詞」「聯綿字」「連語」。兩字只記錄聲音，合起來表示一個意義。

特徵與判斷

  1. 不可分訓：兩字不能拆開各自解釋。如「窈窕」不可解為「窈」與「窕」，「彷彿」不可解為「彷」與「彿」。
  2. 多有聲音關係：聲母相同者為雙聲，韻母（韻腹與韻尾）相同者為疊韻，亦有兼具或兩者皆無者。
  3. 字形不固定：因只記音，同一詞常有數種寫法，如 彷彿／仿佛／髣髴、逶迤／委蛇、徘徊／俳佪、匍匐／扶服、猶豫／猶與。
  4. 多為形容詞或名物詞：形容狀態（參差、窈窕、徘徊、逍遙），或為動植物、器物之名（芙蓉、蝴蝶、琵琶）。

辨析

  • 聯綿詞與同義複詞：同義複詞兩字各自有義，可分訓（乏、困均為缺乏）；聯綿詞兩字合表一義，不可分訓。
  • 聯綿詞與疊字：疊字是同一音節的重複（蒼蒼、翳翳、冥冥），又稱重言；聯綿詞是兩個不同的音節。
  • 「蒹葭」非聯綿詞：「蒹」為荻，「葭」為蘆葦，是兩種植物並列，可以分訓；雖然聲母相同，仍屬並列結構。雙聲、疊韻是語音關係，聯綿詞是構詞類型，二者不可混同。「艱難」「貧困」等合義複詞亦可能恰為雙聲或疊韻。
  • 音譯外來詞：葡萄、琉璃、菩薩等亦為不可分訓的雙音節單純詞，一般與聯綿詞分列。

深究一：雙聲疊韻以古音為準

  • 聯綿詞形成於上古，其雙聲、疊韻關係須依古音判定。今音不合者，多因語音演變所致。
  • 錢大昕《十駕齋養新錄》卷五：「凡輕脣之音，古讀皆為重脣。」今讀ㄈ的字，上古讀如ㄅ、ㄆ。故「繽紛」（今ㄅ、ㄈ）、「匍匐」（今ㄆ、ㄈ）古為雙聲；錢氏並舉《禮記・檀弓》引《詩》「匍匐」作「扶服」為證。
  • 「憔悴」今讀ㄑ、ㄘ，中古同屬一個聲母，為雙聲；今國語ㄐ、ㄑ、ㄒ有一部分由ㄗ、ㄘ、ㄙ分化而來。
  • 測驗中判斷雙聲疊韻，通常以國語讀音為準；遇今音不合而參考書列為雙聲、疊韻者，原因在此。

深究二：望文生訓之誤

  • 聯綿詞只取其音，拆字解釋即成誤解，訓詁學稱為望文生訓。
  • 「猶豫」：顏之推《顏氏家訓・書證》以「猶」為犬或獸名，謂其「豫」在人前、往返不定，故稱猶豫。此說拆字為訓，後世學者多不取；「猶豫」又作「猶與」，可知只是記音。
  • 「望洋」：《莊子・秋水》「望洋向若而歎」，教育部辭典釋為看遠、遠視，並注也作「望羊」「望陽」，字形不定，屬以聲記詞。成語「望洋興歎」，辭典則釋為看到海洋之大而驚嘆；《莊子》原文與後世成語用法宜分別看待。
  • 「狼狽」：唐段成式《酉陽雜俎》卷十六以狼、狽為二獸，狽前足短，須與狼相搭而行；教育部辭典另收一說，以「狽」為「跋」之訛，與《詩經・豳風・狼跋》相關。字源諸說紛歧，「狼狽」今形容困頓窘迫，不宜拆字解釋。
