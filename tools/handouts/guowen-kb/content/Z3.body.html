Z3　字義：文言常見實詞與一字多義

本單元收錄文言實詞 190 字（常見 117 字、進階 73 字），共 634 個義項。各字依注音順序排列，義項大致由本義到引申義、假借義；讀音隨義項改變者，於義項前標注音。字音與義項依教育部《重編國語辭典修訂本》，例句標出處。虛詞用法見 F1，通同字總表見 Z4。

一、考點與推斷方法

（一）題型

題型考法對應能力
同字異義四至五組文句，各含同一字，判斷意義是否相同掌握一字多義，並能依語境選定義項
字義解釋判斷選項對文句中某字的解釋是否正確分辨古今義、通同字、詞類活用
文意理解課外文言短文，關鍵在一、二個實詞的理解依字形、語法、上下文推斷生字義
字音字義綜合同一字在不同文句中的讀音與意義配對破音別義（讀音隨詞性、意義改變）

（二）推斷實詞義的八種方法

  1. 字形推義：形聲字的形符標示意義範疇。從「貝」與財貨有關（負、責、質、資、貽），從「辵」「彳」「止」「足」與行走有關（造、適、遷、遺、過、逮、徒、御、趨），從「言」與言語有關（誠、請、謝、說、讓、識、許），從「刀」與切割有關（解、絕、利），從「糸」與絲織有關（素、絕、累），從「水」與水有關（涉、濟、湯、涕、治）。
  2. 語法定性：先定詞性，再選義項。名詞後接賓語或前有副詞、能願詞者，活用為動詞（「沛公欲王關中」）；動詞前的名詞若非主語，為狀語（「廷見相如」）；「所」後、「不」後多為動詞；形容詞帶賓語為使動或意動（「固國不以山谿之險」）。
  3. 對文互訓：對偶、排比句中，位置相當的字，意義相同、相近或相反。「追亡逐北」，亡、北同指敗逃者；「殫其地之出，竭其廬之入」，殫、竭皆「盡」；「彼竭我盈」，竭、盈相反。
  4. 上下文推義：依前後事理選擇義項。「懷王悔，追張儀，不及」，前有「追」，則「及」為「追上」；「項王按劍而跽曰：『客何為者？』」，前有按劍之舉，則「跽」為戒備的動作。
  5. 成語印證：成語保留古義，可據以推義。「走」為跑（走馬看花、奔走相告）；「去」為離開（去蕪存菁）；「兵」為兵器（短兵相接）；「再」為第二次（一而再，再而三）；「勝」為盡（不勝枚舉）；「殆」為危險（百戰不殆）；「假」為借（狐假虎威）；「就」為靠近（避重就輕）；「卻」為退（望而卻步）；「涕」為眼淚（感激涕零、痛哭流涕）。
  6. 通假求義：依本字解釋不通時，改以同音、音近的字代入。「距關，毋內諸侯」，「內」解作裡面不通，讀為「納」；「卒然問曰」，「卒」讀為「猝」。通假須有音同或音近的條件，不可任意改字。
  7. 古今對照：單音詞古今義差異大者，須依古義解釋。走（跑）、去（離開）、涕（眼淚）、湯（熱水）、兵（兵器）、再（兩次、第二次）、稍（逐漸）、謝（道歉、辭別）、勸（勉勵）、恨（遺憾）、憐（愛）、國（國都）、賊（禍害、作亂者）、幸（寵愛、臨幸）。
  8. 代入檢驗：選定義項後代回原句，檢查詞性是否相合、文意是否通順、與上下文是否矛盾。同字異義題尤須逐項代入，不以白話語感判斷。

注意　同字異義題的誘答，多取「白話常用義」與「文言義」的落差，如「可憐體無比」的「憐」（愛）、「卻坐促絃絃轉急」的「卻」（退）、「一鼓作氣，再而衰」的「再」（第二次）、「後五年，吾妻來歸」的「歸」（出嫁）。凡單音詞恰與白話常用詞同形者，先查古義。

二、深究：詞義的系統

（一）本義、引申義、假借義

名稱定義示例
本義造字時字形所表示的意義，為各義項的起點「本」：《說文》「木下曰本」，指樹根
引申義由本義依相關、相似、因果等關係推演而出的意義；與本義之間有脈絡可循「本」：樹根 → 根本、基礎 → 推究本源（動詞）→ 本來（副詞）
假借義借用同音、音近的字形記錄另一個詞；與本義無意義關聯「莫」：本義日暮，借為無定代詞「沒有誰」、否定副詞「不、不要」，本義另造「暮」字

引申的常見方向：具體到抽象（道：道路 → 方法 → 道理、學說）；個別到一般（病：重病 → 疾病 → 缺點 → 擔憂）；動作到與動作相關的人、事、物（兵：兵器 → 持兵器的人 → 軍事、戰爭；書：書寫 → 所寫之物，即文字、書信、文書、書籍）；實到虛（及：追上 → 到 → 等到，由動詞虛化為介詞、連詞；被：被子 → 覆蓋 → 蒙受 → 表被動的助詞）。

深究　引申脈絡示例

  • 解：以刀剖牛角 → 分割（庖丁解牛）→ 解開、鬆開 → 消除（色少解）→ 分析說明（解惑）→ 明白（不求甚解）。
  • 絕：以刀斷絲 → 斷、中止（群響畢絕）→ 隔斷不通（絕境）→ 橫向截斷水流，即橫渡（絕江河）→ 到達極點（妙絕、絕類彌勒）。
  • 間：門縫中見月光，指空隙（節者有間）→ 空間、時間的中間（斗牛之間）→ 使有空隙，即隔開（與外人間隔）、離間（讒人間之）→ 從空隙插入，即參與（又何間焉）→ 乘隙、偶爾（時時而間進）。空隙以下各義讀ㄐㄧㄢˋ。
  • 就：《說文》「就高也」，指趨向高處 → 靠近、趨向（金就礪）→ 赴任（辭不就職）→ 趨於某種狀態（三徑就荒）→ 達成（事不就）。
  • 歸：《說文》「女嫁也」→ 返回（古人以夫家為女子歸宿）→ 使返回，即歸還（完璧歸趙）→ 歸附、歸向（天下歸仁、吾誰與歸）。
  • 顧：《說文》「還視也」，指回頭看 → 看望、拜訪（三顧）→ 回頭考慮，即顧念、顧慮（不顧細謹）→ 轉折連詞「只是、反而」（顧吾念之）。
  • 謝：《說文》「辭去也」→ 辭別（謝家來貴門）→ 推辭（謝媒人）→ 以言辭告人，即告訴（多謝後世人）→ 認錯（謝項王）→ 感謝；辭去引申為凋落（花謝）。
  • 除：《說文》「殿陛也」，指臺階 → 一級一級更替，即去舊換新 → 去掉（攘除）、授新官職（除臣洗馬）、歲月更替（一歲除）。

（三）詞義的演變：擴大、縮小、轉移、褒貶

類型說明例字（古義 → 今義）
擴大今義的範圍大於古義，古義包含在今義之內病（重病 → 一切疾病）；江、河（長江、黃河的專名 → 河流通稱）；好（女子貌美 → 一切美好）；響（回聲 → 一切聲音）
縮小今義的範圍小於古義，今義包含在古義之內金（金屬通稱 → 黃金）；臭（氣味 → 難聞的氣味）；宮（房屋通稱 → 帝王居所）；子（兒女 → 兒子）；禽（鳥獸總稱 → 鳥類）
轉移古今所指不同，互不包含走（跑 → 步行）；去（離開 → 前往）；涕（眼淚 → 鼻涕）；湯（熱水 → 菜湯）；兵（兵器 → 士兵）；賊（作亂害人者 → 偷竊者）；再（兩次 → 又一次）；稍（逐漸 → 略微）；勸（勉勵 → 規勸）；謝（道歉、辭別 → 感謝）
褒貶與輕重改變感情色彩或程度改變恨（遺憾 → 仇恨，程度加重）；謗（公開議論他人過失 → 惡意毀謗，中性轉貶）；爪牙（得力的武臣 → 幫凶，褒義轉貶）；鄙（邊邑、見識淺 → 粗俗、輕蔑，轉貶）

注意　判斷類型的方法：比較古義與今義所指的範圍。今義涵蓋古義為擴大，古義涵蓋今義為縮小，兩者不相涵蓋為轉移。「兵」由兵器指士兵屬轉移，但文言中兩義並存，須依句子判斷：「收天下之兵」為兵器，「沛公兵十萬」為軍隊。雙音詞的古今異義見 Z4。

（四）因聲求義：通假字、古今字、同源字

清代王念孫《廣雅疏證・序》云：「訓詁之旨，本於聲音。」主張就古音求古義，不受字形限制。文言實詞中讀音相同或相近而互相通用的情形，依成因分為三類。

類別成因判斷例字
通假字本有其字，書寫時借用另一個音同、音近的字兩字同時並存，意義無關聯信—伸、卒—猝、適—謫、歸—饋、矜—鰥、得—德、離—罹、被—披
古今字一字兼表數義，後世另造新字分擔其中一義；先用者為古字，後造者為今字今字多在古字上加偏旁；兩字有先後莫—暮、要—腰、說—悅、知—智、見—現、內—納、屬—囑、舍—捨、責—債、陳—陣、坐—座、道—導、陰—蔭、厭—饜
同源字音近義通，出於同一語源意義有共同的核心曾—增—層（重疊、加多）；亡—無（不存在）

深究　古今字與破音　古今字分化之後，古字在文言中仍保留今字的讀音，因此形成破音：「說」表喜悅讀ㄩㄝˋ，「知」表智慧讀ㄓˋ，「見」表顯現讀ㄒㄧㄢˋ，「內」表接納讀ㄋㄚˋ，「屬」表囑託讀ㄓㄨˇ，「責」表債務讀ㄓㄞˋ，「陳」表軍陣讀ㄓㄣˋ，「食」表餵養讀ㄙˋ，「莫」表日暮讀ㄇㄨˋ。考題常稱此類為「通同字」，不細分通假與古今。通同字總表詳見 Z4。

（一）同義詞辨析

古人訓詁有「渾言」「析言」之分：泛說時兩詞通用（渾言），對舉時各有所指（析言）。下列各組為文言閱讀常見的同義詞。

詞組區別例證
疾／病疾為一般的病，病為重病《說文》：「疾，病也。」「病，疾加也。」《論語・述而》：「子疾病，子路請禱。」
走／趨／行走為跑；趨為小步快走，含恭敬之意；行為步行《說文》：「走，趨也。」《戰國策・趙策四》：「入而徐趨，至而自謝。」「老臣病足，曾不能疾走。」
涕／泣涕為眼淚（名詞）；泣為無聲流淚（動詞），亦指眼淚《詩經・衛風・氓》：「不見復關，泣涕漣漣。」《說文》：「涕，泣也。」
饑／飢饑指穀物不熟、荒年；飢指腹中飢餓。後世混用《說文》：「饑，穀不孰為饑。」「飢，餓也。」
言／語言為主動說話；語為與人交談、告訴《說文》：「直言曰言，論難曰語。」〈桃花源記〉：「此中人語云。」
視／見；聽／聞視、聽指動作；見、聞指動作的結果《禮記・大學》：「心不在焉，視而不見，聽而不聞。」
伐／侵／襲伐為公開聲討；侵為不宣而戰；襲為輕裝突擊《左傳・莊公二十九年》：「凡師，有鐘鼓曰伐，無曰侵，輕曰襲。」
崩／薨／卒／不祿／死依死者身分而異《禮記・曲禮下》：「天子死曰崩，諸侯曰薨，大夫曰卒，士曰不祿，庶人曰死。」
盜／賊盜指竊取財物者；賊指作亂、害人者。與今義相反《禮記・禮運》：「盜竊亂賊而不作。」〈後出師表〉：「漢、賊不兩立。」
恨／怨恨為遺憾、不滿足；怨為怨恨。恨輕而怨重〈出師表〉：「未嘗不嘆息痛恨於桓、靈也。」〈陌上桑〉：「來歸相怨怒。」
假／借二字同義，先秦多用「假」《孟子・盡心上》：「久假而不歸，惡知其非有也？」
遺／貽／歸（饋）皆為贈送。遺讀ㄨㄟˋ；歸讀ㄎㄨㄟˋ，通「饋」，多指送食物〈飲馬長城窟行〉：「遺我雙鯉魚。」《論語・陽貨》：「歸孔子豚。」
如／適／之／往皆為「到……去」。如、適、之後接處所賓語；往一般不接賓語《史記・項羽本紀》：「沛公起如廁。」《論語・子路》：「子適衛。」
