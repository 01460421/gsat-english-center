G8　重要作家（先秦至唐）

本單元收錄先秦至唐代作家七十七位：主要作家五十位（第二至六節），進階作家二十七位（第九節）。各表依序列出：時代、字號、籍貫與別稱；文學地位與風格；代表作、作品集與並稱。第十至十五節為風格比較、歷代評語、風格成因與承襲關係、爭議與異說、並稱與詩體補充、時代定位總表。籍貫括號內為今地。宋以後作家見 G9，詞人另見 G5，史書體例另見 G2。

一、考點與判讀方法

常見考法

  • 字、號、別稱、稱號與作家配對，如「柳柳州」「陳思王」「詩佛」。
  • 並稱所指作家，以及並稱的依據（同派、同時、同族、同體）。
  • 代表作、作品集與作者配對；作品集的命名依據。
  • 評語與所評作家配對，如「文起八代之衰」「古今隱逸詩人之宗」。
  • 作家時代先後排序；作家與流派、文學運動的對應。

二、先秦兩漢作家

作家時代・字號・籍貫・別稱地位與風格代表作・作品集・並稱
屈原戰國楚人。名平，字原；〈離騷〉自述名正則，字靈均。曾任左徒、三閭大夫。楚辭的開創者與代表作家，後世尊為「辭賦之祖」。想像豐富，辭采瑰麗；以香草美人為比興，句中多用「兮」字。〈離騷〉〈九歌〉〈九章〉〈天問〉。作品收入西漢劉向所輯《楚辭》。並稱：屈宋。
宋玉戰國楚人，時代後於屈原。楚辭作家。〈九辯〉以秋景寫失意，為後世悲秋之作所本。〈九辯〉；《文選》收〈風賦〉〈高唐賦〉〈神女賦〉〈登徒子好色賦〉〈對楚王問〉。〈招魂〉一說宋玉作，一說屈原作。並稱：屈宋。
李斯秦。楚國上蔡（今河南上蔡）人。師事荀子，官至秦丞相。文章鋪陳排比，多用對偶，氣勢充沛，下開漢代辭賦之風。主張統一文字，以小篆為標準，作《倉頡篇》。〈諫逐客書〉。無專集，文見《史記・李斯列傳》。
賈誼西漢洛陽人。世稱賈生；曾任長沙王太傅，又稱賈太傅、賈長沙。西漢初年政論家、辭賦家。政論說理透闢，氣勢充沛；辭賦上承楚辭，下啟漢賦。〈過秦論〉〈治安策〉（又名〈陳政事疏〉）、〈論積貯疏〉、〈弔屈原賦〉、〈鵩鳥賦〉。《新書》。並稱：屈賈（《史記》二人合傳）。
司馬相如西漢蜀郡成都人，字長卿。漢賦代表作家，後世稱「賦聖」「辭宗」。鋪張揚厲，辭藻富麗。〈子虛賦〉〈上林賦〉〈長門賦〉。並稱：揚馬（與揚雄）；漢賦四大家。
司馬遷西漢夏陽（今陝西韓城）人，字子長。繼父司馬談為太史令，世稱太史公、史遷。《史記》為紀傳體之祖、通史之祖、正史之首。敘事生動，人物形象鮮明。魯迅《漢文學史綱要》評為「史家之絕唱，無韻之〈離騷〉」。《史記》（原稱《太史公書》；本紀十二、表十、書八、世家三十、列傳七十，共一百三十篇）、〈報任少卿書〉。並稱：班馬（馬班）。
班固東漢扶風安陵（今陝西咸陽）人，字孟堅。班彪之子，班超、班昭之兄。《漢書》為第一部紀傳體斷代史。文字典雅整飭。兼為辭賦家。《漢書》（紀、表、志、傳；續父班彪之作，未竟部分由班昭、馬續補成）、〈兩都賦〉。並稱：班馬；漢賦四大家。

補充：《詩經・國風》與《楚辭・離騷》並稱「風騷」，後泛指文學。「漢賦四大家」指司馬相如、揚雄、班固、張衡。《史記》與《漢書》並稱「史漢」；二書之別見 G2。

三、魏晉作家

作家時代・字號・籍貫・別稱地位與風格代表作・作品集・並稱
曹操東漢末沛國譙（今安徽亳州）人，字孟德。曹丕稱帝後追尊為魏武帝。建安文學的開創者。以樂府舊題寫時事；四言詩成就尤高。風格慷慨悲涼，古直雄健。〈短歌行〉〈觀滄海〉〈龜雖壽〉〈蒿里行〉。《魏武帝集》。並稱：三曹。
曹丕三國魏。字子桓，曹操之子。代漢稱帝，即魏文帝。詩風清麗婉約。〈燕歌行〉為現存最早的完整文人七言詩。《典論・論文》為現存最早的文學批評專論，謂文章為「經國之大業，不朽之盛事」。〈燕歌行〉、《典論・論文》。《魏文帝集》。並稱：三曹。
曹植三國魏。字子建，曹丕之弟。封陳王，諡思，世稱陳思王。鍾嶸《詩品》稱為「建安之傑」，評其詩「骨氣奇高，詞采華茂」。五言詩成就為建安之冠。「才高八斗」「七步成詩」典故均出其事。〈洛神賦〉〈白馬篇〉〈贈白馬王彪〉、〈七步詩〉（見《世說新語・文學》）。《曹子建集》。並稱：三曹。
孔融東漢末魯國（今山東曲阜）人，字文舉。孔子二十世孫。曾任北海相，世稱孔北海。建安七子之一。曹丕評其文「體氣高妙」。〈論盛孝章書〉〈薦禰衡表〉。
王粲東漢末山陽高平（今山東）人，字仲宣。先依劉表，後歸曹操。建安七子之一，劉勰《文心雕龍》稱為「七子之冠冕」。長於辭賦與五言詩，多寫亂離與懷鄉。〈登樓賦〉（「雖信美而非吾土兮，曾何足以少留」）、〈七哀詩〉。
諸葛亮三國蜀漢琅邪陽都（今山東）人，字孔明，號臥龍。封武鄉侯，諡忠武，世稱諸葛武侯。蜀漢丞相。文章質樸懇切，不尚雕飾。〈出師表〉、〈後出師表〉（一說非亮所作）、〈誡子書〉。《諸葛亮集》（又稱《諸葛武侯集》）。
李密西晉犍為武陽（今四川彭山）人，字令伯。原仕蜀漢；蜀亡後，晉武帝徵為太子洗馬，上表辭謝。以孝著稱。文辭懇切委婉。「煢煢孑立」「形影相弔」「日薄西山」「烏鳥私情」等語均出〈陳情表〉。〈陳情表〉。
阮籍三國魏陳留尉氏（今河南）人，字嗣宗。阮瑀之子。曾任步兵校尉，世稱阮步兵。竹林七賢之一，正始文學代表。五言〈詠懷詩〉隱晦曲折，《詩品》謂其「厥旨淵放，歸趣難求」。〈詠懷詩〉八十二首、〈大人先生傳〉。《阮步兵集》。並稱：嵇阮。
嵇康三國魏譙郡銍（今安徽）人，字叔夜。曾任中散大夫，世稱嵇中散。後為司馬昭所殺。竹林七賢之一。長於四言詩與論說文，《文心雕龍》謂「嵇志清峻，阮旨遙深」。善琴，以〈廣陵散〉知名。〈與山巨源絕交書〉〈養生論〉〈聲無哀樂論〉〈琴賦〉。《嵇中散集》。並稱：嵇阮。
左思西晉臨淄（今山東）人，字太沖。出身寒門。太康詩人。〈詠史〉詩抒寒士不平，筆力剛健，後世稱「左思風力」。〈三都賦〉成，時人競相傳寫，「洛陽紙貴」典故出此。〈三都賦〉（〈蜀都賦〉〈吳都賦〉〈魏都賦〉）、〈詠史〉八首。

建安七子（名單出自曹丕《典論・論文》，又稱鄴下七子）

孔融（文舉）、陳琳（孔璋）、王粲（仲宣）、徐幹（偉長）、阮瑀（元瑜）、應瑒（德璉）、劉楨（公幹）。陳琳、阮瑀長於章表書檄；徐幹著《中論》；劉楨長於五言詩。

竹林七賢

山濤、阮籍、嵇康、向秀、劉伶、阮咸、王戎。崇尚老莊，輕視禮法。

四、東晉南北朝作家

作家時代・字號・籍貫・別稱地位與風格代表作・作品集・並稱
王羲之東晉琅邪臨沂（今山東臨沂）人，後居會稽；字逸少。曾任右軍將軍，世稱王右軍。書法家，後世尊為「書聖」。散文清新自然，不尚駢儷。〈蘭亭集序〉（東晉穆帝永和九年作）。並稱：二王（與子王獻之，指書法）。
陶淵明東晉潯陽柴桑（今江西九江）人。名潛，字元亮（《晉書・隱逸傳》）；一說字淵明，或名淵明、字元亮（《宋書・隱逸傳》：「陶潛字淵明，或云淵明字元亮。」）。自號五柳先生；卒後友人私諡靖節，世稱靖節先生。曾任彭澤令。鍾嶸《詩品》稱為「古今隱逸詩人之宗」；田園詩的開創者，後世稱「田園詩人之宗」。風格平淡自然，質樸真淳。蘇軾稱其詩「質而實綺，臞而實腴」（見蘇轍〈子瞻和陶淵明詩集引〉；臞，同「癯」）。〈歸去來兮辭〉〈桃花源記〉〈五柳先生傳〉〈歸園田居〉〈飲酒〉。《陶淵明集》（又稱《靖節先生集》）。並稱：陶謝。
謝靈運南朝宋陳郡陽夏（今河南太康）人。謝玄之孫，襲封康樂公，世稱謝康樂；小名客兒，又稱謝客。山水詩的開創者。刻畫細緻，富麗精工。《詩品》稱為「元嘉之雄」。〈登池上樓〉（「池塘生春草，園柳變鳴禽」）。《謝康樂集》。並稱：陶謝；顏謝（與顏延之）；大小謝（與謝朓）；元嘉三大家。
劉義慶南朝宋彭城（今江蘇徐州）人。宋武帝劉裕之姪，襲封臨川王。所撰《世說新語》為志人小說代表，記東漢末至東晉名士言行，語言簡約雋永。《世說新語》（分德行、言語、政事、文學等三十六門；南朝梁劉孝標注）、《幽明錄》（志怪）。
鮑照南朝宋東海人，字明遠。出身寒微。曾任前軍參軍，世稱鮑參軍。長於樂府與七言歌行，影響唐代七言詩。杜甫以「俊逸」稱之。〈擬行路難〉十八首、〈蕪城賦〉。《鮑參軍集》。並稱：元嘉三大家。
謝朓南朝齊陳郡陽夏人，字玄暉。曾任宣城太守，世稱謝宣城；又稱小謝。永明體代表詩人，竟陵八友之一。山水詩清麗，講究聲律，下開唐代近體詩。李白詩「中間小謝又清發」即指謝朓。〈晚登三山還望京邑〉（「餘霞散成綺，澄江靜如練」）。《謝宣城集》。並稱：大小謝。
庾信南陽新野（今河南新野）人，字子山。初仕南朝梁，出使西魏被留，後仕北周，官至開府儀同三司，世稱庾開府。前期文風綺豔，與徐陵並稱，世稱「徐庾體」；後期多鄉關之思，風格蒼涼沉鬱。駢文、駢賦成就最高。杜甫〈戲為六絕句〉其一稱「庾信文章老更成」。〈哀江南賦〉〈擬詠懷〉。《庾子山集》（又稱《庾開府集》）。並稱：徐庾。
酈道元北魏范陽涿縣（今河北涿州）人，字善長。地理學家、散文家。寫景文字清麗峻潔，為後世山水遊記先導。《水經注》四十卷（為《水經》作注；〈江水〉記三峽一段最著名）。

補充：南朝的文學批評與總集

  • 劉勰《文心雕龍》：五十篇，以駢文寫成，論文體、創作與批評，為體大思精的文學理論專著。
  • 鍾嶸《詩品》：品評漢至梁的五言詩人，分上、中、下三品。陶淵明列於中品。
  • 蕭統《文選》：蕭統為梁武帝之子，諡昭明，世稱昭明太子；所編《文選》為現存最早的詩文總集，又稱《昭明文選》。

辨析：田園詩與山水詩。陶淵明寫農村生活與躬耕之樂，風格平淡，屬田園詩；謝靈運寫遊覽所見山水，刻畫精工，屬山水詩。二者至盛唐王維、孟浩然合流為山水田園詩派。

五、初唐、盛唐作家

王勃初唐絳州龍門（今山西河津）人，字子安。初唐四傑之首。駢文與五言律詩兼擅。〈滕王閣序〉（「落霞與孤鶩齊飛，秋水共長天一色」）、〈送杜少府之任蜀州〉（「海內存知己，天涯若比鄰」）。《王子安集》。
楊炯初唐華陰（今陝西華陰）人。曾任盈川令，世稱楊盈川。初唐四傑之一。長於五言律詩，多邊塞之作。自謂「愧在盧前，恥居王後」。〈從軍行〉（「寧為百夫長，勝作一書生」）。《盈川集》。
盧照鄰初唐幽州范陽（今河北涿州）人，字昇之，號幽憂子。初唐四傑之一。長於七言歌行。〈長安古意〉。《幽憂子集》（又稱《盧昇之集》）。
駱賓王初唐婺州義烏（今浙江義烏）人。曾任臨海丞，世稱駱臨海。初唐四傑之一。長於七言歌行與駢文。曾為徐敬業草檄討武后。〈為徐敬業討武曌檄〉（「請看今日之域中，竟是誰家之天下」）、〈在獄詠蟬〉。《駱臨海集》（又稱《駱丞集》）。
陳子昂初唐梓州射洪（今四川射洪）人，字伯玉。曾任右拾遺，世稱陳拾遺。唐詩革新的先驅。〈與東方左史虯修竹篇序〉標舉「漢魏風骨」與「興寄」，批評齊梁詩「彩麗競繁」。後世稱「詩骨」。〈登幽州臺歌〉、〈感遇〉三十八首。《陳伯玉集》（又稱《陳拾遺集》）。
孟浩然盛唐襄州襄陽（今湖北襄陽）人。名浩，字浩然，以字行。世稱孟襄陽。曾隱居鹿門山，終身未仕。山水田園詩人。長於五言，風格清淡自然。〈過故人莊〉〈春曉〉〈宿建德江〉〈望洞庭湖贈張丞相〉。《孟浩然集》。並稱：王孟。
王維盛唐太原祁（今山西祁縣）人，後徙蒲州；字摩詰。官至尚書右丞，世稱王右丞。山水田園詩人，兼擅繪畫、音樂。篤信佛教，世稱「詩佛」。蘇軾評：「味摩詰之詩，詩中有畫；觀摩詰之畫，畫中有詩。」風格空靈閒淡，富禪趣。〈山居秋暝〉〈鹿柴〉〈竹里館〉〈送元二使安西〉〈使至塞上〉〈九月九日憶山東兄弟〉。《王右丞集》。並稱：王孟。
李白盛唐。字太白，號青蓮居士。祖籍隴西成紀（今甘肅），幼隨父遷居綿州（今四川）。曾供奉翰林。世稱「詩仙」；賀知章稱為「謫仙」。浪漫詩風的代表。風格豪放飄逸，想像奇特，多用誇飾。長於樂府、歌行、絕句。〈將進酒〉〈蜀道難〉〈行路難〉〈月下獨酌〉〈長干行〉〈早發白帝城〉〈春夜宴從弟桃花園序〉。《李太白集》。並稱：李杜。
杜甫盛唐。字子美，自號少陵野老、杜陵布衣。祖籍襄陽，生於河南鞏縣。曾任左拾遺、檢校工部員外郎，世稱杜拾遺、杜工部。世稱「詩聖」。詩作反映安史之亂前後的社會實況，有「詩史」之稱。風格沉鬱頓挫。各體兼擅，尤工律詩。「三吏」（〈新安吏〉〈石壕吏〉〈潼關吏〉）、「三別」（〈新婚別〉〈垂老別〉〈無家別〉）、〈兵車行〉〈春望〉〈茅屋為秋風所破歌〉〈登高〉〈旅夜書懷〉。《杜工部集》。並稱：李杜。
高適盛唐渤海蓨（今河北景縣）人，字達夫。官至散騎常侍，世稱高常侍。邊塞詩人。風格悲壯渾厚，多夾敘夾議。〈燕歌行〉（「戰士軍前半死生，美人帳下猶歌舞」）、〈別董大〉（「莫愁前路無知己，天下誰人不識君」）。《高常侍集》。並稱：高岑。
岑參盛唐南陽（今河南）人，一說江陵人。兩度出塞。曾任嘉州刺史，世稱岑嘉州。邊塞詩人。長於七言歌行。風格奇峭瑰麗，善寫塞外風光。〈白雪歌送武判官歸京〉（「忽如一夜春風來，千樹萬樹梨花開」）、〈走馬川行奉送封大夫出師西征〉、〈逢入京使〉。《岑嘉州集》。並稱：高岑。
王昌齡盛唐京兆長安（今陝西西安）人，一說太原人；字少伯。曾任江寧丞、龍標尉，世稱王江寧、王龍標。長於七言絕句，世稱「七絕聖手」；又有「詩家天子」之稱（《唐才子傳》作「詩家夫子」）。題材含邊塞、閨怨、宮怨、送別。〈出塞〉（「秦時明月漢時關」）、〈從軍行〉、〈閨怨〉、〈芙蓉樓送辛漸〉（「一片冰心在玉壺」）。
王之渙盛唐并州晉陽（今山西太原）人，字季凌。以絕句著稱，與高適、王昌齡齊名。傳世作品甚少。〈登鸛雀樓〉、〈涼州詞〉（「黃河遠上白雲間」）。

初唐四傑：王勃、楊炯、盧照鄰、駱賓王，時稱「王楊盧駱」。四人官位不高而文名甚盛；詩文仍帶六朝辭采，而題材已由宮廷擴及江山、邊塞、市井。王、楊長於五言律詩，盧、駱長於七言歌行。

李杜比較：李白，詩仙，浪漫，豪放飄逸，長於古體與絕句；杜甫，詩聖，寫實，沉鬱頓挫，長於律詩。韓愈〈調張籍〉：「李杜文章在，光焰萬丈長。」

高岑比較：高適多寫征戍之苦與邊事得失，風格悲壯質實；岑參多寫塞外奇景，風格奇麗。

六、中唐、晚唐作家

作家時代・字號・籍貫・別稱地位與風格代表作・作品集・並稱
韋應物中唐京兆（今陝西西安）人。曾任蘇州刺史，世稱韋蘇州。山水田園詩人。長於五言，風格閒澹簡遠，近於陶淵明。〈滁州西澗〉〈寄全椒山中道士〉。《韋蘇州集》。並稱：韋柳；王孟韋柳。
韓愈中唐河南河陽（今河南孟州）人，字退之。郡望昌黎，世稱韓昌黎；官至吏部侍郎，又稱韓吏部；諡文，又稱韓文公。唐代古文運動領袖，唐宋古文八大家之首。主張文道合一；〈答李翊書〉主「惟陳言之務去」，〈南陽樊紹述墓誌銘〉稱「文從字順」。蘇軾譽為「文起八代之衰」。文風雄健奔放；詩則以文為詩，奇崛險怪。〈師說〉〈原道〉〈原毀〉〈進學解〉〈雜說〉〈祭十二郎文〉〈送董邵南序〉〈諫迎佛骨表〉。《昌黎先生集》。並稱：韓柳；韓孟。
柳宗元中唐河東（今山西永濟）人，字子厚，世稱柳河東。參與永貞革新失敗，貶永州司馬；後任柳州刺史，又稱柳柳州。古文運動的倡導者，唐宋古文八大家之一。〈答韋中立論師道書〉自述「文者以明道」。長於山水遊記、寓言、傳記。文風峻潔峭拔。「永州八記」（首篇〈始得西山宴遊記〉）、〈三戒〉（〈臨江之麋〉〈黔之驢〉〈永某氏之鼠〉）、〈捕蛇者說〉〈種樹郭橐駝傳〉、詩〈江雪〉〈漁翁〉。《柳河東集》。並稱：韓柳；劉柳；韋柳。
劉禹錫中唐洛陽（今河南洛陽）人，自稱中山人；字夢得。參與永貞革新失敗，屢遭貶謫。晚年任太子賓客，世稱劉賓客。白居易稱為「詩豪」。風格雄健明快。長於懷古詩；仿巴渝民歌作〈竹枝詞〉。〈陋室銘〉〈烏衣巷〉〈石頭城〉〈西塞山懷古〉〈竹枝詞〉〈酬樂天揚州初逢席上見贈〉（「沉舟側畔千帆過，病樹前頭萬木春」）。《劉賓客集》（又稱《劉夢得文集》）。並稱：劉白；劉柳。
白居易中唐下邽（今陝西渭南）人，祖籍太原；字樂天，晚號香山居士、醉吟先生。曾貶江州司馬。新樂府運動的倡導者，主張「文章合為時而著，歌詩合為事而作」。風格平易淺近，相傳「老嫗能解」。有「詩魔」之稱（語本其詩「酒狂又引詩魔發」）。自分其詩為諷諭、閒適、感傷、雜律四類。〈長恨歌〉〈琵琶行〉〈賣炭翁〉、〈新樂府〉五十首、〈秦中吟〉十首、〈與元九書〉。《白氏長慶集》。並稱：元白；劉白。
元稹中唐河南（今河南洛陽）人，字微之。與白居易同倡新樂府，詩風平易。長於悼亡詩。兼作傳奇。〈遣悲懷〉三首、〈離思〉（「曾經滄海難為水，除卻巫山不是雲」）、〈連昌宮詞〉、傳奇〈鶯鶯傳〉（又名〈會真記〉，《西廂記》故事所本）。《元氏長慶集》。並稱：元白。
孟郊中唐湖州武康（今浙江德清）人，字東野。苦吟詩人。詩多寫窮愁，風格寒苦。元好問〈論詩三十首〉稱為「詩囚」（「高天厚地一詩囚」）。〈遊子吟〉〈登科後〉。《孟東野詩集》。並稱：郊島；韓孟。
賈島中唐范陽（今河北涿州）人，字浪仙（一作閬仙）。早年為僧，法名無本，後還俗。曾任長江主簿，世稱賈長江。苦吟詩人。長於五言律詩，風格清奇幽峭。「推敲」典故出其事。有「詩奴」之稱。〈尋隱者不遇〉、〈題李凝幽居〉（「鳥宿池邊樹，僧敲月下門」）。《長江集》（又稱《賈長江集》）。並稱：郊島。
李賀中唐福昌（今河南宜陽）人，家居昌谷，世稱李昌谷；字長吉。年二十七卒。世稱「詩鬼」「鬼才」。想像奇詭，辭采冷豔，好用神話、鬼魅意象。長於樂府歌行。〈李憑箜篌引〉、〈雁門太守行〉（「黑雲壓城城欲摧」）、〈金銅仙人辭漢歌〉（「天若有情天亦老」）。《昌谷集》（又稱《李長吉歌詩》）。
杜牧晚唐京兆萬年（今陝西西安）人，字牧之，號樊川居士，世稱杜樊川。宰相杜佑之孫。世稱「小杜」，以別於杜甫。長於七言絕句與詠史詩，風格俊爽。文章多論時政、兵事。〈阿房宮賦〉〈泊秦淮〉〈山行〉〈赤壁〉〈題烏江亭〉〈過華清宮〉〈遣懷〉。《樊川文集》。並稱：小李杜。
李商隱晚唐懷州河內（今河南沁陽）人，字義山，號玉谿生、樊南生。長於七言律詩、絕句。風格深情綿邈，辭藻精麗，好用典故，旨意多隱晦；以〈無題〉詩著稱。兼擅駢文。宋初西崑體即仿其詩風。〈錦瑟〉、〈無題〉（「相見時難別亦難」）、〈夜雨寄北〉〈登樂遊原〉〈嫦娥〉〈賈生〉。《李義山詩集》《樊南文集》。並稱：小李杜；溫李。
溫庭筠晚唐太原祁（今山西祁縣）人，本名岐，字飛卿。才思敏捷，相傳八叉手而成八韻，人稱溫八叉。詩與李商隱齊名。詞為花間派之祖，世稱「花間鼻祖」，《花間集》列於卷首。風格濃豔綺麗，多寫閨情。詞：〈菩薩蠻〉（「小山重疊金明滅」）、〈望江南〉（「梳洗罷，獨倚望江樓」）、〈更漏子〉。詩：〈商山早行〉（「雞聲茅店月，人跡板橋霜」）。《溫飛卿詩集》。並稱：溫李（詩）；溫韋（詞，與韋莊）。

韓柳比較

  • 相同：同倡古文，反對駢文獨尊；同列唐宋古文八大家。
  • 韓愈：尊儒排佛；長於論說、贈序、祭文；文風雄渾奔放。
  • 柳宗元：兼容儒佛；長於山水遊記、寓言、傳記；文風峻潔峭拔。

中唐兩大詩派：韓愈、孟郊、賈島、李賀尚奇險，重苦吟；白居易、元稹尚平易，重諷諭。

注意：「文以載道」一語本於北宋周敦頤《通書・文辭》「文所以載道也」，後世用以概括古文家的主張；韓愈、柳宗元文中所用為「明道」一類說法。〈長恨歌〉〈琵琶行〉屬白居易自分的感傷詩，不屬〈新樂府〉；〈賣炭翁〉屬〈新樂府〉。

  • 老杜指杜甫，小杜指杜牧；杜審言為杜甫祖父，杜佑為杜牧祖父。
  • 「二謝」所指不一，可指謝靈運與謝朓，亦可指謝靈運與謝惠連；「大小謝」專指謝靈運與謝朓。
  • 曹丕〈燕歌行〉為七言閨怨詩；高適〈燕歌行〉為邊塞詩，二者同題異趣。

十、並稱作家風格比較

並稱前者後者評語（出處）
屈宋屈原：抒寫忠憤，情志激切，開創騷體。宋玉：長於鋪陳體物，辭采工麗，由騷入賦。「相如好書，師範屈宋。」（《文心雕龍・才略》）
班馬司馬遷：通史；文筆疏宕，多用散句；寓褒貶於敘事。班固：斷代史；文筆整飭，多用排偶與古字。「其文直，其事核，不虛美，不隱惡，故謂之實錄。」（《漢書・司馬遷傳》贊述劉向、揚雄之評，評司馬遷）
三曹曹操：古直悲涼；四言、樂府。曹丕：清麗婉約；七言、文論。曹植：骨氣與辭采兼備；五言。「子建思捷而才儁，詩麗而表逸；子桓慮詳而力緩，故不競於先鳴。」（《文心雕龍・才略》）
嵇阮嵇康：峻切直露；長於論說文、四言詩。阮籍：隱晦曲折；長於五言詩。「嵇康師心以遣論，阮籍使氣以命詩。」（《文心雕龍・才略》）
潘陸潘岳：清綺流暢，長於抒哀情。陸機：繁富深厚，講究辭藻。「潘詩爛若舒錦，無處不佳；陸文如披沙簡金，往往見寶。」（謝混語，《詩品》卷上引）
陶謝陶淵明：田園；平淡自然，重寫意。謝靈運：山水；富麗精工，重形似。「以康樂之奧博，多溺於山水；以淵明之高古，偏放於田園。」（白居易〈與元九書〉）
顏謝顏延之：雕琢典麗，好用故事。謝靈運：寫景清新，時有自然之句。「謝詩如芙蓉出水，顏如錯彩鏤金。」（湯惠休語，《詩品》卷中引）
大小謝謝靈運：篇幅較長，繁富典重，篇末多說理。謝朓：篇幅較短，清麗圓熟，講究聲律。「奇章秀句，往往警遒。」（《詩品》卷中，評謝朓）
王孟王維：亦官亦隱；各體兼工；融詩、畫、禪於一。孟浩然：布衣終身；以五言為主；清淡渾成。「孟襄陽學力下韓退之遠甚，而其詩獨出退之之上者，一味妙悟而已。」（嚴羽《滄浪詩話・詩辨》）
高岑高適：質實悲壯，多議論。岑參：奇峭瑰麗，多寫景。「高岑之詩悲壯，讀之使人感慨。」（《滄浪詩話・詩評》）
李杜李白：飄逸；長於樂府歌行、絕句。杜甫：沉鬱；長於律詩、敘事長篇。「子美不能為太白之飄逸，太白不能為子美之沉鬱。」（《滄浪詩話・詩評》）
韓柳韓愈：文雄渾奔放；詩奇崛。柳宗元：文峻潔峭拔；詩清峻簡淡。「獨韋應物、柳宗元發纖穠於簡古，寄至味於淡泊。」（蘇軾〈書黃子思詩集後〉，評柳詩）
元白元稹：長於豔情、悼亡。白居易：題材更廣，諷諭、閒適、感傷兼備。「元輕白俗。」（蘇軾〈祭柳子玉文〉）
郊島孟郊：多作五言古詩，寒苦。賈島：多作五言律詩，清瘦幽僻。「郊寒島瘦。」（同上）；「孟郊之詩刻苦，讀之使人不歡。」（《滄浪詩話・詩評》）
小李杜李商隱：深婉綿密；七律、無題。杜牧：俊爽明快；七絕、詠史。二人同為晚唐大家，風格相異而並稱。
溫韋溫庭筠：穠麗，多客觀描摹閨閣。韋莊：清疏，多直抒個人情感。「溫飛卿之詞，句秀也；韋端己之詞，骨秀也。」（王國維《人間詞話》）

辨析：鮑照答顏延之語另見《南史・顏延之傳》：「謝五言如初發芙蓉，自然可愛。君詩若鋪錦列繡，亦雕繢滿眼。」與湯惠休語意近而出處不同。二語皆以自然為高、以雕飾為次，故《詩品》記「顏終身病之」。

  • 「風骨」「風力」「骨氣」：指作品情志剛健、言辭端直，多用於建安詩人與左思。
  • 「興寄」：指詩有寄託，藉物事寓含對時世的感慨，陳子昂用以批評齊梁詩。
  • 「沉鬱頓挫」：情感深沉鬱積，音節、章法抑揚轉折，專指杜甫。
  • 「興趣」「妙悟」：嚴羽以禪喻詩的用語，指不著痕跡、言有盡而意無窮的詩境，以盛唐為準。
  • 「蘇李」：指蘇武、李陵；「曹劉」：指曹植、劉楨。二者常見於唐宋人評語。

十二、深究：風格成因與承襲關係

（一）時代、際遇與風格

作家時代與際遇對風格的影響
屈原楚地巫風與神話傳統；忠而見疏，兩度放逐。多神話意象與香草美人之喻。《史記》謂〈離騷〉「蓋自怨生」。
司馬遷因李陵事下獄受刑。《漢書》謂其「既陷極刑，幽而發憤」。列傳多為失意者立傳，筆端常帶感慨。
建安諸家漢末戰亂，文士集於鄴下。劉勰歸因於「世積亂離，風衰俗怨」，故詩文慷慨多氣。
阮籍、嵇康魏晉易代之際，司馬氏專權。阮籍避禍，詩旨隱晦；嵇康直言，終遭殺害。
陶淵明晉宋易代，門閥當道；數度出仕，終辭彭澤令。以田園為寄，語言平淡而內含感慨。
謝靈運出身高門；入宋後不得志，出為永嘉太守。肆意遊覽，以詩記遊，篇末多歸於說理。
鮑照、左思出身寒微，仕途受門第所限。多抒不平之氣。《詩品》謂鮑照「才秀人微」。
庾信梁亡後羈留北朝，位高而心懷故國。由早年宮體之綺豔，轉為晚年之蒼涼。
李白盛唐國力鼎盛；兼受道家、遊俠風氣影響；供奉翰林後離京漫遊。自信奔放，多寫理想與自由。
杜甫以儒者自期；親歷安史之亂，晚年漂泊西南。關懷時事民生，風格沉鬱，世號「詩史」。
柳宗元、劉禹錫永貞革新失敗，長期貶謫。柳宗元以山水、寓言寄憤；劉禹錫多豪健不屈之語。
白居易前期任左拾遺，後貶江州司馬。前期多諷諭詩；貶後閒適、感傷之作增多。
李賀、李商隱李賀因避父諱不得應進士試；李商隱身陷牛李黨爭。李賀詩奇詭；李商隱詩隱晦，多不明言本事。

深究：貶謫與文學。韓愈〈柳子厚墓誌銘〉：「然子厚斥不久，窮不極，雖有出於人，其文學辭章，必不能自力以致必傳於後如今，無疑也。」意謂柳宗元的文學成就得力於長期貶謫。此說與司馬遷「發憤著書」、韓愈「不平則鳴」同屬一脈，後為歐陽脩「窮而後工」之說所承（見 G9）。

（二）承襲關係

  • 辭賦：楚辭 → 賈誼騷體賦 → 枚乘〈七發〉 → 司馬相如大賦 → 揚雄、班固、張衡 → 張衡〈歸田賦〉轉為抒情小賦。《文心雕龍・辨騷》：「枚賈追風以入麗，馬揚沿波而得奇，其衣被詞人，非一代也。」
  • 史傳與古文：《史記》的散體敘事為韓愈、柳宗元古文所取法；傳記手法又為唐傳奇所承。
  • 田園山水：陶淵明、謝靈運 → 謝朓 → 王維、孟浩然 → 韋應物、柳宗元。
  • 七言歌行：曹丕〈燕歌行〉 → 鮑照〈擬行路難〉 → 盧照鄰、駱賓王 → 李白、高適、岑參 → 白居易、元稹的長篇敘事歌行。
  • 復古與興寄：建安風骨 → 陳子昂〈感遇〉 → 張九齡〈感遇〉 → 李白、杜甫。
  • 寫實與諷諭：漢樂府 → 建安樂府 → 杜甫「三吏」「三別」 → 元稹、白居易、張籍的新樂府。
  • 杜甫之後：韓愈承其奇險與鋪敘，發展為以文為詩；白居易承其寫實；李商隱承其七言律詩的精工。
  • 奇詭與綺麗：楚辭 → 李賀 → 李商隱 → 宋初西崑體；溫庭筠 → 花間詞 → 宋代婉約詞。
  • 山水散文：酈道元《水經注》 → 柳宗元「永州八記」。
  • 小說：《搜神記》《世說新語》 → 唐傳奇（〈鶯鶯傳〉〈李娃傳〉） → 元雜劇（《西廂記》）。

深究：《詩品》的源流說。鍾嶸將五言詩人分別溯源於《國風》《小雅》《楚辭》三系，所述如下：

  • 《國風》 → 曹植 → 陸機 → 顏延之；曹植 → 謝靈運。
  • 《國風》 → 古詩 → 劉楨 → 左思。
  • 《楚辭》 → 李陵 → 王粲 → 潘岳、張協；李陵 → 曹丕。
  • 《小雅》 → 阮籍。
  • 陶淵明：「其源出於應璩，又協左思風力。」

此說為後世所爭議，然可見南朝人以曹植為五言詩正宗、以陶淵明為旁支的看法。

深究：陶淵明地位的變化。《文心雕龍》論歷代作家，幾未及陶淵明；《詩品》列於中品。入唐後，王維、孟浩然、韋應物、白居易等人始多效法。至北宋，蘇軾謂其詩「質而實綺，臞而實腴」，推為曹、劉、鮑、謝、李、杜所不及，陶淵明遂居第一流詩人之列。

十三、深究：爭議與異說

  • 屈原作品的歸屬：〈招魂〉，司馬遷歸於屈原，東漢王逸《楚辭章句》歸於宋玉。〈卜居〉〈漁父〉，王逸題為屈原作，後世多以為楚人追記之辭。
  • 李陵詩：《詩品》以李陵為五言詩之始；題為蘇武、李陵的五言詩，後世多以為東漢以後人所擬。
  • 〈後出師表〉：不見於陳壽《三國志》正文，出自裴松之注所引，真偽歷來有爭議。
  • 〈七步詩〉：不見於曹植本集，出自《世說新語・文學》，原為六句；通行的四句本為後出。
  • 〈洛神賦〉本事：舊說為感念甄后而作（「感甄」說），後世學者多不採信。
  • 陶淵明的名與字：本書從《晉書・隱逸傳》作「名潛，字元亮」；《宋書・隱逸傳》作「字淵明，或云淵明字元亮」，蕭統〈陶淵明傳〉作「字元亮，或云潛字淵明」，諸說並存。
  • 《詩品》的品第：曹操列下品，陶淵明、鮑照、謝朓列中品，後世多以為偏低；其標準偏重辭采。
  • 李白的出生地：有蜀中、西域等說，尚無定論。
  • 王昌齡的稱號：有「詩家天子」「詩家夫子」二說；《唐才子傳》作「詩家夫子王江寧」。
  • 〈陋室銘〉的作者：通行題為劉禹錫作，然不見於其本集，另有唐人崔沔作之說。
  • 「八代」所指：蘇軾「文起八代之衰」的「八代」，通說指東漢、魏、晉、宋、齊、梁、陳、隋。

炯與王勃、盧照鄰、駱賓王以文詞齊名，海內稱為王楊盧駱，亦號為「四傑」。炯聞之，謂人曰：「吾愧在盧前，恥居王後。」當時議者，亦以為然。其後崔融、李嶠、張說俱重四傑之文。崔融曰：「王勃文章宏逸，有絕塵之跡，固非常流所及。炯與照鄰可以企之，盈川之言信矣！」說曰：「楊盈川文思如懸河注水，酌之不竭，既優於盧，亦不減王。『恥居王後』，信然；『愧在盧前』，謙也。」《舊唐書・文苑傳・楊炯》。G8-26 依此文作答。
