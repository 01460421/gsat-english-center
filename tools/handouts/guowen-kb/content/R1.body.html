（四）取材與命題方向

  • 取材範圍：符合普通高中學生程度、對應國文教材內容的古今各類文本；兼顧文言文與白話文，文言文取材比率參酌課綱必修課程的教材編選原則（文言文課數比率三年平均 35%至 45%）。
  • 教材選文依選錄版本數分三類：四至五家版本共同選文為 A 類，二至三家為 B 類，一家為 C 類。各類試題的總占分比率，原則上 B 類不高於教材選文試題的 40%，C 類不高於 10%；A 類不受此限。
  • 命題重點：字詞與語法知識（含六書基本原則、詞性、句型）、文學知識、文本涵義（文句的邏輯與意義、篇章的主旨與結構）、寫作手法、文化內涵。
  • 語法題多於題幹舉例說明測驗方向，避免直接使用文法術語；表現手法題亦不只列修辭格術語，而以舉例與說明引導作答。作答時須依題幹的定義判斷，不宜只憑術語記憶。
  • 考試說明表示不宜規定出自教材選文試題的占分比率；試題取材涵蓋古典、現代各文類與跨領域文本，不以教材選文為限。

考試說明指出，混合題「順著閱讀歷程」命題：選擇題引導考生掌握文本脈絡，檢測檢索與理解；非選擇題要求以精簡文字寫出理解、分析或推理的結果，檢測統整與解釋。其能力層次可整理如下：

層次能力常見設問多用題型

二、作答流程、順序與時間分配

（一）通用解題流程

  1. 圈題幹：標出限定語（依據上文、最適當、不正確、皆、前後相同）與設問對象（作者的看法、文中人物的心態、某段的作用）。
  2. 判題型：知識題（不必讀長文，可直接判斷）、文本題（答案須回原文找依據）、綜合題（知識與文本並用）。
  3. 回原文定位：以選項中的關鍵詞回原文找對應句，標出句子位置。
  4. 逐項比對：比對主語、範圍、程度、因果方向、時間、出處六項；任一項不合即錯。
  5. 複核：反向檢查答案是否回應題幹；單選題檢查是否有兩個看似可選的選項，若有，以「最適當」再比一次。

（三）作答順序的原則

  1. 開考後先翻閱全卷：確認頁數、混合題位置、題組的文本長度與題數。
  2. 依序作答為原則；知識題（字音、字形、字義、成語、國學常識）宜速答，不宜反覆猶豫。
  3. 單題思考超過約兩分鐘仍無把握者，在試題本上標記，先作答後面的題目，最後回頭處理。
  4. 混合題的非選擇題須先在試題本空白處擬稿、計算字數，再謄寫到答題卷；答題卷不得增補，謄寫錯誤只能以修正帶處理。
  5. 跨頁的題組，先讀題幹再讀文本；題組各小題多依文本段落順序排列，可據此分段閱讀、分段作答。

三、各類題目解法

（一）字音題

考點：判斷「」內字讀音前後相同或不同；由注音判斷字；多音字依義定音。素材多為偏旁相同或形體相近的字。詳細字表見 Z1。

  1. 分類：同偏旁異讀（聲符誤導）、形近字、多音字、特殊讀音（人名、地名、通假）。
  2. 多音字先判詞義與詞性，再定讀音，不憑熟悉的讀法直接作答。
  3. 逐字標出注音（聲母、韻母、聲調三者分開核對），最後再比較；聲調不同即為讀音不同。
  4. 無把握的字，以所在詞語回想完整讀法（如「躋身」「蹊蹺」），避免單字孤立判斷。
檢核項目判斷要點
聲符誤導形聲字聲符與全字讀音不同者多（如 酗、莘、恪），不可「有邊讀邊」；形近字（如 贗／膺）亦不可互推
聲調聲母、韻母相同而聲調不同（如 躋ㄐㄧ／擠ㄐㄧˇ），仍判為不同
多音字依義定音（如「否極泰來」的否讀ㄆㄧˇ）
辭典兩讀辭典兩讀皆收者不可判為錯讀；依題目語境選讀

示範題　下列各組「」內的字，讀音相同的是：

(A) 「莘」莘學子／「辛」勤耕耘(B) 「酗」酒滋事／波濤「洶」湧(C) 「贗」品充斥／「膺」選代表(D) 「靦」腆不安／「緬」懷先人

解題步驟：

  1. 逐字標音：莘ㄕㄣ、辛ㄒㄧㄣ；酗ㄒㄩˋ、洶ㄒㄩㄥ；贗ㄧㄢˋ、膺ㄧㄥ；靦ㄇㄧㄢˇ、緬ㄇㄧㄢˇ。
  2. 比較聲母、韻母、聲調：(D) 三者皆同。
  3. 答案 (D)。(A)(B)(C) 皆為聲符或形近字誤導：莘不讀辛，酗不讀凶，贗不讀膺。

（二）字形題

考點：判斷文句有無錯別字；空格填字；由注音判斷字形。素材多為音近或形近、日常常誤用的字。易錯字整理見 Z2、N12，成語寫法見 N6。

  1. 逐字讀過，不以詞為單位略讀；成語、四字語特別放慢。
  2. 可疑字以「字義」驗證：該字的意義能否解釋所在詞語（如「再接再厲」的厲為「磨利」，作勵則義不可通）。
  3. 同音字以「詞源」驗證：回想成語出處或構詞（如「墨守成規」源於墨子善守）。
  4. 「完全沒有錯別字」題，找到一個錯字即可刪去該選項，不必續讀；四個選項皆有疑處時，以把握最大的錯誤先刪。
檢核項目判斷要點
同音替代步／部、急／及、勵／厲、糜／靡等同音或音近字
形近替代偏旁相近而義別（如 賭／睹、辨／辯）
異體與兩收教育部辭典「也作」所收寫法不可判錯（如 琳瑯滿目／琳琅滿目）
語境同一詞在不同語境可用不同字（如 反映／反應），依句意判斷

示範題　下列文句，完全沒有錯別字的是：

(A) 他行事墨守成規，遇到新狀況總不肯變通(B) 球隊雖然輸了一場，選手們仍決定再接再勵(C) 放學鐘聲一響，孩子們迫不急待地衝出教室(D) 事情的始末，他在報告中交代得鉅細糜遺

解題步驟：

  1. (B)「再接再勵」：厲指磨利，勵字不合，應作「厲」。
  2. (C)「迫不急待」：及指趕上、來得及，應作「及」。
  3. (D)「鉅細糜遺」：靡指無、沒有，應作「靡」。
  4. 答案 (A)。「墨守成規」寫法正確，且與「不肯變通」語意相合。

（三）字義題

考點：同一字在不同文句中的意義異同；古今字義差異；部首與字義的關係。題目原則上提供完整語境。字義表見 Z3，古今異義與通同字見 Z4，虛詞見 F1。

  1. 先判詞性：「」內字在句中作動詞、名詞、副詞或虛詞，詞性不同者意義必不同。
  2. 代入候選義項，以通順與否驗證；可用現代複合詞聯想（去＝離去、顧＝回顧或反而）。
  3. 留意對文：對偶、排比句中位置相同的字，意義多相同或相反（「去國懷鄉」中，去與懷相對，皆為動詞）。
  4. 出處熟悉的句子，回想整句語譯，不只看單字。
檢核項目判斷要點
詞性同一字可兼動詞與副詞（如 卒：死亡，動詞／終於，副詞）
通同字本字讀不通時，考慮通假（信通伸、卒通猝）
古今異義不以現代詞義套用（如「無自信」不等於今語「沒有自信」）
語境範圍同一句中的字，以整句文意為準，不以單一詞組判斷

示範題　下列各組「」內的字，意義相同的是：

(A) 不「足」為外人道也／豐衣「足」食(B) 三「顧」臣於草廬之中／人之立志，「顧」不如蜀鄙之僧哉(C) 「卒」廷見相如／「卒」然臨之而不驚(D) 則有「去」國懷鄉／「去」以六月息者也

解題步驟：

  1. (A) 前者為「值得」（陶淵明〈桃花源記〉），後者為「充足」。
  2. (B) 前者為「拜訪」（諸葛亮〈出師表〉），後者為副詞「反而、難道」（彭端淑〈為學一首示子姪〉）。
  3. (C) 前者為副詞「終於」（《史記・廉頗藺相如列傳》），後者通「猝」，突然（蘇軾〈留侯論〉）。
  4. (D) 前者「去國」為離開國都（范仲淹〈岳陽樓記〉），後者為大鵬「離開」北冥（《莊子・逍遙遊》），皆為動詞「離開」。答案 (D)。

（四）詞語與成語運用題

考點：成語運用是否適切；成語填空；語詞意義與古今義；量詞；謙敬詞。成語誤用整理見 N6，謙敬詞與稱謂見 C1。

  1. 先確定成語本義與適用對象（人、事、物、建築、言論、罪狀）。
  2. 檢查褒貶：褒義成語用於負面語境，或貶義成語用於讚美者，判誤（如「始作俑者」為貶義）。
  3. 檢查搭配：主語與成語的適用對象是否相合（「美輪美奐」只用於建築）。
  4. 檢查前後文邏輯：成語意義與句中其他成分是否矛盾（「差強人意」為大致令人滿意，不可與「令人失望」連用）。
  5. 謙敬詞檢查方向：謙詞用於己方，敬詞用於對方；「惠存」「斧正」「拜讀」等詞的動作主體為何人。
檢核項目判斷要點示例
適用對象成語限定的對象美輪美奐（建築）、罄竹難書（罪狀）
褒貶感情色彩與語境一致始作俑者、炙手可熱不用於讚美
望文生義不依字面臆解差強人意、不刊之論、首當其衝
語意重複成語與前後詞語意義重疊「親眼目睹」類（見 N12）
謙敬方向謙己敬人拙作（己）、大作（人）；家父（己）、令尊（人）

示範題　下列文句「」內的成語，使用最適當的是：

(A) 這款新手機一上市便「炙手可熱」，門市前大排長龍(B) 舞者的肢體流暢優雅，整場表演「美輪美奐」(C) 颱風來襲，沿海低窪地區「首當其衝」，須提早撤離(D) 他的論點漏洞百出，堪稱「不刊之論」

解題步驟：

  1. (A) 炙手可熱比喻地位尊貴、勢燄熾盛，不用於商品暢銷。
  2. (B) 美輪美奐形容房屋華美，不用於表演。
  3. (D) 不刊之論指確鑿不移、不可磨滅的言論，與「漏洞百出」矛盾。
  4. (C) 首當其衝指最先受到攻擊或首先遭遇災難，與颱風語境相合。答案 (C)。

（五）語法與表述方式題

考點：詞性、句型、被動句、詞類活用、修辭與表述方式。此類題目多於題幹舉例或下定義，不直接使用術語。文言句式見 F2，修辭見 F3，詞性與複句見 F4。

  1. 先讀懂題幹的定義或示例，用自己的話寫出判斷標準（如「以物擬人＝物做出人的動作或具人的情感」）。
  2. 以題幹示例為模型，逐一比對選項的結構，不憑術語記憶判斷。
  3. 定義有多項條件者，逐項核對；只符合一部分者不選。

示範題　「轉化」中的擬人，是把物當作人來描寫，使物具有人的動作或情感。下列文句使用此手法的是：

(A) 傍晚時分，路燈一盞接一盞亮起(B) 老榕樹張開手臂，替整條街撐起一片陰涼(C) 他聽到消息，心像壓了一塊石頭(D) 雨下得好大好大，整條街都淹了水

解題步驟：依題幹定義，須「物＋人的動作或情感」。(B) 榕樹「張開手臂」「替整條街撐起」為人的動作，為擬人。(A) 為一般敘述。(C) 以石頭比喻心情，為譬喻。(D) 疊用「好大」，為類疊。答案 (B)。

（六）文句重組題

考點：將打散的文句依文意排出最適當的順序，文白皆有；文言排序多配合虛詞、對偶與論證層次。

  1. 定首尾：讀題目給定的首句與尾句，判斷各自須接的內容；首句後接者多承其主語或話題，尾句前多為結論或總括。
  2. 找銜接詞：代詞（此、這些、其、之）須在其指涉對象之後；關聯詞（因此、然而、於是、既……又）標示前後關係。
  3. 排時間與邏輯：時間詞（先、隨後、隔年）、因果、總分、由淺入深。
  4. 先組小塊：確定兩句必須相連者（如代詞與其先行詞），再以小塊對照選項刪除。
  5. 通讀驗證：將選出的順序連同首尾句讀一遍，檢查代詞指涉與話題是否一貫。
銜接手段判斷要點示例
指代代詞須在先行詞之後「這些溼地」前須已出現溼地
連接關聯詞決定前後關係「因此」前為原因；「然而」前後語意相反
詞彙重複相同或同義詞語相承上句末為「規則」，下句首為「這條規則」
時間順序時間詞與動作先後出發、到達、停留、離開
總分結構總說在前，分說在後；或反之「原因有二」之後接兩項原因

示範題　下列文句，依序排列最適當的是：
黑面琵鷺是候鳥，
甲、隔年春天，再陸續北返繁殖地
乙、每年秋季，自北方飛抵臺灣西南沿海
丙、度冬期間，多在河口與魚塭一帶覓食
丁、牠們離開之後，溼地的監測工作仍持續進行

(A) 乙丙甲丁(B) 乙甲丙丁(C) 丙乙甲丁(D) 乙丙丁甲

解題步驟：

  1. 時間詞依序為：每年秋季（乙）→ 度冬期間（丙）→ 隔年春天（甲）→ 離開之後（丁）。
  2. 代詞檢查：丁的「牠們離開」須在甲「北返」之後。
  3. 答案 (A)。(B) 北返後才度冬，時序顛倒；(C) 未飛抵即度冬；(D) 未北返即言離開之後。

（七）語意邏輯與關聯詞填空題

考點：依文意選填關聯詞或語詞；判斷文句前後是否連貫、關聯詞是否搭配。複句類型與關聯詞表見 F4。

  1. 判斷空格前後兩分句的關係：並列、遞進、轉折、因果、假設、條件、讓步、選擇。
  2. 核對關聯詞的固定搭配：雖然……但是、即使……也、只要……就、只有（唯有）……才、除非……才（否則）、與其……不如、不但……而且（反而）。
  3. 區分事實與假設：已發生的事用「雖然」，假設的情況用「即使」「縱使」。
  4. 區分充分條件與必要條件：「只要……就」為充分條件，「只有……才」為必要條件。
  5. 逐空代入後，以整段文意核對；任一空不合即刪去該選項。
關係常用關聯詞常見誤用
轉折雖然……但是、固然……但、然而「固然」後接「而且」
讓步（假設）即使……也、縱使……仍以「即使」陳述已發生的事實
充分條件只要……就「只要……才」
必要條件只有……才、唯有……才、除非……才「只有……就」「除非……就」
取捨與其……不如、寧可……也不「與其……還是」
遞進不但……而且、不但不……反而「不但……反而」用於同向遞進

示範題　依序填入下文＿＿＿處的詞語，最適當的是：
這項實驗的結果＿＿＿出乎預期，＿＿＿樣本數太少，＿＿＿不宜據以推論；＿＿＿擴大樣本後重複驗證，結論＿＿＿可靠。

(A) 雖然／但／因此／唯有／才(B) 因為／所以／但是／只要／就(C) 雖然／而且／所以／如果／便(D) 即使／但／因此／除非／就

解題步驟：

  1. 第一、二空：結果已出乎預期（事實），與樣本太少為轉折，用「雖然……但」。(D)「即使」用於假設，(B)「因為……所以」因果不通，(C)「而且」不表轉折。
  2. 第三空：樣本太少為不宜推論的原因，用「因此」。
  3. 第四、五空：擴大樣本為結論可靠的必要條件，用「唯有……才」。(D)「除非……就」搭配錯誤。
  4. 答案 (A)。

（八）國學常識題

考點：作家、作品、體類、流派；學術思想的學派歸屬；應用文、對聯、節令、典故等文化常識。命題以教材共同選文、文學史重要作品與生活常用者為主。經學見 G1，史學見 G2，諸子見 G3，韻文與散文流變見 G4–G7，作家見 G8–G10，文化常識見 G11，應用文見 C2。

  1. 將選項拆成「主體＋屬性」（作家＋朝代、作品＋體例、學派＋主張），逐一核對。
  2. 以「張冠李戴」與「時空錯置」為優先檢查方向：作者與作品是否錯配，朝代先後是否顛倒。
  3. 學派判斷抓核心概念：儒（仁、禮、性善或性惡）、道（無為、自然）、墨（兼愛、非攻）、法（法、術、勢）。
  4. 文段判斷學派時，找出關鍵詞後，再看整段論證方式是否相合，不以單一詞語斷定。
  5. 題辭與對聯依場合判斷：婚嫁、生子、壽慶、新居、開業、醫院、喪事各有專用語。
檢核項目判斷要點
作者與作品同時代、同流派作家的作品最易互換
朝代與先後「首創」「集大成」「繼之」等詞涉及先後，須核對
體例與類別史書體例（紀傳、編年、國別、紀事本末）；文體（表、說、記、序）
題辭場合題辭適用對象是否與情境相符

示範題　友人新居落成，下列題辭最適合致贈的是：

(A) 杏林春暖(B) 美輪美奐(C) 鴻案相莊(D) 弄璋之喜

解題步驟：依場合核對。(A) 杏林春暖用於醫界；(C) 鴻案相莊用於夫妻相敬，多用於結婚；(D) 弄璋之喜用於賀生男孩；(B) 美輪美奐形容房屋華美，適用於新居落成。答案 (B)。

（九）單篇文意題

考點：依據單篇文本判斷文句意義、段旨、主旨、作者觀點與態度、寫作手法。為國綜的主要題型，題材遍及古今各類文本。

  1. 先讀題幹：確認設問對象（作者、文中人物、某一句、全文主旨）。
  2. 讀文本並標記：論點句、轉折詞（然而、但、其實、事實上）後的句子、結論詞（因此、可見）後的句子、對比與例外。
  3. 定位：以選項關鍵詞回原文找對應段落。
  4. 比對六項：主語、範圍、程度、因果方向、時間、出處。
  5. 排除誘答：依本單元第四節的誘答類型逐一檢查。
檢核項目判斷要點
主語選項的主語是否為原文中的同一對象
範圍部分、多數、全部是否與原文一致
程度「可能」「往往」是否被改為「必定」「完全」
因果原文是否提出因果；方向是否一致
立場作者引述的他人觀點，不可當作作者本人主張

示範題　閱讀下文，回答問題。
編輯排版時，初學者常想把版面填滿，以為空白是浪費。然而適度的空白能讓讀者的視線有所停頓，也使標題與內文的層次分明；版面一旦塞滿，每一項資訊都在爭取注意，結果沒有一項能突出。
依據上文，作者認為版面留白的主要作用是：

(A) 減少印刷用墨，降低出版成本(B) 使視線有停頓之處，並區隔資訊的層次(C) 版面空白愈多，讀者閱讀效果愈好(D) 初學者應避免在版面上使用標題

解題步驟：

  1. 題幹限定「依據上文」「主要作用」。
  2. 定位：「然而」之後為作者觀點——視線停頓、層次分明。
  3. 答案 (B)。(A) 原文未提成本，為無中生有；(C) 原文言「適度」，改為「愈多愈好」為過度推論；(D) 原文提及標題，未主張避免使用，為偷換概念。

（十）題組

考點：同一文本（或多則文本）下設二至數小題，分層測驗擷取、理解、推論與延伸。文言題組的閱讀方法見 R2，白話、現代詩與圖表題組見 R3。

  1. 先讀各小題題幹（不讀選項），標出每題要找的訊息。
  2. 讀文本時，在相關段落旁註記題號。
  3. 小題多依文本段落順序排列；前段的小題可先作答。
  4. 文末附注釋者，注釋多為解題關鍵，先讀注釋再讀全文。
  5. 主旨題放在最後作答，以前面各小題的理解為基礎。
  6. 各小題的選項互為參照：某小題選項中的正確敘述，可能提示其他小題的答案。
檢核項目判斷要點
題號分布小題是否依段落順序；跨段的小題留到最後
注釋注釋中的字義、人物、背景是否已用於判斷
出處說明篇末「改寫自」「節錄自」的作者與時代，可用於判斷背景
一致性各小題的答案彼此不矛盾

示範題　閱讀下文，回答 1–2 題。
某讀書會訂有兩條討論規則：一是發言前先複述前一位發言者的重點，確認無誤後才提出自己的看法；二是反對他人意見時，須指出文本中的依據。實行半年後，成員發現爭執減少了，討論的時間卻變長了。有人主張廢除第一條以節省時間，多數成員則認為，爭執減少正是因為誤解先被排除，寧可多花時間。
1. 依據上文，讀書會第一條規則的作用是：
2. 依據上文，多數成員保留第一條規則的理由是：

第 1 題選項：

(A) 縮短每次討論所需的時間(B) 確保回應前已正確理解他人的意見(C) 要求所有意見都須引用文本(D) 限制每位成員的發言次數

第 2 題選項：

(A) 規則實行後討論時間變短(B) 新成員不熟悉討論方式(C) 減少誤解比節省時間更重要(D) 第二條規則無法單獨實行

解題步驟：

  1. 先讀兩題題幹：第 1 題找規則一的作用，第 2 題找多數成員的理由。
  2. 第 1 題定位「發言前先複述……確認無誤」，答案 (B)。(A) 與「時間卻變長」相反；(C) 為第二條規則的內容，張冠李戴；(D) 無中生有。
  3. 第 2 題定位末句「誤解先被排除，寧可多花時間」，答案 (C)。(A) 與原文相反；(B)(D) 原文未提。

（十一）跨文本比較題

考點：比較兩則以上文本（古今對讀、同題異作、正反觀點、文本與圖表）的觀點、手法、情感異同。觀點異同表的作法另見 R3。

  1. 先各自讀懂：每則文本以一句話寫出主旨或立場。
  2. 列比較表：比較項目（主題、觀點、論據、手法、情感、時代背景）為列，甲、乙為欄。
  3. 判斷選項所述為「甲乙皆」「僅甲」「僅乙」或「皆非」；選項言「皆」「均」者，兩則都須符合。
  4. 注意兩文的「對話關係」：乙文是否引用、回應、反駁甲文。
  5. 古今對讀時，文言文先譯出關鍵句，再與白話文比較。
檢核項目判斷要點
共同點是否兩則都有原文依據
相異點差異是否為「相反」或僅為「側重不同」
錯置甲文的特點是否被說成乙文所有
時代古代文本不可套用現代概念

示範題　閱讀甲、乙二文，回答問題。
甲、子曰：「君子病無能焉，不病人之不己知也。」（《論語・衛靈公》）
乙、社群平臺把「被看見」換算成數字。按讚數高，未必代表作品好；按讚數低，也未必代表作品差。創作者若把注意力全放在數字上，便容易忘了追問自己究竟做得夠不夠好。
甲、乙二文共同的看法是：

(A) 他人的評價毫無參考價值(B) 應以充實自身能力為重，不必過度在意外界的認可(C) 不被他人所知，是君子最憂慮的事(D) 社群數字是衡量作品優劣最客觀的標準

解題步驟：

  1. 甲：病，憂慮。君子憂慮自己沒有能力，不憂慮別人不了解自己。乙：讚數不等於作品好壞，應追問自己是否做得夠好。
  2. 共同點：重自身能力，輕外界認可。答案 (B)。
  3. (A)「毫無」為絕對化，乙文只說「未必」；(C) 與甲文意思相反；(D) 與乙文意思相反。

（十二）圖表題

（十三）混合題的作答要領

考點：同一題組內，選擇題引導理解，非選擇題要求以精簡文字擷取、說明、統整或推論。非選擇題的形式有簡答、表格或圖表填寫、短文說明。

  1. 依字數限制：先看題末字數要求；「30 字以內」不可超出，「合計 30–40 字」宜落在範圍內；分項者各項分別計算。標點是否計入，以題目說明為準；連同標點計算仍不超出者最為穩妥。
  2. 摘取關鍵詞：答案以原文的核心詞語為骨幹（評分要點多由此訂定），再以自己的文字連成完整句子；不整句照抄長句。

  4. 引文佐證：題目要求「依據文本」「摘錄文句」時，照錄原文並加引號，摘句宜短；引文後以一句說明其與答案的關係。
  5. 主語明確：句首寫出主語（作者、甲文、某人物），避免只寫「因為……」。

  1. 選項與原文字面重疊愈多，愈須核對「改動之處」；誘答選項常保留原文大部分字詞，只改一個程度詞、一個主語或一個因果方向。
  2. 原文的保留語（往往、多半、可能、部分、未必、似乎）被刪去或改強者，多為絕對化或過度推論。
  3. 原文中出現兩種以上的因素（如晨讀與圖書館同時發生）時，選項若只歸因於其中一項，多為相關誤為因果或過度推論。

深究　誘答類型的邏輯基礎

  • 全稱與特稱：「所有 A 都是 B」須每一個 A 都符合；原文為「部分 A 是 B」或「A 平均而言較 B」時，不能推出全稱命題。絕對化用語與以偏概全皆屬此類。
  • 條件命題：「若 A 則 B」成立時，其逆命題「若 B 則 A」與否命題「若非 A 則非 B」不必然成立；與之等價的只有逆否命題「若非 B 則非 A」。選項把「凡運動多者皆睡眠好」改成「凡睡眠好者皆運動多」，即以逆命題代替原命題。
  • 條件比例（進階）：「甲組中具某特性者占七成」不能換算為「具（或不具）該特性者中屬甲組者占多數」；兩種比例的分母不同，須知各組人數方能換算（見測驗 R1-09）。
  • 相關與因果：兩項數據同時變化僅表示相關；可能是第三因素同時影響兩者（干擾因素），或因果方向相反。圖表題與研究報導題最常據此設計誘答，R3 稱「相關誤為因果」「因果倒置」。
  • 充分條件與必要條件：「只要 A 就 B」表示 A 足以導致 B；「只有 A 才 B」表示無 A 則無 B。兩者混用為關聯詞題與文意題的共同陷阱（見 F4）。
  • 模糊限制語：原文中「可能、往往、在某些情況下」一類詞語用以限定斷言的強度；選項若刪去限定，命題強度改變，即與原文不符。

五、多選題的逐項判斷法

考點：多選題各選項獨立判定，每一選項無論劃記與否皆計入判定：未劃記即視為判為「不正確」。正確選項可能只有一個，也可能五個皆是。

（一）計分換算（以五選項為例）

1五分之三多劃一個或少劃一個，皆算答錯一個
2五分之一

（二）判斷步驟

  1. 逐項判斷：每一選項視為一道是非題，各自回原文或知識核對，不與其他選項比較。
  2. 記號標示：在試題本上標示「○（確定正確）」「×（確定錯誤）」「△（無把握）」；△須再寫出傾向（△○或△×）。
  3. 先定確定項：確定項先劃記；△項再回原文找證據，找到即改為○或×。
  4. 證據不足時：依可能性較高的一方判定；未劃記即判為錯誤，與劃記同樣承擔判斷錯誤的風險。
  5. 不以數量臆測：不預設「答案通常二至三個」；全部正確或只有一個正確者，都依判斷結果劃記。
  6. 最後核對：劃記與試題本記號一一對照。

深究　為何整題空白無益

依計分規定，得分低於零者以零分計，而全未作答亦為零分；因此對一道多選題而言，作答所得最低為零，與空白相同。就單一選項而言，判斷錯誤扣去該題五分之二的分數，劃記與不劃記的風險相同，故應依判斷正確的可能性較高的一方作答，不以「少劃較保險」為原則。以直覺猜測與依證據判定的差別，在於後者能提高每一選項判斷正確的機率。

（三）多選題常見陷阱

  • 五個選項中，常有一至二項只錯一個字詞（主語、程度、朝代），須逐字核對。
  • 字音、字形、字義多選題，一個選項內常有兩處待判斷，兩處都須符合題幹要求。
  • 文意多選題的錯誤選項，常是「原文另一段的內容」或「常識上正確而原文未提」。
  • 國學常識多選題常以「首創」「集大成」「第一部」等詞設陷阱。

「明天白天降雨機率七成」，常被理解為「七成的地區會下雨」或「白天有七成的時間在下雨」。依中央氣象署的定義，在預報時段內，預報區域內測得 0.1 毫米以上的雨量，就算下雨；降雨機率指的是出現這種降雨的可能性。換言之，七成可理解為：在類似的天氣條件下，十次之中約有七次會下雨。它不說明雨下多久，也不說明雨下多大。
另一方面，降雨機率低，也不保證不會下大雨。午後雷陣雨範圍小、發生地點難以事先確定，預報的機率有時只有兩三成，但一旦發生，短時間內的雨量可能相當可觀。因此，判斷是否帶傘，宜一併參考雨量預報與降雨可能發生的時段。
