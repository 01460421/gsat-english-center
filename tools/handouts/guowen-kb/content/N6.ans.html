N6　成語（易誤用、易寫錯）

N6-01 股 → 鼓（一鼓作氣） 作戰時擊第一通鼓，士氣最盛。
N6-02 勵 → 厲（再接再厲） 厲：同「礪」，磨利；非「鼓勵」的「勵」。
N6-03 急 → 及（迫不及待） 及：來得及。指急得來不及等待。
N6-04 矛 → 茅（名列前茅） 前茅：古代行軍時，前哨用作旗號的茅草。
N6-05 熄 → 息（川流不息） 息：停止。如河水流動不止。
N6-06 斧 → 釜（破釜沉舟） 釜：鍋子。打破鍋、鑿沉船，不留退路。
N6-07 愁 → 籌（一籌莫展） 籌：計策。指一個辦法也想不出。
N6-08 芋 → 竽（濫竽充數） 竽：吹奏樂器，竹字頭。
N6-09 拙 → 絀（相形見絀） 絀：不足、短缺。
N6-10 茶 → 荼（如火如荼） 荼：茅草開的白花；較「茶」多一橫。
N6-11 嘎 → 戛（戛然而止） 戛然：突然停止的樣子。
N6-12 復 → 愎（剛愎自用） 愎：任性、固執，心字旁。
N6-13 及 → 幾（一蹴可幾） 幾，音ㄐㄧ，接近、達到。也說「一蹴而就」。
N6-14 默 → 墨（墨守成規） 墨：指墨翟（墨子），善於守城。
N6-15 利 → 厲（變本加厲） 厲：猛烈。指情況變得更嚴重。
N6-16 夾 → 浹（汗流浹背） 浹：溼透，水字旁。
N6-17 沿 → 緣（緣木求魚） 緣：攀爬。指爬到樹上捉魚。
N6-18 指 → 趾（趾高氣揚） 趾：腳。走路時把腳抬得很高。
N6-19 嬌 → 矯（矯揉造作） 矯揉：故意做作；「嬌」生慣養作「嬌」。
N6-20 緻 → 致（淋漓盡致） 致：旨趣。指把意思表達得透澈；不作「緻」，也不作「至」。
N6-21 錯誤。 「首當其衝」指最先受到攻擊或遭遇災難，非「帶頭」之意。可改為：新任班長以身作則，每天第一個到教室開門。
N6-22 錯誤。 「差強人意」指大致還能讓人滿意，與後半句矛盾。可改為：這家店的牛肉麵令人失望，我以後不會再來了。
N6-23 錯誤。 句意為不在乎，應作「不以為意」；「不以為然」指不同意。可改為：他卻不以為意，頭也不抬地繼續打電動。
N6-24 錯誤。 「萬人空巷」形容擁擠熱鬧。可改為：連假過後的墾丁大街冷冷清清，路上一個人影也沒有。
N6-25 正確。 「不以為然」表示不同意。
N6-26 錯誤。 「無時無刻」須接「不」，才是「時時刻刻」之意。可改為：學長無時無刻不照顧我們；或：學長時時刻刻都很照顧我們。
N6-27 錯誤。 「罄竹難書」形容罪狀極多，貶義。可改為：這位志工阿姨三十年來做過的好事多得數不清。
N6-28 正確。 「不脛而走」指消息很快傳開。
N6-29 正確。 「美輪美奐」形容房屋高大華美，適用於建築物。
N6-30 錯誤。 「不恥下問」指向地位、學問不如自己的人請教，不適用於請教老師。可改為：我總是不怕丟臉，下課就去請教老師。
N6-31 錯誤。 「不知所云」用於批評說話者內容混亂空洞；此處聽不懂的原因在自己。可改為：我還是聽得一頭霧水。
N6-32 正確。 「安土重遷」指久居故鄉、不肯輕易搬遷。
N6-33 錯誤。 「曾幾何時」指「才過了多少時間」，非「曾經」之意。可改為：小學二年級時，我也養過一隻兔子。
N6-34 正確。 「綿薄之力」形容微小的力量，多用於謙稱自己的付出。
N6-35 錯誤。 「蠢蠢欲動」比喻意圖搗亂、為害，貶義。可改為：全班都興奮不已；或用「躍躍欲試」形容急著想嘗試。
