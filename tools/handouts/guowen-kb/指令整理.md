# 學測國文知識庫｜指令整理

本檔整理兩種「指令」：
**一、需求指令**：這套書是依哪些要求做出來的。可直接複製，下次製作其他科目或主題時沿用。
**二、操作指令**：如何在電腦上重新排版、修改內容、增加單元。

全套三冊：

| 冊別 | 書名 | 內容 |
| --- | --- | --- |
| 第一冊 | 語文基礎與國學常識 | 字音字形字義（Z1–Z4）、文法與修辭（F1–F4）、詞語與應用文（C1–C2）、國學常識（G1–G11） |
| 第二冊 | 古文解釋與閱讀 | 核心古文十五篇（W01–W15）、經典與詩詞選讀（W16–W22）、閱讀與題型（R1–R3） |
| 第三冊 | 寫作素材 | 國寫素材庫（N1–N12）與進階篇（N13–N19） |

| 3 | 國寫素材庫增廣成國文知識庫，包括所有的國文知識、古文解釋、字音字型……等等參考書有的資料 | 擴編為三冊 65 單元：字音字形、文法修辭、應用文、國學常識、古文二十二篇（原文、注釋、語譯）、閱讀題型、寫作素材 |

### 2. 可重複使用的完整指令（Prompt）

把下面整段貼上即可。〔 〕內換成自己的內容。

```text
請製作一套「〔學測國文知識庫〕」，分〔三〕冊，輸出為 A4 的 PDF。

【內容範圍】
- 對象：〔目標頂標與滿級分的高中生、資優班與科學班學生〕。
- 涵蓋參考書會有的全部內容：〔字音字形字義、文言實詞與古今異義、虛詞與句式、修辭、
  應用文、國學常識與文學史、核心古文（原文、注釋、語譯）、閱讀題型、寫作素材〕。
- 每個知識點寫三層：基礎（定義與整理表）、進階（易混辨析、例外、跨篇比較；為主體）、
  深究（文字學、聲韻、訓詁、語法的學理依據與學界不同說法）。
- 條目求全，冷僻者照收並標「（進階）」；例句除課本名句外，再補課外古文例句並標出處。
- 古文單元：課本通行本原文、逐段注釋、語譯，另有文本細讀、歷代評點、比較閱讀、爭議與異說。
- 每單元附測驗：基礎三成、進階五成、高難度兩成；多選四成以上；含課外文言題組；
  四選一答案平均分布；詳解逐一說明每個選項。

【查證】
- 字音、字形、字義以教育部《重編國語辭典修訂本》現行版為準；辭典兩讀併收者不列為誤讀。
- 古文原文逐字核對，採臺灣高中課本通行本；有異文者註「一作……」。
- 作者、年代、字號、出處、評語逐條上網查證並記下網址；查不到原文就改為不加引號的轉述，或不收。
- 不收歷屆試題原題、官方參考答案、評分原則與考生佳作；注釋與語譯自己撰寫，不抄課本與參考書。
- 正文不出現網站名稱，以版本稱之（如「《古文觀止》本」「通行本」）；網址只列在書末資料來源。
- 使用臺灣繁體中文與臺灣用語。

【全書統一】
- 列一張統一用字表（人名、書名、異文、詞性術語、通假字讀音體例），所有單元照表執行。

【文風】
- 參考書語體：條目化、客觀、精煉、有術語。不對讀者喊話，不寫導覽式開場，不替例句寫賞析，
  不用格言與對句，不用「不是……而是……」，不用比喻說理，不刻意湊三點，不口語。

【流程】
- 每個單元寫完後，由另一位審稿者獨立複查：重新上網核對、先自己做一遍測驗再對答案、
  檢查文風與深度；審稿直接改檔。全部單元審完後，再做一次全書統一用字的總檢查。

【版面】
- 全書字體「芫荽（Iansui）」；像畫過重點的筆記：螢光筆、紅色波浪線、重點整理框、
  便利貼樣式的延伸補充、紅色虛線的易錯提醒；各部不同代表色。
- 古文原文用原文框、注釋分兩欄、語譯用語譯框。
- 每冊都要有：封面、編輯說明、使用說明、可點選且有頁碼的目錄、各部章名頁與單元總覽、
  解答篇、書末附錄（答案速查、細目索引、資料來源）。

【交付】
- 各冊 PDF；一份「指令整理.md」；可重新排版的原始檔。
```

## 二、操作指令

### 0. 專案結構

```
guowen/
├── content/        各單元內容檔（Z1.body.html、Z1.ans.html …）← 要改內容就改這裡
├── sources/        各單元查證過的網址（Z1.sources.json …）
├── build.mjs       內容檔 → PDF 的排版程式（分冊設定 VOLS、封面、編輯說明、目錄、附錄）
├── desc.json       各單元在總覽頁的一句話介紹
├── base.css        基礎樣式
├── theme.css       筆記版樣式（字體、顏色、螢光筆、筆記框、原文／注釋／語譯框）
├── join.py         把封面接到本文前面（保留目錄的超連結）
├── tools/check.py  檢查單一單元的格式
└── dist/           成品 PDF
```

### 1. 環境準備（只需一次）

需要 Node.js、Python 3（含 `pypdf`）與 poppler-utils（`pdftotext`、`pdfinfo`）。

```bash
cd guowen
```

```bash
npm install
```

```bash
npx playwright install chromium
```

```bash
pip3 install pypdf
```

macOS 安裝 poppler：

```bash
brew install poppler
```

### 2. 產生某一冊的 PDF

```bash
node build.mjs 1
```

- 參數 `1`、`2`、`3` 分別為第一、二、三冊。
- 會自動排版多次，回填目錄、總覽頁與細目索引的頁碼，直到頁碼不再變動；結尾顯示「頁數一致 ✓」即完成。
- 成品：`dist/學測國文知識庫_第一冊_語文基礎與國學常識.pdf` 等。

### 3. 只排某幾個單元（改稿時用）

```bash
python3 tools/check.py W05
```

檢查 W05 的內容檔：標籤與 class、題號與解答是否對得上。印出 `OK` 才算通過。

```bash
node build.mjs 2 W05,W06
```

只排第二冊的 W05、W06，輸出樣張（沒有封面、目錄與附錄）。

### 4. 修改內容

所有文字都在 `content/單元代號.body.html`（本文）與 `content/單元代號.ans.html`（解答）。最常用的寫法：

| 想做的事 | 寫法 |
| --- | --- |
| 黃色螢光筆 | `<strong>文字</strong>` |
| 紅色波浪線 | `<em>文字</em>` |
| 重點整理框 | `<div class="key"><p>…</p></div>` |
| 便利貼（延伸補充、深究） | `<div class="tip"><p>…</p></div>` |
| 紅色虛線框（易錯提醒） | `<div class="warn"><p>…</p></div>` |
| 古文原文（含注釋編號） | `<div class="orig"><p>……<sup>1</sup>……</p></div>` |
| 注釋（兩欄） | `<ol class="notes"><li><strong>詞</strong>：釋義。</li></ol>` |
| 語譯框 | `<div class="trans"><p>……</p></div>` |
| 表格 | `<table class="t"><thead><tr><th>欄1</th></tr></thead><tbody><tr><td>…</td></tr></tbody></table>` |

`orig` 裡的 `<sup>` 編號要和後面 `notes` 的條數一致，每段從 1 起。完整說明見 `kb-spec.md`。改完後依序執行第 3、第 2 節的指令。

### 5. 調整版面

| 想調整 | 修改位置 |
| --- | --- |
| 字體 | `theme.css` 最上方 `:root` 的 `--hand` |
| 螢光筆、紅筆、藍筆的顏色 | `theme.css` 的 `:root` |
| 各冊、各部的名稱與代表色 | `build.mjs` 的 `VOLS` |
| 原文、注釋、語譯框樣式 | `theme.css` 的 `.orig`、`.notes`、`.trans` |
| 封面文字 | `build.mjs` 的 `coverHtml()` |
| 編輯說明、使用說明 | `build.mjs` 的 `frontHtml()` |
| 總覽頁的單元介紹 | `desc.json` |
| 書末資料來源不列入的網站 | `build.mjs` 的 `sourcesHtml()` 內 `skip` |

### 6. 新增單元（例如 W23）

1. 依 `kb-spec.md`、`w-brief.md` 撰寫 `content/W23.body.html` 與 `content/W23.ans.html`，查證的網址記在 `sources/W23.sources.json`。
2. 在 `build.mjs` 的 `VOLS` 把 `'W23'` 加進要放的那一部，並在 `desc.json` 加一句介紹。
3. 執行第 3 節的檢查與樣張，再執行第 2 節。

### 7. 常見問題

| 狀況 | 處理 |
| --- | --- |
| `check.py` 顯示「不允許的 class」或「標籤不成對」 | 依訊息的行號修正 |
| 顯示「解答缺」「解答多出」 | 本文題號（`id="W05-01"`）與解答檔題號要一一對應 |
| 某個字顯示成不同字體 | 芫荽缺字，自動以霞鶩文楷補字，屬正常現象 |
| 個別罕用字（如「利格拉樂・阿𡠄」的𡠄）印不出來 | 所附字體都沒有這個字；可另裝含該字的字體（如花園明朝），加進 `theme.css` 的字體清單 |
| 結尾顯示「頁數不一致」 | 再執行一次 `node build.mjs 冊別` |
