# 《學測國文知識庫》撰寫規格（每位撰稿人必讀）

## 這本書是什麼

一套印成 PDF 的學測國文全科參考書，由「學測英文中心」（本站）製作，給準備學測國文（國語文綜合能力測驗與國語文寫作能力測驗）的高中生用。站主的要求：把市面上國文參考書有的知識都整理進來——字音字形字義、文法修辭、詞語與應用文、國學常識、文學史、作家、文化常識、古文的原文注釋與語譯、閱讀與題型解法、寫作素材——條目清楚、查得到、內容正確。

## 蒐集與查證（最重要）

你有網路搜尋工具（先用 ToolSearch 載入 `select:WebSearch`；若有 WebFetch 也可以用）。請實際上網蒐集與查證，不要只憑記憶。學生會照著背，寫錯一個字音、一個作者、一個年代，就會被學起來。

1. **字音、字形、字義**：以教育部《重編國語辭典修訂本》《國語辭典簡編本》《成語典》《異體字字典》為準（dict.revised.moe.edu.tw、dict.concised.moe.edu.tw、dict.idioms.moe.edu.tw、dict.variants.moe.edu.tw；抓不到時可用萌典 moedict.tw，它收的是同一部辭典的資料）。字音用注音符號標示。辭典兩讀或兩種寫法都收的，不能當成錯誤，要寫明「辭典兩種都收」。
2. **古文原文**：逐字對過維基文庫（zh.wikisource.org）或中國哲學書電子化計劃（ctext.org），並採用臺灣高中課本通行的版本與標點；有異文的地方註明「一作……」。原文一個字都不能錯。
3. **注釋與語譯**：自己寫，不抄任何課本、參考書或網站的注釋與翻譯。注釋要解到字（哪個字是什麼意思、什麼詞性、怎麼活用），語譯要忠實、通順。
4. **國學常識、文學史、作家生平**：朝代、年代、字號、並稱、作品集名稱、文體歸屬、流派都要查證。各家說法不一的（例如生卒年、某些作品的作者），採臺灣高中課本通行的說法，必要時註明「一說」。不確定的不寫。
5. **現代作家與作品**：只寫可查證的事實（筆名、籍貫、代表作、風格、文學地位）。引用作品原文每句不超過 40 個字，同一位作者在一個單元最多引 3 句；不引歌詞；不整段轉載仍有著作權的作品。
6. **記下來源**：把你用到的主要網頁記在 `/tmp/claude-0/zhw/work/單元代號.sources.json`，格式 `[{"item": "條目或段落名稱", "url": "網址", "note": "查了什麼"}]`，至少 15 筆。
7. **絕對不收**：歷屆試題的整題原文、官方參考答案、評分原則、考生佳作；出版社課本或參考書的注釋、翻譯、題目。可以說「這個考點學測常考」，但題目一律自己出。

## 文風：參考書語體（必讀）

站主對初版的意見是「太有 AI 教學感」。請先完整讀 `/tmp/claude-0/zhw/style.md`，全書照那份規範寫。重點：

- 讀起來要像臺灣市售的國文參考書、資深國文老師編的講義：條目化、客觀、精煉、有術語。
- 說明文字不對讀者喊話（不用「你」「我們」「同學」、不用勸導的祈使句），不寫導覽式的開場白，不替例句寫賞析，不用格言與對句，不用「不是……而是……」，不用比喻說理，不湊三，不口語，不寫「本站」。
- 多用整理表、條列規則、辨析（甲與乙之別）、口訣；每條一句，寫明規則與例證。
- 固定用語：作用、適用、不宜、注意、句型、示例、辨析、補充、語譯、注釋、題解、主旨、段旨、寫作特色。

## 內容原則

1. **每一節都照「考什麼 → 規則或整理表 → 例子 → 自己做」**。先給規則或表格，再給例子（例句盡量用高中課本常見的古文與詩詞，並標出處），最後給小測驗。
2. **規則要能操作**：寫成學生考場上用得出來的判斷方法，例如「『之』在主語和謂語之間，取消句子獨立性，不譯」。不寫空泛的建議。
3. **整理表要完整而不灌水**：參考書會列的條目都要有，但每條說明精煉；罕見、不考的不收。
4. **小測驗**：題型比照學測（單選四選一、多選五選、題組），全部原創；每個單元照指派的題數出題。四選一的答案要平均分布；每題只有一個最佳答案（多選題每個選項都要能明確判斷對錯）。解答要說「為什麼」，並逐一說明錯的選項錯在哪裡。
5. **中文**：繁體中文、臺灣用語、全形標點；字詞寫法以教育部辭典為準（裡、臺灣、汙染）。書名用《》，篇名用〈〉，書名與篇名之間的間隔號用「・」（例如《論語・學而》）。
6. **不可以寫的東西**：不提 AI、模型；不寫「大考中心」（寫「學測」「歷屆試題」即可）；不寫不確定的統計數字；內容適合未成年人；不評論當代政治人物與政黨。
7. **篇幅**：照指派的頁數寫。A4、內文約 10.5 級字，一頁大約 800–1,000 個中文字；表格一頁約 22–28 列。寧可精煉，不要灌水；也不要因為趕時間而明顯少於指派的篇幅。

## 格式：只寫 HTML 片段

不寫 `<html>`、`<head>`、`<style>`，不寫行內 style，不用 emoji，不用 Markdown。只用下面這些標籤與 class（排版時會自動套上顏色、螢光筆與筆記框）：

- 單元外框：`<section class="unit" id="單元代號">…</section>`
- 標題：`<h2>`（一個單元只有一個，開頭寫單元代號，例如 `<h2>F1　文言虛詞</h2>`）、`<h3>`（節）、`<h4>`（小節）。
- 段落與清單：`<p>`、`<ul>`、`<ol>`、`<li>`。
- `<strong>…</strong>`：重點詞，排出來是**黃色螢光筆**。只標真正的關鍵詞，一段最多兩三處。
- `<em>…</em>`：容易弄錯、要特別注意的地方，排出來是**紅色波浪線**。
- 獨立的例句或引文：`<p class="eg"><span class="en">句子本身</span><span class="zh">出處、語譯或說明</span></p>`。
- 框：`<div class="key">…</div>`（重點整理：規則、步驟、口訣）、`<div class="tip">…</div>`（延伸補充：相關知識、辨析、記憶法）、`<div class="warn">…</div>`（易錯提醒：常見誤判）。
- 錯誤與正確對照：`<p class="bad"><span class="mark">誤</span>…</p>`、`<p class="good"><span class="mark">正</span>…</p>`。
- 表格：`<table class="t"><thead><tr><th>…</th></tr></thead><tbody><tr><td>…</td></tr></tbody></table>`，不超過 5 欄。
- **古文原文**（只有 W 單元和需要整段引原文的地方用）：
  - 原文段落：`<div class="orig"><p>原文……若<strong>舍</strong><sup>1</sup>鄭以為<em>東道主</em><sup>2</sup>……</p></div>`。注釋編號用 `<sup>`；原文裡的重要字詞用 `<strong>`（螢光筆），易考、易錯的用 `<em>`（波浪線），像在課本上畫重點。
  - 注釋：`<ol class="notes"><li><strong>舍</strong>：通「捨」，放棄。動詞。</li>…</ol>`，編號要和原文的 `<sup>` 對得上，每段原文後面接它自己的注釋，編號每段從 1 開始。
  - 語譯：`<div class="trans"><p>白話語譯……</p></div>`。
- 一組測驗的開頭：`<h4 class="exset">小測驗　單選題（6 題）</h4>`。
- 測驗題（編號用你的單元代號加流水號，例如 F1-01；W 單元寫成 W03-01）：

  ```html
  <div class="ex" id="F1-01"><span class="exid">F1-01</span>下列文句中的「之」，用法與其他三者不同的是：
  <div class="opts"><span>(A) ……</span><span>(B) ……</span><span>(C) ……</span><span>(D) ……</span></div></div>
  ```

  多選題在題幹最後註明「（多選）」，選項 (A)–(E)。需要學生寫字的題目，在題目後面加 `<div class="lines" data-n="1"></div>`（行數 1 或 2）。
- 自我檢核表（每個單元最後放一個）：`<ul class="check"><li>…</li></ul>`。
- 解答檔（另一個檔案）：

  ```html
  <section class="ans-unit" id="ans-F1"><h3>F1　文言虛詞</h3>
    <div class="ans"><span class="exid">F1-01</span> (B) <span class="why">(B) 的「之」是動詞「往」；其餘都是結構助詞「的」。</span></div>
  </section>
  ```

  選擇題答案一律寫成題號後面接 `(B)`；多選寫成 `(A)(C)(E)`。
