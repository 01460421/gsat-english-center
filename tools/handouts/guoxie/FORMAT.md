# 國寫素材庫｜內容檔格式與品質規範

每個單元有兩個檔案，放在 `content/`：

- `單元代號.body.html`：本文
- `單元代號.ans.html`：解答（沒有練習的單元寫一個空的 `<section class="ans-unit" id="ans-單元代號"></section>`）

各單元查證過的網頁記在 `sources/單元代號.sources.json`，格式是
`[{"item": "條目或段落名稱", "url": "網址", "note": "查了什麼"}]`。

## 1. 只寫 HTML 片段

不寫 `<html>`、`<head>`、`<style>`，不寫行內 style，不用 emoji。只用下面這些標籤與 class；排版時會自動套上顏色、螢光筆與筆記框。

| 想做的事 | 寫法 | 排出來的樣子 |
| --- | --- | --- |
| 單元外框 | `<section class="unit" id="N5">…</section>` | 每個單元從新的一頁開始 |
| 單元標題 | `<h2>N5　成語（主題分類）</h2>`（開頭寫單元代號） | 題頭：代號色塊、標題、所屬的部 |
| 節、小節 | `<h3>`、`<h4>` | 節標題有底色螢光筆；節會自動進入書末的細目索引 |
| 重點詞 | `<strong>…</strong>` | 黃色螢光筆 |
| 提醒注意 | `<em>…</em>` | 紅色波浪線 |
| 示範句或引文 | `<p class="eg"><span class="en">句子</span><span class="zh">出處或說明</span></p>` | 左側色條；說明是藍色小字 |
| 重點整理 | `<div class="key">…</div>` | 白底色框 |
| 延伸補充 | `<div class="tip">…</div>` | 黃色便利貼 |
| 易錯提醒 | `<div class="warn">…</div>` | 紅色虛線框 |
| 誤／正對照 | `<p class="bad"><span class="mark">誤</span>…</p>`、`<p class="good"><span class="mark">正</span>…</p>` | 紅圈「誤」、綠圈「正」 |
| 表格 | `<table class="t"><thead><tr><th>…</th></tr></thead><tbody><tr><td>…</td></tr></tbody></table>` | 表頭是該部的代表色；不超過 4 欄 |
| 一組練習的開頭 | `<h4 class="exset">練習 A　選出最恰當的成語（10 題）</h4>` | 色帶標題 |
| 練習題 | `<div class="ex" id="N5-01"><span class="exid">N5-01</span>題目…</div>` | 題號是圓角標籤 |
| 選擇題選項 | 題目後加 `<div class="opts"><span>(A) …</span><span>(B) …</span>…</div>` | 依選項長度自動排成一列、兩列或直排 |
| 作答格線 | 題目後加 `<div class="lines" data-n="2"></div>`（行數 1 或 2） | 橫線 |
| 自我檢核表 | `<ul class="check"><li>…</li></ul>` | 綠框、每項前有方格 |

解答檔：

```html
<section class="ans-unit" id="ans-N5"><h3>N5　成語（主題分類）</h3>
  <div class="ans"><span class="exid">N5-01</span> (B) 韋編三絕 <span class="why">說明……</span></div>
</section>
```

選擇題的答案寫成 `(B)`，接在題號後面，書末的「選擇題答案速查」會自動抓到。

## 2. 查證規則

1. **成語**：寫法、釋義、出處以教育部《成語典》與《重編國語辭典修訂本》為準。辭典沒有標明典源的，出處欄留空。
2. **古典名句與詩詞**：逐句對原文（維基文庫、教育部辭典等）；有異文的採臺灣高中課本與通行寫法，並註「一作……」。
3. **現代與外國名言**：只收查得到原書、原文或可靠出處的；查不到的不收。每句不超過 40 個字，要標作者與篇名或書名；同一位作者在一個單元最多引 3 句；不引歌詞。
4. **人物事例**：年代、事件、數字都要查證；不確定的細節不寫。
5. **不收**：歷屆試題的官方參考答案、評分原則與考生佳作；補習班或他人已發表的範文段落。
6. 解釋、白話翻譯、事例敘述都用自己的話重寫，不照抄網頁。

## 3. 寫作規則

文風照 `STYLE.md`（參考書語體）。

1. 示例句、示例段落、練習題都自己寫，要像文筆好的高中生：具體、有細節、語氣自然，不刻意在句尾反轉。
2. 每一類素材都要說明：適合知性題還是情意題、一篇用多少、常見的誤用。
3. 繁體中文、臺灣用語、全形標點；字詞寫法以教育部辭典為準（裡、臺灣、汙染）。
4. 書名與篇名的間隔號用「・」，篇名用〈〉，書名用《》。
5. 內容適合未成年人；不評論當代政治人物與政黨。
6. 四選一的答案要大致平均分布，每題只有一個最佳答案。

## 4. 檢查

```bash
python3 tools/check.py N5
```

會檢查：標籤與 class 是否在允許清單內、標籤是否成對、題號是否連續且和解答對得上、有沒有禁用字。印出 `OK` 才算通過。
