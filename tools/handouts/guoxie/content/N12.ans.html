N12　附錄：易錯字、標點、常見語病

N12-01 因 → 應（應該） 「應」義為應當；辭典查無「因該」。
N12-02 既 → 即（即使） 表假設用「即使」，義同「就算」；表已成立的事實用「既然」。
N12-03 燥 → 躁（急躁） 「躁」從「足」，指性急；「燥」從「火」，指乾（乾燥、枯燥）。
N12-04 晴 → 睛（眼睛） 「睛」從「目」，指眼睛；「晴」從「日」，指天氣。
N12-05 廢 → 費（浪費） 「費」指耗用；「廢」指停止不用（荒廢、廢棄）。
N12-06 厲 → 勵（鼓勵） 「勵」指勸勉；「厲」用於嚴厲、再接再厲。
N12-07 式 → 勢（姿勢） 指身體、動作呈現的樣子用「勢」；「式」指規格、方法（方式、形式）。
N12-08 憾 → 撼（震撼） 「撼」從「手」，指搖動；「憾」從「心」，指心中感到不圓滿（遺憾）。
N12-09 籍 → 藉（藉口） 「藉」指憑藉、假借；「籍」指書冊、登記（書籍、國籍）。辭典亦收「借口」。
N12-10 概 → 慨（感慨） 「慨」從「心」，指心有感觸；「概」從「木」，用於大概、氣概。
N12-11 祥 → 詳（安詳） 「安詳」指平靜、從容；「祥」指吉利（慈祥、吉祥）。
N12-12 響 → 嚮（嚮往） 「嚮」指內心傾向；「響」指聲音（影響）。
N12-13 待 → 代（交代） 囑咐、說明義作「交代」；辭典「交待」僅收接待義。
N12-14 彩 → 采（興高采烈） 「采」指神采、精神；「彩」指顏色。
N12-15 急 → 及（迫不及待） 「不及」指來不及：情況急迫，來不及等待。
N12-16 需 → 須（必須） 其後接動作「想辦法」，用「必須」；「必需」表一定要有某物（必需品）。
N12-17 應 → 映（反映） 呈現、傳達心聲用「反映」；「反應」指受刺激後的回應。
N12-18 漲 → 脹（膨脹） 體積變大用「脹」；水位、價格升高用「漲」。
N12-19 在 → 再（再接再厲） 「再」表又一次；「在」表位置或正在進行。
N12-20 的 → 得（美得讓人捨不得眨眼） 形容詞後接程度或結果，用「得」。
N12-21 參考：這次志工服務，讓我看見自己的幸運。 主詞不明。「透過……」與「讓……」並用，全句無主詞；可刪去「透過」，或改為「透過這次志工服務，我看見了自己的幸運」。
N12-22 參考：為了防止同樣的錯誤再發生，我把訂正過的題目抄在筆記本上。 否定失當。「防止」已含「不讓」義，再加「不」，語意變為希望錯誤繼續發生。
N12-23 參考：他成績進步，是因為每天固定複習。 句式雜糅。「……的原因是……」「是因為……」「是……的緣故」三種句式混用，擇一即可。
N12-24 參考：我們班在這次合唱比賽中，取得了很好的成績。 搭配不當。「發揮」與實力、水準搭配，「成績」與「取得」「得到」搭配；亦可改為「發揮了平常練習的實力」。
N12-25 參考：班長整理了大家的意見。 弱動詞。「進行了一個整理的動作」即「整理了」。
N12-26 參考：我很佩服他，也想成為像他那樣的人。 口語過多。刪去「然後」「就」「超……的」，並直接寫出「厲害」引起的感受。
N12-27 參考：我把那件外套忘在公車上，後來司機撿到，送回了學校。 「被」字濫用。三處「被」均可改為主動句。
N12-28 參考：阿凱對小宇說：「你的便當被人拿錯了。」 指代不明。原句的「他」可指阿凱，亦可指小宇。若指阿凱，可作「阿凱告訴小宇，自己的便當被人拿錯了」。
N12-29 參考：妹妹不但會彈鋼琴，還會拉小提琴。 關聯詞誤用（位置不當）。前後分句主詞同為「妹妹」，「不但」須置於主詞之後。
N12-30 參考：我昨天中午在福利社遇到國中的導師。 語序不當。時間詞語在前，處所詞語在後。
