# 文風規範：參考書語體

初版的說明文字太像教學口吻。這份規範說明問題在哪裡、要改成什麼樣子。全書所有說明文字都照這份規範寫。

## 目標

讀起來要像**臺灣市售的國文參考書、資深國文老師編的講義**：條目化、客觀、精煉、有術語，一眼能查到要的東西。不要像一位熱心的家教在旁邊一句一句叮嚀，也不要像一篇勸學的散文。

## 問題清單（初版裡大量出現，全部要改掉）

1. **對讀者喊話**：用「你」「我們」「同學」，或用勸導的祈使句。
   例如「讀的時候請拿筆」「下筆前先問自己三件事」「考場上請換成你自己的經驗」「想用之前請自己再查一次」。
2. **導覽式的開場白**：單元開頭先介紹「這個單元整理了……每一則都有四樣東西……」。
3. **替自己的例句寫賞析**：每個示例後面都接一句說它好在哪裡。
   例如「沒有說『我很想滑手機』，讓手機自己演。」「便當就不只是便當。」「意思藏在落差裡。」
4. **格言與對句**：用漂亮的對稱句下結論。
   例如「成語負責下判斷，細節負責讓人相信這個判斷。」「人物事例是配角。」「名言不等於論證。」「寫錯比不寫更傷。」
5. **「不是……而是……」與同類句式**：「仿寫不是抄句子，是……」「問題不在句子，而在……」「……才算完成」「……等於什麼都沒寫」「……永遠是最好的例子」。
6. **比喻式說理**：用比喻解釋概念，例如「成語是壓縮過的判斷」「把好句子拆開來，看它的骨架怎麼搭，再用自己的材料重蓋一次」。
7. **湊三**：「三個原則」「三步用法」「三種情形不要用」「三種安全的寫法」一再出現。條目數應該由內容決定。
8. **同一套寫作觀念反覆講**：每個單元都重講一次「要切題、要具體、要有自己的經驗」「閱卷老師想看的是……」。
9. **口語與語氣詞**：「老老實實」「其實」「真的」「就好」「就夠了」「一眼就看得出來」「很容易」「當然可以寫，只是……」。
10. **示例句千篇一律**：每一句學生示例都在句尾來一個機巧的反轉或對比（「我沒有湖，只有一支可以關機的手機。」），而且句句都有「我」。
11. **「本站」字樣與自我指涉**：「本站示範」「本書沒有查到」「本單元查核到……為止」。

## 改寫規則

1. **人稱**：說明文字不出現「你」「我們」「同學」「閱卷老師想看的是」。改用客觀陳述或規則句：「引用須標明作者與篇名。」「一段以一至二個為限。」
2. **開場**：單元開頭至多兩句，交代範圍與體例（收錄幾條、各欄是什麼）；能不寫就不寫。
3. **固定用語**（全書統一）：

   | 初版用語 | 改為 |
   |---|---|
   | 效果 | 作用 |
   | 什麼時候用 | 適用 |
   | 什麼時候不要用 | 不宜 |
   | 提醒 | 注意 |
   | 框架、仿寫框架 | 句型 |
   | 本站示範、示範 | 示例 |
   | 這樣用 | 運用示例 |
   | 可用主題、可用在什麼題目 | 適用主題 |
   | 高分技巧、小提醒 | 補充 |

4. **示例後的說明**：只留技術性的標註，用名詞短語，不寫賞析句。
   例如「示例（句型一）。明喻；喻依：未說完的叮嚀。」「題目〈家鄉的改變〉。今昔對比。」沒有必要的標註就整句刪掉。
5. **寫作觀念只講一次**：「切題、具體、有個人經驗」這套原則只在 N1 說明。其他單元需要時寫「見 N1」，或濃縮成一行使用原則，不再展開。
6. **使用原則的寫法**：把原本勸導式的段落改成條列的規則，每條一句，寫明對象、數量、限制。
   例如：
   - 「一段以一至二個成語為限；近義成語不連用。」
   - 「成語宜置於總括、評斷處，其前後須有具體敘述。」
   - 「知性題：引用後須說明其與論點的關係。情意題：全篇至多一句。」
7. **語體**：平實的書面語。可用「宜」「不宜」「忌」「須」「多用於」「常見於」「見於」「指」「謂」這類參考書慣用的字眼，但不要寫成文言文。不用驚嘆號、反問句、設問自答。
8. **誤／正對照**保留，但對照後的說明改成一句客觀的判斷：「誤例連用三個近義成語，且無具體敘述。」
9. **示例句**：保留自然、平實的；凡是句尾刻意反轉、對仗工整到像廣告詞的，改寫成普通高中生會寫的句子。示例不必句句有「我」，也不必句句精巧。
10. **不寫「本站」**：寫「示例」即可；查證範圍等說明集中在全書的編輯說明，單元內不寫。

## 改寫示範

| 初版 | 改後 |
|---|---|
| 仿寫不是抄句子，是把好句子拆開來，看它的骨架怎麼搭，再用自己的材料重蓋一次。這個單元整理十二種最常用的修辭與句式，每一種都照同樣的順序排：先說它的效果、什麼時候用、什麼時候不要用……讀的時候請拿筆，在框架的空格裡填上你自己的通勤路、便當和操場。 | 本單元收錄十二種常用修辭與句式。各條依序列出：作用、適用與不宜、名家例句（附出處）、句型、示例。 |
| 修辭不是加分清單。國寫看的是切題、具體、有自己的想法，沒有人會去數你用了幾種修辭。一段裡有一兩處用得準就夠了，其餘的句子老老實實把事情說清楚。 | 修辭以貼切為要，一段以一至二處為宜。情意題多用摹寫、轉化、譬喻、類疊、誇飾；知性題多用排比、層遞、映襯、設問、引用；對偶、頂真兩者皆可，宜少用。 |
| 成語是壓縮過的判斷，四個字就把一個評價說完。它的好處是省字、有分量；壞處是沒有畫面。讀到「廢寢忘食」，閱卷老師只知道你說某人很用功，看不到他到底怎麼用功。所以成語適合放在需要一句話下結論的地方，細節則要留給你自己的句子。 | 成語言簡意賅，宜用於總括與評斷；敘事、描寫仍以具體細節為主。 |
| 提醒：不要問答案顯而易見的問題（「誰不想成功呢？」）；問了就要在文章裡回答。 | 注意：忌明知故問（如「誰不想成功呢？」）；所提問題須於文中作答。 |
| 本站示範（框架一）。喻依選「沒說完的話」，便當就不只是便當。 | 示例（句型一）。明喻；喻依：未說完的叮嚀。 |
| 人物事例是配角。閱卷老師想看的是你怎麼想、你經歷過什麼；別人的故事寫得再完整，也只證明你記性好。一篇文章用一個事例就夠，最多兩個，而且用完一定要回到自己。 | 事例為論據，全篇以一至二例為限；敘述後須回扣論點或個人經驗。 |
| 表裡沒有的句子不一定是假的，只代表本書沒有查到可靠的出處；想用之前請自己再查一次。 | 未收錄者，表示未查得可靠出處，引用前宜另行查證。 |

## 不能動的東西

- 每一條素材本身：成語、名句、詩詞、人物事例的事實敘述、出處、注音、年代、數字。這些已經逐條查證過，**不得改動字句，也不得刪除條目**。
- 練習題的題號、題目的考點與正確答案。題幹與解答說明的語氣可以照本規範精簡，但不能改變答案。
- 表格的條目數與順序（欄名可照固定用語改）。
- 允許的標籤與 class（見撰寫規格）。

## 篇幅

只減不增。說明文字預期減少二到四成；條目與例句不減。
