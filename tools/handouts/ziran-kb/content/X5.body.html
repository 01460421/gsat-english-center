4. 多選題計分

\text{得分} = S\times\frac{n-2k}{n}\quad(\text{低於 0 以 0 計})

深究　單一選項是否劃記的期望值

在得分未降到 0 以下的範圍內，每個選項判斷正確與否，得分相差 2S/n（S ＝ 2、n ＝ 5 時為 0.8 分），且各選項互不影響。設某選項正確的機率為 p：

E(\text{劃}) - E(\text{不劃}) = p\cdot\frac{2S}{n} - (1-p)\cdot\frac{2S}{n} = (2p-1)\frac{2S}{n}

故 p > \tfrac12 時劃記較有利，p < \tfrac12 時不劃較有利。題末註明應選項數時，p 須依此條件重估：例如應選 2 項、已確定 1 項，其餘 4 項中能刪到只剩 2 項候選時，各候選 p ＝ 1/2，劃與不劃期望值相同；只能刪到 3 項候選時 p ＝ 1/3，不劃較有利。得分降到 0 時此式不適用

單選題不倒扣，每題都應作答；多選題全部不作答為 0 分，至少依最有把握的判斷劃記。考後對答案時，多選題得分須逐選項核對，不可只看「全對與否」。

二、作答策略

1. 多選題的選項判讀

多選題是「五題是非題」。

每個選項單獨判定，不受其他選項的對錯影響。

  1. 先讀題幹的限定條件：「下列哪些正確」或「哪些錯誤」「何者不可行」；情境的溫度、壓力、是否忽略空氣阻力、是否為理想狀況。圈出否定詞
  2. 逐一判斷選項，在試題本上每個選項旁標「○」「×」「?」三種記號。
  3. 標「×」的選項寫出錯在哪個字詞（如「一定」「所有」「成正比」「同時」），以便檢查時快速複核。
  4. 標「?」的選項依機率判斷（見一之 4 深究）；若題末註明應選項數，以已確定的選項數校對。
  5. 劃記前核對：劃記數與「應選 n 項」是否一致；若不一致，回頭檢查最沒把握的選項。

絕對字詞（「一定」「所有」「永遠」）不等於必錯：「真空中各頻率電磁波速率皆為 c」「同溫下各種氣體分子平均移動動能皆相同」都是正確的絕對敘述。判斷依據是科學內容，不是字面語氣。

學測多選題常在同一題中混合「定義」「條件」「圖表讀值」「推論」四類選項；推論類選項須確認資料是否足以支持，資料未提及者不可當成已知。

3. 實驗題的作答步驟

  1. 找出研究問題：題目要驗證的是哪兩個量的關係，或哪個假說。
  2. 標出操縱變因、應變變因、控制變因，並找出對照組；應變變因常以間接量表示（如以混濁所需時間的倒數表示反應速率、以單位時間氣泡數表示光合作用速率）。
  3. 檢查設計缺失：是否同時改變兩個以上變因、是否缺少對照組、重複次數是否足夠、測量方法是否會干擾結果。
  4. 判讀結果：由數據得出的結論不可超出實驗範圍；未測的條件只能寫成「推測」。
  5. 非選擇題作答：先寫結論，再寫依據的數據或現象，最後寫推理（見二之 7）。

重點整理　實驗題常見設問

  • 「本實驗的操縱變因為何」：只有一個；以實驗組之間的差異判斷。
  • 「哪一組為對照組」：不施加處理或施加已知效果處理的一組。
  • 「如何改良」：增加重複、增加測量點、改用更精密的儀器、排除干擾因素（如光源發熱影響溫度）。
  • 「由結果可推論」：只能就已改變的變因作結論；兩量同時變動時須另設實驗區分。

學測實驗題多取材於課本探究活動或研究論文的簡化版；題目常故意讓學生由數據表反推操縱變因，或在選項中放入「數據不足以支持」的推論。探究歷程通則見 X1。

4. 計算題：估算與單位檢查

選項數值相差 10 倍以上時，估算數量級即可作答。

選項相差不到 10% 時，才須仔細計算有效數字。

  1. 寫出所用的公式與每個量的單位；全部換成 SI 單位（或題目指定的一致單位，如化學用 atm、L）再代入。
  2. 先估算數量級：數值取一位有效數字，指數另外相加減。
  3. 計算後做單位檢查：等號兩邊單位須一致（\mathrm{J = N\cdot m = kg\cdot m^2/s^2}）。
  4. 做合理性檢查：數值是否在常識範圍（人跑速約 m/s 量級、分子大小約 10^{-10}\ \mathrm{m}、效率不超過 1、機率介於 0 與 1）。
  5. 做極限檢查：令某個量為 0 或極大，看結果是否合理（如斜面傾角為 0 時加速度應為 0）。

5. 刪去法的適用與陷阱

可用來刪去的依據適用陷阱
單位（因次）不符公式型選項因次一致只是必要條件，無因次係數（2π、1/2）無法檢驗（P1）
極限情形不合理含參數的公式、趨勢判斷只檢查一種極限可能刪不完，宜檢查兩端
違反守恆律能量、質量（化學反應）、電荷、核子數核反應中質量不守恆，守恆的是質量數與電荷數（P10）
與已知事實矛盾概念判斷課本簡化說法本身可能不嚴謹（如「電子沿軌道繞核」）
選項之間互斥單選題多選題中兩選項互斥時，可能兩者皆錯

刪去法只保證刪去者為錯；剩下的選項不必然正確。單選題刪到剩一個仍須正面驗證；多選題不可用「選項通常有兩到三個正確」來推測答案，近年試題以「應選 n 項」明示數目，未明示時每個選項獨立判斷。

6. 時間分配

  • 第壹部分約 36 題，平均每題約 1.5 分鐘；一題超過 3 分鐘仍無頭緒者，先標記跳過。

7. 混合題的非選擇題作答

重點整理　非選擇題作答格式

  • 簡答（說明理由）：結論 → 依據 → 推理。依據指題目給的數據、圖表特徵或已知定律；推理說明依據如何導出結論。
  • 計算：寫出公式、代入數值（含單位）、結果（含單位、有效數字）。只寫答案者「酌予扣分」。
  • 作圖：座標軸標物理量與單位；描點清楚；趨勢以平滑曲線或最佳直線表示，不逐點連折線（除非題目要求）。
  • 設計實驗：寫明操縱、應變、控制變因與對照組；說明預期結果與其對應的結論。
  • 名詞與符號：用標準名詞（如「克氏溫標」「體積莫耳濃度」「震度」），化學式、單位大小寫正確。

誤（說明為何高山上煮飯不易熟）高山上溫度低。

六、生物公式、定律與必背數據速查

生物的「公式」多為機率與比例。

先判斷事件獨立（乘）或互斥（加）。

P(A\ \text{且}\ B) = P(A)\times P(B)\qquad P(A\ \text{或}\ B) = P(A) + P(B)

乘法：A、B 為獨立事件（兩對獨立分配的基因、兩次各自的受精）。加法：A、B 為互斥事件（同一個體為 AA 或 Aa）。

p + q = 1\qquad p^2 + 2pq + q^2 = 1

p、q：對偶基因 A、a 的頻率；p²、2pq、q² 為 AA、Aa、aa 的頻率（族群處於哈溫平衡時）。攜帶者是 2pq，不是 q由個體數求頻率：p = \dfrac{2N_{AA} + N_{Aa}}{2N}。

例題 1　多選題計分　某多選題 5 個選項、配分 2 分，題末註明「應選 3 項」，正確答案為 (A)(B)(C)。甲劃記 (A)(B)(D)，乙劃記 (D)(E)，丙五個選項全劃。三人各得幾分？

  1. 逐選項比對，答錯數 k 包括漏劃與誤劃。
  2. 甲：漏劃 (C)、誤劃 (D)，k ＝ 2，得 2\times\frac{5-4}{5} = 0.4 分。
  3. 乙：漏劃 (A)(B)(C)、誤劃 (D)(E)，k ＝ 5，5 - 10 < 0，得 0 分。
  4. 丙：誤劃 (D)(E)，k ＝ 2，得 0.4 分。

陷阱：甲「對了兩個」不等於得 2/3 的分數；全劃也不保證得分，答錯數照算。

例題 2　圖表題：光合作用速率曲線　圖 X5-10 為某植物葉片在定溫、CO2 濃度固定下，O2 淨釋放速率與光強度的關係。求：(1) 該葉片的呼吸作用 O2 消耗速率；(2) 光補償點；(3) 光強度 20 klx 時的總光合作用 O2 產生速率。

  1. 座標軸：縱軸為「淨」釋放速率，可為負值；橫軸為光強度。
  2. 截距：光強度 0 時只行呼吸作用，淨速率 −2 mL/h，故呼吸作用 O2 消耗速率 2 mL/h。
  3. 與橫軸交點：淨速率為 0，光合作用產氧＝呼吸作用耗氧，光補償點 5 klx。
  4. 20 klx 時淨速率 6 mL/h；總光合作用速率＝淨速率＋呼吸速率 ＝ 6 ＋ 2 ＝ 8 mL/h（設呼吸速率不隨光強度改變）。

陷阱：把縱軸讀值 6 當成總光合作用速率；把光補償點誤為「光合作用開始進行」的光強度（光強度大於 0 即開始行光合作用）。

例題 3　實驗題：變因與設計缺失　某生將水蘊草置於裝滿水的試管中，以白熾燈泡由 10 cm、20 cm、30 cm 三種距離照射，每次記錄 1 分鐘內莖切口冒出的氣泡數，各距離照射 1 次。指出本實驗的操縱變因、應變變因與兩項設計缺失。

  1. 研究問題：光強度（以距離調整）與光合作用速率的關係。
  2. 操縱變因：燈泡與試管的距離；應變變因：每分鐘氣泡數（光合作用速率的相對指標）。
  3. 缺失一：白熾燈泡發熱，距離近者水溫較高，溫度成為未控制的變因；改用 LED 燈或在燈與試管之間放置水槽隔熱，並監測水溫。
  4. 缺失二：每個距離只測一次，無法評估隨機誤差；宜重複數次取平均，且每次改變距離後須等待氣泡速率穩定再計數。

陷阱：把「氣泡全是 O2」當成前提；氣泡含其他溶解氣體，只能作為相對指標。

例題 4　單位檢查　1.00 mol 理想氣體在 27 °C、2.00 atm 下的體積為何？（R ＝ 0.082 atm·L/(mol·K)）

  1. 換單位：T = 27 + 273 = 300\ \mathrm{K}。
  2. V = \dfrac{nRT}{P} = \dfrac{1.00\times0.082\times300}{2.00} = 12.3\ \mathrm{L}。
  3. 單位檢查：\dfrac{\mathrm{mol\cdot (atm\cdot L/(mol\cdot K))\cdot K}}{\mathrm{atm}} = \mathrm{L}。
  4. 合理性：STP 下 1 mol 為 22.4 L；壓力加倍、溫度升高約 1.1 倍，體積約 22.4 × 1.1 ÷ 2 ≈ 12.3 L，相符。

陷阱：代入 27 °C 得 1.11 L，比 STP 的一半還小得多，合理性檢查即可發現。

例題 5　數量級估算　大氣層頂垂直於陽光的單位面積接收太陽輻射約 1361 W/m²，地球半徑 6371 km。估算地球一年攔截的太陽輻射能的數量級（1 年 ≈ 3.16\times10^{7} s）。

  1. 地球攔截陽光的是其截面積（圓面積），不是表面積：\pi R^2 = 3.14\times(6.371\times10^{6})^2 \approx 1.27\times10^{14}\ \mathrm{m^2}。
  2. 功率：1361\times1.27\times10^{14} \approx 1.73\times10^{17}\ \mathrm{W}。
  3. 一年：1.73\times10^{17}\times3.16\times10^{7} \approx 5.5\times10^{24}\ \mathrm{J}。
  4. 5.5 ＞ 3.16，數量級為 10²⁵ J。

陷阱：以表面積 4\pi R^2 計算會高估 4 倍；以首位數字 5 直接判為 1024，忽略 √10 的進位界線。

例題 6　刪去法：極限檢查　質量 m 的木塊沿傾角 θ 的粗糙斜面下滑，動摩擦係數 μ。下列何者可能為其加速度量值？(A) g(\sin\theta - \mu\cos\theta)　(B) g(\cos\theta - \mu\sin\theta)　(C) g(\sin\theta + \mu\cos\theta)　(D) \mu g\sin\theta　(E) g(\tan\theta - \mu)

  1. μ ＝ 0（光滑）時應為 g\sin\theta：刪 (B)、(D)、(E)（(E) 得 g\tan\theta）。
  2. 有摩擦時加速度應小於 g\sin\theta：刪 (C)（(C) 為上滑時的加速度量值）。
  3. 正面驗證 (A)：沿斜面 mg\sin\theta - \mu mg\cos\theta = ma，得 a = g(\sin\theta - \mu\cos\theta)。答 (A)。

陷阱：五個選項的因次都相同，單位檢查無法刪去任何一個，須改用極限與物理判斷。

例題 7　跨科連結：氫原子譜線　氫原子由 n ＝ 3 躍遷至 n ＝ 2 放出的光子波長為何？此譜線在恆星光譜中屬於哪一系列？

  1. 能階：E_3 = -1.51\ \mathrm{eV},\ E_2 = -3.40\ \mathrm{eV}（P11）。
  2. \Delta E = -1.51 - (-3.40) = 1.89\ \mathrm{eV}。
  3. \lambda \approx \dfrac{1240}{1.89} \approx 656\ \mathrm{nm}，紅光。
  4. 終態 n ＝ 2，屬巴耳末系列（可見光區）；恆星光譜中氫的巴耳末吸收線在 A 型星最強（E1）。

陷阱：把能量差寫成 −3.40 − (−1.51) 得負值；或代入 J 卻用 1240 的 eV 公式。

例題 8　非選擇題的寫法　說明汽水開瓶後大量冒泡的原因。

  1. 結論：開瓶後二氧化碳在水中的溶解度變小，過量的 CO2 逸出成為氣泡。
  2. 依據：亨利定律，定溫下氣體溶解量與該氣體分壓成正比，C = k_HP（C6）。
  3. 推理：未開瓶時瓶內 CO2 分壓高，溶解量大；開瓶後液面上方 CO2 分壓降至接近大氣中的 CO2 分壓，飽和溶解量大幅下降，溶液成過飽和而釋出氣體。

陷阱：只寫「壓力變小」而未指明是 CO2 分壓；或歸因於溫度升高（開瓶瞬間溫度未明顯改變）。

迷思概念對照

以下為作答策略的常見迷思；各科內容迷思見第八節總表。

誤多選題沒有把握時整題不作答，以免倒扣。

正所有選項均未作答以 0 分計；每個選項依「正確機率是否大於 1/2」判斷劃記，期望得分不低於不作答。

誤單選題答錯會倒扣，不會的題目應空白。

正單選題答錯、未作答皆為 0 分，不倒扣，每題都應作答。

誤多選題的正確選項通常是兩到三個，可依此推測。

正近年試題於題末註明應選項數；未註明時各選項獨立判定，不可依選項數目的經驗猜測。

誤應選 2 項時，劃滿 2 個一定比只劃 1 個有利。

正第二個選項猜錯時答錯數為 2，只得 0.4 分，少於只劃 1 個正確選項的 1.2 分；候選正確機率大於 1/2 時加劃才有利。

誤含「一定」「所有」的選項必定錯誤。

正絕對敘述也可能正確，如「真空中各頻率電磁波速率皆為 c」；依科學內容判斷。

誤圖表題看曲線形狀即可判斷關係。

正須先讀座標軸的量、單位與刻度；對數軸上的直線代表指數關係，刻度不從 0 開始時比例會被放大。

誤兩組數據同時增加，表示一者造成另一者。

正相關不等於因果；須以控制變因的實驗或排除共同原因後才能推論因果。

誤非選擇題只要答案數值正確，過程可省略。

正試卷規定須寫出計算過程或理由，否則酌予扣分；算式須含代入數值與單位。

誤單選題刪到只剩一個選項，即可不加驗證直接作答。

正刪去法只證明被刪者錯誤；剩下的選項仍須正面驗證，以免題意或計算誤解。

誤題組第一小題不會，後面小題也無法作答，應整組跳過。

正題組各小題常可獨立作答，或後題題幹已給出前題的結論；應逐題判斷。

誤選項數值相近時才需要估算；估算只能用在選擇題。

正選項相差 10 倍以上時估算即可作答；計算題與非選擇題算完後，也以估算檢查數量級是否合理。
