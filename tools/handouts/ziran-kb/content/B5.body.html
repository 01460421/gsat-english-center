一、染色體學說的提出

1. 背景：兩條獨立發展的研究路線

孟德爾 1866 年只說「遺傳因子」，沒有指出因子在細胞的哪裡。

1900 年法則被再發現時，細胞學家已看得到染色體。

  • 遺傳學路線：孟德爾（Gregor Mendel，1822–1884）於 1866 年發表豌豆雜交結果，推論成對的遺傳因子在形成配子時分離（分離律）、不同對因子獨立分配（獨立分配律）。1900 年，法則由多位學者分別再發現。德弗里斯、科倫斯等
  • 細胞學路線：19 世紀後期，染色法與顯微技術進步，細胞學家陸續描述有絲分裂中染色體的複製與平均分配，並觀察到配子的染色體數目為體細胞的一半、受精後恢復原數。
  • 兩條路線交會的問題：遺傳因子位於細胞的哪一部分？其行為能否以可見的構造說明？

2. 蘇頓的蝗蟲研究

蘇頓（Walter Sutton，1877–1916）以一種大型蝗蟲（Brachystola magna）的精母細胞為材料，於 1902 年描述其染色體在減數分裂中的形態與配對，1903 年發表〈遺傳中的染色體〉（The Chromosomes in Heredity），系統提出染色體行為與孟德爾因子行為的平行關係。平行≠證明

  • 蝗蟲染色體大小形態各異、易於辨認，可追蹤每一對同源染色體在分裂中的去向。材料選得好
  • 觀察到同源染色體一條來自父方、一條來自母方，在減數分裂中配對後分離。
  • 推論：每一對同源染色體在赤道板上的排列方向互不影響，配子得到的父源、母源染色體組合有多種可能，與獨立分配律所需的配子比例相符。

3. 包法利的海膽實驗

包法利（Theodor Boveri，1862–1915）利用海膽卵的雙精受精現象研究染色體的功能（1902 年前後發表）。

  1. 一個卵同時被兩個精子受精，形成含三套染色體的受精卵，常出現四極紡錘體。
  2. 第一次分裂時染色體被不規則地分到四個細胞，每個細胞得到的染色體組合各不相同。
  3. 這些胚胎多數發育異常；分離個別細胞培養，發現只有得到某些組合的細胞能正常發育。
  4. 推論：各條染色體帶有不同的遺傳功能，正常發育需要一套完整的染色體，染色體的「數量」本身不足以決定發育。

4. 染色體學說的要點

染色體學說（chromosome theory of inheritance，亦稱蘇頓－包法利學說）：遺傳因子（基因）位於染色體上，基因在世代間的傳遞方式由減數分裂與受精時染色體的行為決定。

孟德爾的遺傳因子減數分裂與受精中的染色體對應的法則
體細胞中成對存在，一個來自父方、一個來自母方體細胞中同源染色體成對，一條來自父方、一條來自母方成對因子的來源
形成配子時成對因子分離，配子只含其中一個減數分裂Ⅰ同源染色體分離，配子只含每對中的一條分離律
不同對因子的分配互不影響不同對同源染色體在赤道板的排列方向隨機獨立分配律
受精時因子恢復成對受精時精卵染色體合併，恢復雙套（2n）子代基因型組合
在雜交中保持完整、不互相混合染色體在世代間保持形態與個別性顆粒遺傳

染色體學說在 1903 年仍是推論：平行關係只說明「兩者行為一致」，未能指出某一特定基因在某一特定染色體上。直接證據來自摩根的白眼果蠅（1910，基因與 X 染色體的對應）與布里吉斯的不分離實驗（1916，例外表現型與例外染色體組成的對應），見三之 4。

學測常以「減數分裂的哪一個事件對應分離律或獨立分配律」命題：分離律對應減數分裂Ⅰ後期同源染色體分離；獨立分配律對應減數分裂Ⅰ中期不同對同源染色體排列方向的隨機性。減數分裂Ⅱ姊妹染色分體分離不對應分離律（不考慮互換時，姊妹染色分體上的等位基因相同）。

深究　平行關係的限制與連鎖

  • 染色體的數目遠少於遺傳因子的數目（人類 23 對染色體，蛋白質編碼基因約兩萬個），若基因位於染色體上，同一條染色體上的多個基因應一起傳遞，不遵守獨立分配律。蘇頓在 1903 年的論文中已指出此一推論，後由連鎖現象證實（見 B4 進階）。
  • 獨立分配律因此只適用於位於不同對染色體，或在同一染色體上相距極遠、互換頻繁的基因。孟德爾研究的七對性狀，其基因分屬豌豆（2n = 14）七對染色體中的四對，同在一對染色體上者多數彼此相距甚遠，故在其雙因子雜交中未出現明顯連鎖（一說）。
  • 歷史評價：包法利對孟德爾法則與染色體關係的明確論述晚於蘇頓（一說至 1904 年），學說名稱的歸屬至今仍有討論；高中教材通行「蘇頓與包法利」並列。

二、性染色體的發現與性別決定

1. 發現歷程

年代學者材料觀察與推論
1891亨金（Hermann Henking，1858–1942）紅蝽（Pyrrhocoris）精母細胞觀察到一個行為特殊、只進入半數精子的染色質體，稱為「X」（一般解釋為「未知」之意，一說），未推論其與性別的關係
1901–1902麥克朗（Clarence McClung，1870–1946）蝗蟲稱之為副染色體（accessory chromosome），推測其與性別決定有關（誤以為帶有副染色體的精子產生雄性）
1905史蒂文斯（Nettie Stevens，1861–1912）黃粉蟲（麵包蟲，Tenebrio molitor）雌蟲體細胞 20 條大染色體；雄蟲 19 條大、1 條小。精子分兩類，含小染色體者產生雄性。即今之 XY 型

史蒂文斯與威爾遜同年獨立發表。

史蒂文斯是少數在當時取得博士學位並從事研究的女性科學家。

  • 結論：性別由特定染色體的組成決定性狀↔特定染色體，這是首個把某一可見性狀（性別）對應到某一特定染色體的實例，成為染色體學說的有力支持。
  • 史蒂文斯其後調查數十種甲蟲與蠅類，均可歸為 XY 型或 XO 型。

人物與材料的配對是學測科學史題的常見形式：蘇頓—蝗蟲；包法利—海膽；史蒂文斯—黃粉蟲；摩根—果蠅；孟德爾—豌豆。麥克朗提出副染色體與性別有關，但「XY 型」的發現者是史蒂文斯。

2. 常染色體與性染色體

  • 性染色體：雌雄個體間組成不同、與性別決定有關的染色體；其餘稱常染色體（體染色體）。
  • 人類體細胞 46 條：22 對常染色體＋1 對性染色體。女性核型記為 46,XX，男性 46,XY；亦可寫作「44＋XX」「44＋XY」。
  • 同配性別：只產生一種性染色體組成配子的性別（XY 型的雌性、ZW 型的雄性）。異配性別：產生兩種配子、決定子代性別的一方（XY 型的雄性、ZW 型的雌性）。誰異配，誰決定子代性別
  • X 與 Y 形態、大小不同，但兩端各有一小段擬常染色體區（pseudoautosomal region，PAR），在減數分裂中使 X、Y 能配對並發生互換；其餘部分無對應的等位基因。

人類 X 染色體約 1.55 億鹼基對、含約 900–1400 個蛋白質編碼基因（估計值隨方法而異）；Y 染色體約 5900 萬鹼基對、含約 70–200 個蛋白質編碼基因（資料：美國國家醫學圖書館遺傳學資料庫）。X 上的基因多與性別無關，例如凝血因子、色覺、肌肉蛋白。

三、摩根的果蠅實驗與性聯遺傳

1. 為何選用果蠅

摩根本來懷疑孟德爾法則與染色體學說，白眼果蠅的結果使他轉向支持。

  • 體型小、易飼養，以腐熟水果與酵母即可大量培養。
  • 世代時間短（25 °C 下由卵至成蟲約 10 天，溫度較低時延長，18 °C 約 19 天），一對親代可產數百個子代，統計數量充足。
  • 染色體少（2n = 8，3 對常染色體＋1 對性染色體），雌雄易於辨別。
  • 突變性狀（眼色、翅形、體色）明顯，易於觀察計數。
  • 幼蟲唾腺有巨大染色體（進階），可直接觀察染色體構造的改變。

3. 性聯遺傳的名詞

  • 性聯遺傳（sex-linked inheritance）：基因位於性染色體上，使性狀的遺傳與性別相關聯。位於 X 非同源區者稱 X 性聯，位於 Y 非同源區者稱 Y 性聯。
  • 半合子（hemizygous）：雄性（XY 型）的 X 性聯基因只有一份，無所謂同型或異型合子；隱性等位基因在半合子中直接表現。男生沒有「攜帶者」
  • 攜帶者：帶有一個隱性致病等位基因、表現型正常的異型合子，X 性聯隱性中專指女性 X^{A}X^{a}。

4. 布里吉斯的不分離實驗：染色體學說的證明

摩根的學生布里吉斯（Calvin Bridges，1889–1938）在白眼雌 × 紅眼雄的雜交中，發現極少數（約兩千分之一）的例外子代：白眼雌蠅與紅眼雄蠅。依摩根的假說，這兩種子代不應出現。

  1. 假設：母方減數分裂時兩條 X 不分離（nondisjunction），產生含兩條 X 的卵（X^{w}X^{w}）與不含 X 的卵（O）。
  2. 預測：X^{w}X^{w} 卵＋Y 精子 → X^{w}X^{w}Y，白眼雌；O 卵＋X^{W} 精子 → X^{W}O，紅眼雄（不育）。
  3. 驗證：以顯微鏡檢查例外白眼雌蠅的細胞，確有 XXY 組成；例外紅眼雄蠅為 XO 且不育。
  4. 結論（1916 年發表於《Genetics》創刊號）：例外的表現型與例外的染色體組成一一對應，眼色基因必位於 X 染色體上。這是染色體學說的直接證明。例外表現型＝例外染色體

深究　果蠅室的其他成果與 1933 年諾貝爾獎

  • 斯特蒂文特（Alfred Sturtevant，1891–1970）於 1913 年以 X 上數個性聯基因的互換頻率，排出第一張基因連鎖圖，證明基因在染色體上呈線狀排列（見 B4）。
  • 摩根於 1933 年獲諾貝爾生理醫學獎，表彰其發現染色體在遺傳中扮演的角色。果蠅其後成為遺傳學與發育生物學的模式生物。
  • 摩根 1910 年的論文題為〈Sex Limited Inheritance in Drosophila〉，當時所稱的「限性」即今之「性聯」；現代術語中「限性遺傳」另有所指（見四之 4）。

2. X 性聯顯性遺傳

  • 實例：X 性聯低磷酸鹽佝僂症（維生素 D 抗性佝僂症，PHEX 基因）。
  • 特徵：男性患者的女兒全部患病、兒子全部正常父病女必病；女性患者（多為異型合子）的子女約半數患病；若致病基因罕見，族群中女性患者約為男性的兩倍。

3. Y 性聯遺傳

  • 基因位於 Y 的雄性專有區，只由父親傳給兒子，所有男性後代都帶有，女性不出現。只走父子線
  • 確定的實例以與雄性發育、精子生成有關的基因為主（如 SRY、部分精子生成相關基因的缺失造成不孕）。
  • 「耳廓多毛症為 Y 性聯」為舊說，後續分子研究不支持，不宜作為 Y 性聯的典型例。

5. 劑量補償與 X 染色體去活化（進階）

女性有兩條 X、男性只有一條，X 上的基因產物在兩性間若相差一倍，會影響細胞功能。哺乳類以X 染色體去活化達成劑量補償。

  • 1949 年巴爾（Murray Barr，1908–1995）與伯特倫（Ewart Bertram）在雌貓神經細胞核中發現一個染色深的小體，稱巴氏體（Barr body）；後證實為凝縮、不表現的 X 染色體。
  • 1961 年萊昂（Mary Lyon，1925–2014；一譯里昂）提出假說：雌性哺乳類胚胎早期，每個體細胞隨機使一條 X 去活化隨機且終生維持，此後由該細胞分裂而來的子細胞維持同一條 X 去活化，故雌性個體是兩種細胞的鑲嵌體。
N_{\text{Barr}} = N_{X} - 1

N_X：體細胞中 X 染色體的數目。46,XX 為 1；46,XY 為 0；47,XXY 為 1；45,X 為 0；47,XXX 為 2。與 Y 的有無無關。

  • 實例：三花貓的橙色與黑色毛色由 X 上一對等位基因控制，異型合子雌貓因隨機去活化出現橙、黑斑塊；雄貓只有一條 X，通常不會是三花，少數三花雄貓多為 XXY。
  • 攜帶者女性體內有兩群細胞，例如 G6PD 異型合子女性的紅血球分為酵素正常與缺乏兩群；若去活化比例偏向某一條 X，攜帶者也可能出現輕度症狀。

學測常以巴氏體數推斷核型，或以三花貓說明 X 去活化。巴氏體數由 X 的數目決定，與有無 Y 無關；去活化只發生在體細胞，形成卵的生殖細胞系中兩條 X 會恢復活性。

五、譜系分析與機率計算

1. 譜系符號

  • 世代以羅馬數字（Ⅰ、Ⅱ、Ⅲ）由上而下標示；同一世代的個體以阿拉伯數字由左至右編號，記為「Ⅱ-3」。
  • 攜帶者在多數題目中不特別標出，須由親子關係推得；題目若標出，常以圓內加點或半塗表示。

2. 判斷遺傳方式

先找「無中生有」或「有中生無」定顯隱。

再找關鍵性別的患者排除性聯。

排除法的關鍵個體

  • 無中生有為隱性：表現型正常的雙親生出患病子女 → 隱性。
  • 有中生無為顯性：患病的雙親生出正常子女 → 顯性。
  • 隱性時看女患者：其父親或兒子有正常者 → 排除 X 性聯隱性，為常染色體隱性。
  • 顯性時看男患者：其母親或女兒有正常者 → 排除 X 性聯顯性，為常染色體顯性。
  • Y 性聯：只見於男性，患者的父親與兒子皆患病。

無中生有為隱性，隱性看女病：父子有正非性聯。

有中生無為顯性，顯性看男病：母女有正非性聯。

譜系只能排除不可能的遺傳方式，無法證明某一種方式；若找不到關鍵個體，常染色體遺傳通常無法排除。題目若寫「最可能」，須另依性狀是否罕見、患者性別分布等判斷；若寫「一定」，只能選被譜系強制的結論。

3. 機率計算要點

  1. 先寫出確定的基因型：男性表現型即基因型（半合子）；患病男性的母親、患病女性的父親可直接推出。
  2. 不確定的個體先算機率：攜帶者母親與正常父親所生的正常女兒，為攜帶者的機率 \tfrac12。
  3. 分清題目問的母群：「生一個患病男孩」的母群是所有子女，「所生男孩患病」的母群只有男孩。
  4. 多性狀分開算再相乘不同染色體→獨立：常染色體基因與 X 性聯基因位於不同染色體，獨立分配。
P(\text{生患病男孩}) = P(\text{男孩})\times P(\text{患病}\mid\text{男孩})

攜帶者 X^{A}X^{a} × 正常男 X^{A}Y：生一個患病男孩 =\tfrac12\times\tfrac12=\tfrac14；所生男孩中患病 =\tfrac12；所生女兒中患病 =0，女兒中攜帶者 =\tfrac12。

學測性聯機率題的主要失分點在母群的判讀：「再生一個孩子是色盲男孩」「再生一個男孩是色盲」「所生的男孩中色盲的比例」三種問法答案不同。作答前先圈出題目的母群。

深究　已知子女表現型時更新攜帶者機率（進階，貝氏定理）

某女的母親為攜帶者、父親正常，則她為攜帶者的事前機率為 \tfrac12。若她已生下 n 個正常兒子，這項資訊使「她是攜帶者」的可能性下降：

P(C\mid n\ \text{個正常兒子}) = \dfrac{\tfrac12\cdot\left(\tfrac12\right)^{n}}{\tfrac12\cdot\left(\tfrac12\right)^{n}+\tfrac12\cdot 1} = \dfrac{1}{1+2^{n}}

C：該女為攜帶者。分子為「是攜帶者且 n 子皆正常」的機率，分母為「n 子皆正常」的總機率。n=1,2,3 時分別為 \tfrac13,\tfrac15,\tfrac19。

遺傳諮詢以此法結合譜系與檢驗結果估算風險。學測不要求貝氏公式，但「已知條件改變機率」的題型可用列舉所有情況、刪去不符者的方法處理。

深究　族群中的 X 性聯性狀頻率（進階，銜接 B7）

設族群中 X 性聯隱性等位基因頻率為 q（顯性 p = 1-q），兩性基因頻率相同、隨機婚配：

\text{男性患者} = q,\qquad \text{女性患者} = q^{2},\qquad \text{女性攜帶者} = 2pq

男性只有一條 X，表現型頻率即等位基因頻率；女性須兩條 X 皆帶隱性基因。q 很小時，女性患者遠少於男性（q^2 \ll q）。

  • 以歐洲裔男性色盲 8% 估算，女性應為 0.08^2 = 0.64\%，實測約 0.4%，偏低。
  • 原因：紅綠色盲包括紅色覺異常與綠色覺異常兩類，分屬 X 上相鄰的兩個基因。一條 X 帶紅色覺缺陷、另一條帶綠色覺缺陷的女性，兩種視蛋白都有正常的一份，色覺正常。女性色盲須兩條 X 屬同一類缺陷：若男性中兩類約占 2% 與 6%，女性約為 0.02^2+0.06^2 = 0.40\%，與實測相符。

六、染色體異常（進階）

1. 數目異常與不分離

  • 不分離：減數分裂Ⅰ同源染色體未分離，或減數分裂Ⅱ姊妹染色分體未分離，產生多一條（n＋1）或少一條（n−1）染色體的配子；與正常配子受精後形成三染色體（2n＋1）或單染色體（2n−1）個體，統稱非整倍體。

深究　以性聯標記追蹤不分離的來源

X 性聯基因像貼在 X 上的標籤，可分辨某條 X 來自父親或母親，以及來自母親的哪一條。

  • XXY 兒子若帶有父親獨有的 X 等位基因 → 父親的 X 與 Y 一起進入精子 → 父方減數分裂Ⅰ不分離（X、Y 為一對同源染色體）。
  • XXY 兒子的兩條 X 都來自母親且等位基因相同（母親為異型合子） → 不考慮互換時為母方減數分裂Ⅱ不分離；若兩條 X 的等位基因不同 → 母方減數分裂Ⅰ不分離。
  • 45,X 女兒的唯一 X 若為父源 → 卵缺 X（母方不分離，Ⅰ或Ⅱ皆可能）；若為母源 → 精子缺性染色體（父方不分離）。臨床上 45,X 也常由受精後早期分裂中性染色體遺失造成，此處只討論配子形成時的不分離。

例題精解

例題 1　某雄蝗蟲精母細胞的基因型為 AaBb，兩對基因位於不同對的常染色體上。減數分裂中，下列事件各對應孟德爾的哪一條法則？(1) 減數分裂Ⅰ後期，帶 A 與帶 a 的同源染色體分別移向兩極；(2) 減數分裂Ⅰ中期，帶 A 的染色體與帶 B 的染色體排在赤道板同側或異側的機會相等；(3) 減數分裂Ⅱ後期，姊妹染色分體分離。

  1. (1) 同源染色體分離，成對的等位基因隨之分離 → 分離律。
  2. (2) 不同對同源染色體排列方向隨機 → 獨立分配律，產生 AB、Ab、aB、ab 四種配子，比例 1：1：1：1（圖 B5-2）。
  3. (3) 不考慮互換時，姊妹染色分體帶相同的等位基因（如皆為 A），其分離不對應任何一條法則，只把複製所得的兩份 DNA 分配到不同配子。

陷阱：把減數分裂Ⅱ的「分離」當成分離律；若曾發生互換，姊妹染色分體可能帶不同等位基因，此時等位基因的分離延至減數分裂Ⅱ。

例題 2　果蠅體色由一對等位基因控制，親代皆為純品系。正交：灰體雌 × 黃體雄，F1 全為灰體；反交：黃體雌 × 灰體雄，F1 雌蠅全為灰體、雄蠅全為黃體。(1) 判斷基因位置與顯隱性；(2) 反交的 F1 雌雄互交，求 F2 的表現型與比例。

  1. 正交與反交結果不同，且反交子代雌雄表現不同 → 基因位於 X 染色體（排除細胞質遺傳：細胞質遺傳子代不分性別皆隨母本）。
  2. 正交 F1 全灰 → 灰體為顯性。以 X^{A} 表灰體、X^{a} 表黃體。反交：X^{a}X^{a} \times X^{A}Y → F1 雌 X^{A}X^{a}（灰）、雄 X^{a}Y（黃），與題意相符。
  3. F1 互交：X^{A}X^{a}\times X^{a}Y → X^{A}X^{a}、X^{a}X^{a}、X^{A}Y、X^{a}Y 各 \tfrac14。
  4. F2：灰體雌：黃體雌：灰體雄：黃體雄 ＝ 1：1：1：1；不分性別時灰：黃 ＝ 1：1。

陷阱：反交 F2 灰：黃為 1：1，與常染色體的試交結果相同，須分性別看才能與正交的 F2（灰雌 2：灰雄 1：黃雄 1）對照。

例題 3　摩根以原白眼雄蠅與 F1 紅眼雌蠅交配，得紅眼雌 129、紅眼雄 132、白眼雌 88、白眼雄 86。(1) 依「基因位於 X」的假說，求理論比例；(2) 此結果排除了哪一種對 F2「白眼只見於雄蠅」的解釋？

  1. 親代：X^{w}Y \times X^{W}X^{w}。卵 X^{W}、X^{w} 各半；精子 X^{w}、Y 各半。
  2. 子代：X^{W}X^{w}（紅雌）、X^{w}X^{w}（白雌）、X^{W}Y（紅雄）、X^{w}Y（白雄），理論比 1：1：1：1。
  3. 實測紅眼 261、白眼 174，白眼偏少，與白眼個體存活力較低一致。
  4. 白眼雌蠅能出現並存活，排除「白眼雌蠅致死，故 F2 只見白眼雄」的解釋。

陷阱：試交出現 1：1：1：1 本身不能區分常染色體與 X 性聯（兩者在此雜交的預期相同）；摩根的證據來自 F2 的性別分布與白眼雌 × 紅眼雄的預測。

例題 4　白眼雌蠅（X^{w}X^{w}）與紅眼雄蠅（X^{W}Y）交配，約兩千個子代中出現 1 隻白眼雌蠅與 1 隻紅眼雄蠅。以染色體的行為解釋，並說明此結果為何能「證明」染色體學說。

  1. 正常情況：子代雌 X^{W}X^{w} 全紅眼，雄 X^{w}Y 全白眼。
  2. 母方減數分裂兩條 X 不分離，產生 X^{w}X^{w} 卵與不含 X 的卵（O）。
  3. X^{w}X^{w}＋Y → X^{w}X^{w}Y：白眼雌（果蠅 XXY 為雌）；O＋X^{W} → X^{W}O：紅眼雄（XO 為雄、不育）。
  4. 預測的染色體組成經細胞學觀察證實：特定表現型對應特定的染色體異常，基因必在該染色體上。

陷阱：XXY 果蠅為雌、XO 果蠅為雄，與人類相反；人類 XXY 為男、XO 為女。

例題 5　色覺正常的男子與一位色覺正常、父親為紅綠色盲的女子結婚。求：(1) 生一個色盲男孩的機率；(2) 所生男孩中色盲的機率；(3) 所生女兒中為攜帶者的機率。

  1. 女子的父親 X^{b}Y，必傳 X^{b} 給女兒；女子色覺正常 → X^{B}X^{b}。男子 X^{B}Y。
  2. (1) 子女中：X^{b}Y 占 \tfrac12\times\tfrac12 = \tfrac14。
  3. (2) 男孩的 X 來自母親，X^{b} 占 \tfrac12。
  4. (3) 女兒必得父親的 X^{B}，自母親得 X^{b} 的機率 \tfrac12，故攜帶者 \tfrac12，色盲 0。

陷阱：(1) 與 (2) 的母群不同；「生一個色盲男孩」須同時滿足「是男孩」與「色盲」。

例題 6　白化症為常染色體隱性、血友病為 X 性聯隱性。一對表現型正常的夫婦生下一個白化且患血友病的兒子。他們再生一個孩子：(1) 兩病皆無的機率；(2) 只患一種病的機率。

  1. 兒子 aa\,X^{h}Y：a 來自雙方，X^{h} 來自母親。父 Aa\,X^{H}Y，母 Aa\,X^{H}X^{h}。
  2. 兩對基因位於不同染色體，分開計算：白化 \tfrac14、不白化 \tfrac34；血友病（不分性別）\tfrac14、不患 \tfrac34。
  3. (1) \tfrac34\times\tfrac34 = \tfrac{9}{16}。
  4. (2) \tfrac14\times\tfrac34 + \tfrac34\times\tfrac14 = \tfrac{6}{16} = \tfrac38。

陷阱：血友病在「所有孩子」中為 \tfrac14，誤以 \tfrac12 計算即錯；女兒必得父親的 X^{H}，不患病。

例題 7　圖 B5-16 為某罕見性狀的家族譜系（塗黑者具此性狀）。(1) 哪些遺傳方式可由譜系直接排除？(2) 最可能的遺傳方式為何？依據為何？

  1. Ⅱ-2、Ⅱ-4 為女性患者，排除 Y 性聯。
  2. Ⅱ-4（女患者）的兒子Ⅲ-2 正常 → 排除 X 性聯隱性（女患者的兒子必患病）。
  3. 常染色體隱性：須Ⅰ-2 與Ⅱ-5 皆為攜帶者，性狀罕見時可能性很低。
  4. X 性聯顯性：男患者Ⅰ-1 的女兒全患病、兒子全正常；Ⅱ-4 為異型合子，子女約半數患病，皆相符。常染色體顯性亦相符，但「女兒全患、兒子全無」在四個子女中出現的機率為 (\tfrac12)^4 = \tfrac{1}{16}。

陷阱：譜系「相符」不等於「確定」；題目問「一定」時，只能選被強制排除或強制成立的敘述。

例題 8（進階）　某女子的母親為血友病攜帶者，父親正常。她與凝血正常的男子結婚，已生下 3 個凝血正常的兒子。求她為攜帶者的機率，及下一個兒子患血友病的機率。

  1. 事前：攜帶者 \tfrac12、非攜帶者 \tfrac12。
  2. 若為攜帶者，3 子皆正常的機率 (\tfrac12)^3 = \tfrac18；若非攜帶者為 1。
  3. P = \dfrac{\tfrac12\cdot\tfrac18}{\tfrac12\cdot\tfrac18 + \tfrac12\cdot1} = \dfrac{1}{9}。
  4. 下一個兒子患病：\tfrac19\times\tfrac12 = \tfrac{1}{18}。

陷阱：忽略已生子女的資訊，仍以 \tfrac12 計算，得 \tfrac14。

例題 9（進階）　某 X 性聯隱性遺傳的酵素缺乏症，在某族群女性中的患者比例為 0.04%。假設兩性基因頻率相同且隨機婚配，求該族群男性的患者比例，以及女性中攜帶者的比例。

  1. 女性患者須兩條 X 皆帶隱性基因：q^2 = 0.0004，q = 0.02，p = 0.98。
  2. 男性為半合子，患者比例即等位基因頻率：q = 0.02 = 2\%。
  3. 女性攜帶者 2pq = 2\times0.98\times0.02 \approx 0.039 = 3.9\%，約為女性患者的 100 倍。

陷阱：把男性比例當成女性的 2 倍（0.08%）。男性患者比例為 q、女性為 q^2，由女性推男性須開根號。

例題 10　色覺正常的父親與紅綠色盲的母親，生下一個色覺正常、核型為 47,XXY 的兒子。不考慮突變與互換，不分離發生在哪一位親代的哪一次減數分裂？

迷思概念對照

誤蘇頓以雜交實驗證明了基因位於染色體上。

正蘇頓由細胞學觀察提出平行關係的推論；直接證據來自摩根的性聯遺傳與布里吉斯的不分離實驗。

誤性染色體上的基因都與性別決定或性徵有關。

正X 染色體上多數基因與性別無關，如凝血因子、色覺視蛋白、G6PD、失養蛋白的基因。

誤所有生物的子代性別都由父方的精子決定。

正由異配性別的配子決定：XY、XO 型由精子決定；ZW 型由卵決定；鱷類與多數龜類由孵化溫度決定。

誤XO 型的雄蝗蟲是單倍體。

正XO 雄性的常染色體為雙套，只少一條 X；全套染色體只有一套的單倍體雄性見於蜜蜂、螞蟻。

誤果蠅與人類都由 Y 染色體決定雄性。

正人類由 Y 上的 SRY 決定；果蠅由 X 數與常染色體套數的比值決定，XXY 果蠅為雌、XO 果蠅為雄。

誤男性也可能是色盲或血友病的攜帶者。

正男性的 X 性聯基因為半合子，帶有隱性等位基因即表現；「攜帶者」只用於異型合子的女性。

誤色盲父親所生的兒子有一半會色盲。

正父親傳給兒子的是 Y，兒子的色覺只取決於母親；色盲父親的女兒必為攜帶者或患者。

誤F2 紅眼：白眼約 3：1，所以摩根的果蠅眼色是常染色體遺傳。

正總比例相同時須分性別統計：白眼只見於雄蠅，才顯示基因位於 X。

誤兩性表現頻率不同的性狀一定是性聯遺傳。

正從性遺傳與限性遺傳的基因可位於常染色體，同樣有性別差異；X 性聯的特徵是不會父傳子。

誤正交與反交結果不同，基因一定位於性染色體。

正細胞質遺傳也會使正反交結果不同，但其子代不分性別皆與母本相同。

誤「生一個色盲男孩的機率」與「所生男孩為色盲的機率」相同。

正前者的母群為所有子女，後者只有男孩；攜帶者母親與正常父親分別為 \tfrac14 與 \tfrac12。

誤女性體細胞中兩條 X 染色體都會表現。

正哺乳類雌性胚胎早期每個細胞隨機去活化一條 X，成為巴氏體，個體為兩種細胞的鑲嵌體。

誤唐氏症多由父母遺傳，父母染色體正常就不會發生。

正唐氏症多數為配子形成時第 21 對不分離所致的新發生事件，風險隨母親年齡增加；只有少數易位型與親代的平衡易位有關。

誤減數分裂Ⅱ不分離與減數分裂Ⅰ不分離產生的異常配子比例相同。

正減數分裂Ⅰ不分離四個配子皆異常；減數分裂Ⅱ不分離（一個次級細胞）只有一半異常。
