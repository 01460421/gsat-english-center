C9　氧化還原

C9-01 (E) (A) 各元素氧化數不變（Ca +2、C +4、O −2），為分解但非氧化還原。(B) 沉澱反應，離子交換。(C) N 皆為 +4。(D) 同素異形體互變，O 皆為 0；有單質不等於氧化還原。(E) Zn 0 → +2，H +1 → 0，為氧化還原。
C9-02 (C) N 的氧化數：(A) NH4+ 中 −3；(B) 2x - 2 = 0，+1；(C) x - 4 = 0，+4；(D) 1 + x - 4 = 0，+3；(E) 2x + 4 = 0，−2。最高為 NO2。誘答 (D) 為誤以為含氧酸中的 N 必高於氧化物。
C9-03 (D) \ce{Zn + Cu^2+ -> Zn^2+ + Cu}。(A) Cu2+ 得電子，為氧化劑。(B) 鋅失電子被氧化。(C) 析出紅棕色的銅（銀白色是置換 Ag+ 的情形）。(D) 藍色的 Cu2+ 減少，正確。(E) SO42− 為旁觀離子，S 維持 +6。
C9-04 (B)(D)(E) (A) 2 + 2x - 14 = 0，Cr 為 +6。(B) 過氧化物中 O 為 −1。(C) 金屬氫化物中 H 為 −1。(D) F 恆為 −1，O 為 +2。(E) 3x = 8，平均 +\frac{8}{3}（實為 Fe2+ 與 Fe3+ 1 : 2）。
C9-05 (B) (A)(E) Mg、Zn 位於 H 之前，可被 H+ 氧化放出 H2。(B) Ag 位於 H 之後，不與稀硫酸反應。(C) Fe 比 Cu 活潑，析出銅。(D) Cu 比 Ag 活潑，析出銀（銀樹）。
C9-06 (A)(B)(D) (A)(B) Zn 失電子為負極，電子經導線流向銅。(C) K+ 移向正極（銅極）槽補充減少的 Cu2+；移向鋅極槽的是 NO3−。(D) Cu2+ 還原析出於銅片。(E) 電子不經過鹽橋，鹽橋中為離子移動。
C9-07 (A) (A) CO 中 C +2 → +4，被氧化，為還原劑。(B)(C) Cl2 0 → −1，為氧化劑。(D) Mn +4 → +2，MnO2 為氧化劑。(E) CO2 中 C +4 → 0，為氧化劑（鎂可在 CO2 中燃燒）。
C9-08 (B)(C)(E) (A) 乾燥空氣中缺水，幾乎不生鏽。(B) 正確。(C) 電解質增加導電度，加速電化學腐蝕。(D) 鐵鏽疏鬆易剝落，無保護作用（與 Al2O3 不同）。(E) 正確，含水量不定。
C9-09 (A) (A) 鉛蓄電池為二次電池。(B)(C) 一次電池，充電可能漏液或發熱。(D) 實驗室鋅銅電池放電後無法以實用方式充回原狀。(E) 鋰一次電池不可充電，與鋰離子電池不同。
C9-10 (E) 由三式得氧化力 Cl2 ＞ Br2 ＞ Fe3+ ＞ I2，還原力 I− ＞ Fe2+ ＞ Br− ＞ Cl−。(A) 順序顛倒。(B) I2 氧化力弱於 Fe3+，不能氧化 Fe2+。(C) Br2 ＞ I2，可氧化 I−。(D) Cl− 還原力最弱，不能還原 Fe3+。(E) 正確。
C9-11 (A)(C)(D) (A) H2C2O4 中 2 + 2x - 8 = 0，C 為 +3，變為 CO2 的 +4。(B) 草酸被氧化，為還原劑。(C) Mn +7 → +2，得 5e−。(D) 終點前 MnO4− 一滴入即被還原為近無色的 Mn2+；過量一滴即呈淡紫紅色。(E) Cl− 會被 MnO4− 氧化，使 KMnO4 用量偏多。

C9-32 參考答案：(1) 還原：\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}；氧化：\ce{H2O2 -> O2 + 2H+ + 2e-}。(2) 前式乘 2、後式乘 5 相加：\ce{2MnO4- + 5H2O2 + 6H+ -> 2Mn^2+ + 5O2 + 8H2O}。(3) 此處 H2O2 中 O 由 −1 升為 0，為還原劑；與 I− 反應時 O 由 −1 降為 −2，為氧化劑。O 的 −1 介於 −2 與 0 之間，可升可降；MnO4− 的氧化力強於 H2O2，故 H2O2 被氧化，I− 的還原力強於 H2O2，故 H2O2 被還原。評分要點：半反應的電子數與電荷平衡；係數 2、5、6 → 2、5、8；說明氧化數居中。
C9-33 參考答案：(1) 電源正極接純銅片（陽極），負極接鐵鑰匙（陰極）；電解液用 CuSO4 水溶液（含 Cu2+）。(2) n(\ce{Cu}) = 0.635 / 63.5 = 0.0100\ \mathrm{mol}，n_{e^-} = 0.0200\ \mathrm{mol}，Q = 0.0200 \times 96500 = 1930\ \mathrm{C}，t = 1930 / 0.500 = 3.86\times10^{3}\ \mathrm{s}（約 64 分鐘）。(3) 顏色大致不變：陽極 \ce{Cu -> Cu^2+ + 2e-} 溶出的 Cu2+ 與陰極析出的量相等，[Cu2+] 維持不變。常見錯誤：鑰匙接正極，會使鐵被氧化溶解；若改用石墨作陽極，藍色會逐漸變淡。
C9-34 參考答案：(1) 鐵被腐蝕（鐵比銅活潑）。陽極（鐵）：\ce{Fe -> Fe^2+ + 2e-}；陰極（銅表面）：\ce{O2 + 2H2O + 4e- -> 4OH-}；Fe2+ 再氧化生成鐵鏽。(2) 任答兩項：① 以絕緣接頭隔開兩金屬，切斷電子通路；② 改用同種金屬的管材，避免形成電池；③ 在鐵管上連接鋅塊或鎂塊作犧牲陽極；④ 管外加塗層隔絕水與氧。評分要點：指出活性較大的鐵為陽極；陰極反應寫 O2 的還原而非 Cu 的氧化；改善方法須說明原理。
