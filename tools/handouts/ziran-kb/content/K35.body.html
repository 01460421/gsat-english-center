K35-04帶電量分別為 -Q 和 +4Q 的二電荷 A 與 B，相距為 R，如下圖所示。若將第三個電荷 C 擺置 AB 連線上，使三電荷皆處於力平衡狀態，則 C 的電性、電量及位置應為下列何者？
(A) +4Q，在連線上 A 的左邊 R/2 處(B) -4Q，在連線上 B 的右邊 R/2 處(C) -4Q，在連線上 B 的右邊 R 處(D) +4Q，在連線上 A 的左邊 R 處

答案：(D)

F = \frac{k q_1 q_2}{r^2}

同號相斥、異號相吸；三電荷共線平衡時，第三電荷在電量較小者的外側。

  1. C 的位置：A、B 異號，C 必在連線外側且靠近電量較小的 A。設 C 在 A 左方 x 處，C 受力平衡：\dfrac{kqQ}{x^2} = \dfrac{kq \cdot 4Q}{(x + R)^2}，x + R = 2x，x = R。
  2. A 受力平衡：B 吸 A 向右，大小 \tfrac{4kQ^2}{R^2}；C 必須把 A 拉向左，對負電荷 A 是吸引，C 為正電。\dfrac{kQq}{R^2} = \dfrac{4kQ^2}{R^2}，q = 4Q。
  3. 驗算 B：A 吸 B 向左 \tfrac{4kQ^2}{R^2}；C 距 B 為 2R，斥 B 向右 \tfrac{k(4Q)(4Q)}{(2R)^2} = \tfrac{4kQ^2}{R^2}，平衡。

考點：庫侖定律、三電荷共線平衡　對應：P5

誤只寫 C 的平衡方程式，得出位置就以為電量、電性任意；C 的電量與電性要由 A 或 B 的平衡決定。

K35-07如右圖所示，I 為發電機所產生的電流，B 為電流造成的磁場，n 為電磁鐵單位長度的線圈數。在電磁鐵標示為 N 的位置，放置一個盤狀指南針以測量電磁鐵的磁場量值。已知地球磁場量值，並有量角器與直尺，若忽略實驗地點的地球磁偏角，為了測量電磁鐵的磁場量值，請問此裝置應如何擺放?

答案：(C)
