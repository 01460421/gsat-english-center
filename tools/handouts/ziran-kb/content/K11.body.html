K11-01下列關於物質的敘述，何者正確？
(A) 矽晶、碘酒、臭氧、硫黃中，有兩種是元素(B) 鹽酸、福馬林、氨水都不是純物質(C) 金屬的熔點都很高，常溫、常壓下必為固態(D) 黃金、青銅、黃磷都有明確的熔點(E) 雙氧水具有固定的沸點。

答案：(B)

  1. (A) 矽晶（Si）、臭氧（\ce{O3}）、硫黃（S）都是元素，共 3 種；碘酒是碘溶於酒精的溶液，為混合物。錯誤。
  2. (B) 鹽酸是 HCl 的水溶液、福馬林是約 37% 甲醛水溶液、氨水是 \ce{NH3} 的水溶液，都是溶液，皆為混合物。正確。
  3. (C) 汞的熔點約 −39 °C，常溫為液態；鎵、銫的熔點也低於 30 °C。錯誤。
  4. (D) 青銅是銅錫合金，屬混合物，熔化在一段溫度範圍內進行，沒有明確熔點。錯誤。
  5. (E) 雙氧水是過氧化氫的水溶液（市售約 3%），沸點隨濃度而變，且沸騰時組成改變。錯誤。

考點：純物質與混合物、元素與化合物　對應：C2

誤把「雙氧水」「鹽酸」「氨水」當成單一化合物的名稱。三者都是商品名或溶液名，對應的純物質是 \ce{H2O2}、HCl、\ce{NH3}。

K11-0425 克甲物質、5 克乙物質和 10 克丙物質混合加熱，使它們發生化學反應，經分析完全反應後，混合物中含 15 克甲和 21 克丙，還產生一種新物質丁。若甲、乙、丙、丁的莫耳質量分別為 40 克、20 克、44 克、8 克，並用 a、b、c、d 分別表示它們的化學式，則它們之間所發生化學反應式為何？
(A) a＋b → c＋2d(B) a＋2b → 2c＋d(C) 2a＋b → 2c＋d(D) 2a＋b → c＋2d(E) 2a＋b → c＋d。

答案：(A)

  1. 質量變化：甲消耗 25-15=10 g；乙無剩餘，消耗 5 g；丙生成 21-10=11 g。
  2. 質量守恆：丁生成 10+5-11=4 g。
  3. 換成莫耳數：甲 \tfrac{10}{40}=0.25，乙 \tfrac{5}{20}=0.25，丙 \tfrac{11}{44}=0.25，丁 \tfrac{4}{8}=0.5 mol。
  4. 係數比 1:1:1:2，即 a＋b → c＋2d。

考點：質量守恆、係數比＝莫耳數比　對應：C5

誤把丙的 21 g 全當生成量，或用反應前的 25 g 甲計算。係數比要用「反應掉或生成的量」。

K11-05工業上製備硝酸是採用「奧士華法」，其反應的過程是由氨（\ce{NH3}）開始，依序經過三個步驟：
（一）\ce{NH3(g) + O2(g) -> NO(g) + H2O(g)}（以 Rh–Pt 為催化劑）
（二）\ce{NO(g) + O2(g) -> NO2(g)}
（三）\ce{NO2(g) + H2O(l) -> HNO3(aq) + NO(g)}（以上反應皆未平衡）
某化工廠生產 63% 濃硝酸產能為 1 公噸/小時，則每分鐘至少必須提供若干公斤的液態氨原料？（原子量：H＝1，N＝14，O＝16）
(A) 2.83(B) 1.89(C) 170(D) 11.32(E) 340。

答案：(A)

  1. 平衡後三式：\ce{4NH3 + 5O2 -> 4NO + 6H2O}；\ce{2NO + O2 -> 2NO2}；\ce{3NO2 + H2O -> 2HNO3 + NO}。
  2. 第三步生成的 NO 送回第二步再氧化，循環使用時氮原子全部進入硝酸，「至少」的用量即依 N 原子守恆：1\ \ce{NH3}\to1\ \ce{HNO3}。
  3. 每小時純硝酸 1000\times63\%=630 kg，即 630/63=10 kmol；需 \ce{NH3} 10 kmol＝170 kg/小時。
  4. 每分鐘：170/60\approx2.83 kg。

補充　若第三步生成的 NO 不回收，3 mol \ce{NO2} 只得 2 mol 硝酸，需氨量為 1.5 倍（約 4.25 kg/min），不在選項中。(C) 170 是每小時的量，未換算成每分鐘。總反應可合併為 \ce{NH3 + 2O2 -> HNO3 + H2O}。

考點：多步驟反應計量、原子守恆　對應：C5、C11

誤忘記 63% 只算硝酸本身的質量，直接用 1000 kg 計算，得 4.5 kg/min。

K11-06A、B 兩元素生成化合物 X、Y，0.3 克的 A 和 0.4 克的 B 反應生成 0.7 克的 X；1.8 克的 A 和 4.8 克的 B 反應生成 6.6 克的 Y，若 X 之化學式為 AB，則 Y 之化學式為：
(A) \ce{A3B}(B) \ce{A2B}(C) \ce{AB3}(D) \ce{AB2}(E) \ce{A2B3}。

答案：(D)

  1. X：A : B ＝ 0.3 : 0.4。Y：A : B ＝ 1.8 : 4.8 ＝ 0.3 : 0.8。
  2. 固定 A 的質量 0.3 g，與之結合的 B 質量比 X : Y ＝ 0.4 : 0.8 ＝ 1 : 2（倍比定律）。
  3. X 為 AB，故 Y 中每個 A 搭配 2 個 B：AB2。

延伸　由 X＝AB 得原子量比 A : B ＝ 3 : 4，符合 C : O ＝ 12 : 16，X、Y 可視為 CO 與 \ce{CO2}。

考點：倍比定律　對應：C1、C5

誤直接比 1.8 : 4.8 ＝ 3 : 8 就寫成 \ce{A3B8} 一類。質量比要先除以原子量（或與已知化學式比較）才是原子數比。

K11-07從鐵礦煉製鐵的過程中涉及 \ce{C(s) + O2(g) -> CO(g)} 與 \ce{Fe2O3(s) + CO(g) -> Fe(s) + CO2(g)} 二個化學反應（皆未平衡）。若第一個化學反應式中所產生的一氧化碳全部用於第二個化學反應式，則欲產生 70 公斤的鐵，約須氧若干公斤？（原子量：Fe＝56，O＝16，C＝12）

答案：(E)

  2. Fe：70/56=1.25 kmol → 需 CO 1.25\times\tfrac32=1.875 kmol → 需 \ce{O2} 1.875\times\tfrac12=0.9375 kmol。
  3. 質量：0.9375\times32=30 kg。

K11-08下列五種反應中，哪一種反應中的氧元素發生氧化反應？
(A) \ce{Ca(OH)2(aq) + H2SO4(aq) -> CaSO4(s) + 2H2O(l)}(B) \ce{2H2O(l) + 2Na(s) -> 2NaOH(aq) + H2(g)}(C) \ce{2NaHCO3(s) ->[\Delta] Na2CO3(s) + CO2(g) + H2O(l)}(D) \ce{2H2O(l) ->[\text{電解}] 2H2(g) + O2(g)}(E) \ce{3O2(g) -> 2O3(g)}

答案：(D)

  1. 氧化＝氧化數增加。只要找氧的氧化數上升的反應。
  2. (A) 酸鹼中和，各元素氧化數不變。(B) Na：0→＋1 被氧化，H：＋1→0 被還原，O 維持 −2。(C) 熱分解，氧化數皆不變。
  3. (D) O：-2\to0，氧被氧化（H 被還原）。正確。
  4. (E) \ce{O2} 與 \ce{O3} 中 O 的氧化數都是 0，是同素異形體的轉變，不是氧化還原。

考點：氧化數　對應：C9
