K02-01如圖所示之滑輪組，物體 A、B 分別具有向下的加速度 a_A = 2\ \mathrm{m/s^2} 及 a_B = 4\ \mathrm{m/s^2}，物體 C 具有向上的加速度，則物體 C 的加速度大小為何？
(A) 1.5(B) 2(C) 3(D) 5(E) 6 m/s²

答案：(C)

  1. 看懂繩子走法：一條繩子從 A 出發，繞過左定滑輪，往下繞過 B 上方的動滑輪，再繞過右定滑輪，往下繞過 C 的動滑輪，最後向上接在 B 的底部。B 與其動滑輪一起運動。
  2. 以天花板為原點、向下為正，令 A、B、C 的位置為 y_A, y_B, y_C。繩長（略去定長）＝ A 段 y_A ＋ B 動滑輪兩側 2y_B ＋ C 右側 y_C ＋ C 左側到 B 底部 (y_C - y_B)：
    y_A + y_B + 2y_C = \text{const.}
  3. 對時間微分兩次：a_A + a_B + 2a_C = 0，代入 2 + 4 + 2a_C = 0，得 a_C = -3\ \mathrm{m/s^2}，負號表示向上，大小 3 m/s²。

考點：繩長拘束條件（繩不可伸長）。對應：P3（國中：理化 滑輪）

誤把 C 段當成只有一段繩，寫成 a_A + 2a_B + a_C = 0；忽略連到 B 底部那一段繩長會隨 B、C 同時改變。

K02-02將一個長度為 L 的圓柱體木塊，沿圓柱方向鉛直壓入水中使圓柱體頂端在水面下 L 處。若木塊比重為 0.4，由靜止放開圓柱體後，它會沿圓柱方向鉛直向上運動並彈出水面。若只考慮重力與浮力而不計其他力的作用，且過程中水面幾乎不變，則圓柱頂面最高會高出水面多遠？
(A) 2L(B) \frac{9}{4}L(C) \frac{10}{4}L(D) \frac{11}{4}L(E) 3L

答案：(D)

  1. 設截面積 A、水密度 ρ，木塊重 W = 0.4\rho g A L。由靜止放開到最高點靜止，動能變化為 0，所以浮力作功＝克服重力作功。
  2. 浮力作功（變力，用「力–位移」圖面積）：頂端由水下 L 升到水面的前 L 段，木塊全浸，浮力 \rho g A L，作功 \rho g A L^2；接著再升 L，浸入長度由 L 線性減為 0，平均浮力 \frac{1}{2}\rho g A L，作功 \frac{1}{2}\rho g A L^2。合計 \frac{3}{2}\rho g A L^2。
  3. 設頂端總共上升 H（H > 2L，木塊離開水面）：
    0.4\rho g A L\cdot H = \frac{3}{2}\rho g A L^2 \ \Rightarrow\ H = 3.75L
  4. 頂端起點在水面下 L，故最高高出水面 3.75L - L = 2.75L = \frac{11}{4}L。

考點：變力作功（面積法）、功能定理。對應：P9（國中：理化 浮力）

誤以為浮力在出水過程中仍是定值 \rho g A L，得到 H = 5L；或忘記扣掉起點的水深 L。

K02-03水波槽內有相距 10 cm 的 A、B 兩個點波源，同時發出波長為 4 cm 之圓形波，且兩波源同步向上也同步向下振動。已知水面上某點到兩點波源之距離差若為半個波長之奇數倍時，水面上該點便不會上下振動，我們稱之為節點。則在過 B 點且垂直 \overline{AB} 之方向上，離 B 點最遠的節點與 B 點之距離為何？
(A) 0(B) 2.25(C) 5.33(D) 10.5(E) 24 cm

答案：(E)

  1. 在過 B 且垂直 AB 的直線上取點 P，\overline{PB} = y，則 \overline{PA} = \sqrt{100 + y^2}，程差 \Delta = \sqrt{100+y^2} - y。
  2. y = 0 時 Δ = 10 cm；y 增大時 Δ 遞減並趨近 0。所以 Δ 只能落在 0～10 cm。
  3. 節點條件 \Delta = (n+\frac{1}{2})\lambda = 2,\ 6,\ 10\ \mathrm{cm}。Δ 愈小，P 愈遠，最遠節點對應 Δ = 2 cm：
    \sqrt{100+y^2} = y + 2 \ \Rightarrow\ 100 = 4y + 4 \ \Rightarrow\ y = 24\ \mathrm{cm}
  4. 其他選項：Δ = 6 得 y = \frac{16}{3} \approx 5.33（較近的節點）；Δ = 10 得 y = 0；Δ = 4、8（波長整數倍，為加強點，不是節點）分別得 10.5 與 2.25。

考點：雙波源干涉的程差條件。對應：P7

誤把「半波長奇數倍」與「波長整數倍」混淆，選到加強點的 (D) 10.5 cm。

K02-04在 25 °C、1 大氣壓時，建國利用下圖的裝置測量氣體的分子量。已知裝在高山用瓦斯罐中的燃料是一種丙烷（\ce{C3H8}）及丁烷（\ce{C4H10}）的混合物，當量筒中收集 380 毫升的燃料氣體時，量筒內外水面等高，秤得瓦斯罐重量減輕 0.736 克，請問瓦斯燃料中丙烷佔的莫耳分率約為多少？（已知水在常溫時的飽和蒸汽壓約為 24 mmHg；理想氣體方程式為：PV = nRT，其中，P 為氣體壓力，V 為體積，n 為莫耳數，T 為絕對溫度（單位 K），1 atm = 760 mmHg，理想氣體常數 R 為 0.082\ \mathrm{\frac{atm\cdot L}{mol\cdot K}}，絕對溫度（K）＝攝氏溫度（°C）＋273）
(A) 0.22(B) 0.35(C) 0.50(D) 0.65(E) 0.78

答案：(D)

  1. 排水集氣：量筒內外水面等高，筒內總壓＝大氣壓。筒內含飽和水蒸氣，燃料氣體的分壓 P = 760 - 24 = 736\ \mathrm{mmHg}。記得扣水蒸氣壓
  2. n = \frac{PV}{RT} = \frac{\frac{736}{760}\times 0.380}{0.082\times 298} = \frac{0.3680}{24.44} \approx 0.01506\ \mathrm{mol}
  3. 平均分子量 \bar M = \frac{0.736}{0.01506} \approx 48.9\ \mathrm{g/mol}。
  4. 設丙烷莫耳分率 x：44x + 58(1-x) = 48.9，x = \frac{58 - 48.9}{14} \approx 0.65。

考點：道耳頓分壓定律、理想氣體方程式、平均分子量。對應：C4、C5

誤直接用 760 mmHg 計算：n ≈ 0.01555 mol，\bar M \approx 47.3，x ≈ 0.76，誤選 (E)。

K02-09在北極點見到一滿月，其形狀如右圖所示，圖中白圓圈所示為月面的一處低地：危海。若同一時間在北緯 45 度左右見此滿月時，其月面之示意圖為何？

答案：(B)

  1. 月面相對於天球的方位固定：月面上指向天北極的方向一晚之中幾乎不變。觀察者所見月面「轉了多少」，取決於當地天頂方向與天北極方向在月亮位置的夾角。
  2. 北極點：天北極就在天頂，任何天體的「指向天北極」都是正上方，題圖即為「天北極朝上」的月面，危海在右側（約 3 點鐘方向）。
  3. 北緯 45°：天球赤道在東、西方地平與地平線夾 90^\circ - 45^\circ = 45^\circ。滿月在東方天空時，沿赤道方向向右上方升起，天北極方向與此垂直，指向左上方，比天頂方向逆時針偏 45°（圖 K02-1）。
  4. 因此月面整體逆時針轉 45°，危海由 3 點鐘移到約 1 點半方向，為 (B)。

K02-18如圖所示，直線為一個透鏡或面鏡之主軸，將小物置於此鏡之主軸上 A 點時，會成像於 B 點；而將小物置於 B 點時，則成像於 C 點，且距離 \overline{AB} > \overline{BC}，則（多選）
(A) 此鏡一定是凹透鏡(B) 此鏡可能是凸面鏡(C) 這兩次成像都是成虛像(D) 透鏡一定在 A 點的左側(E) 面鏡可能在 A 點的右側

答案：(A)(C)

  1. 面鏡：物體必在鏡前。B 要能放物體，B 在鏡前，所以 A 的像 B 是實像，只有凹面鏡做得到。凹面鏡實像：物在 2f 外，像在 f～2f 之間（較近鏡）；物在 f～2f，像在 2f 外（較遠鏡）。A→B 若「變近」，B 在 f～2f，B 的像必在 2f 外「變遠」，方向反轉；A→B 若「變遠」，B 的像又「變近」。兩次像都朝同一方向移動（A→B→C 同向）不可能。凸面鏡只成鏡後虛像，B 不能放物體。故不是面鏡，(B)(E) 錯。
  2. 凸透鏡：若 A→B 為實像，透鏡在 A、B 之間，B 距透鏡大於 f；B 當物體時須成像在同側的 C，只有物距小於 f 的虛像才在同側，矛盾。若兩次都是虛像，透鏡在 A 左側，像距 q = \frac{pf}{f-p} 隨 p 增加得愈來愈快，會得到 \overline{BC} > \overline{AB}，與題意不符。
  3. 凹透鏡：恆成正立縮小虛像，像與物同側且較靠近透鏡。透鏡在 C 的右側：A→B→C 依次靠近透鏡，且像距 q = \frac{p|f|}{p+|f|} 變化較物距平緩，\overline{AB} > \overline{BC}。例：|f| = 10\ \mathrm{cm}，p = 30 cm → q = 7.5 cm → 再成像 4.3 cm，AB ＝ 22.5 cm，BC ≈ 3.2 cm。
  4. 所以一定是凹透鏡 (A)，兩次都是虛像 (C)；透鏡在 C 的右側，(D) 錯。

考點：面鏡與透鏡成像規律、成像位置隨物距的變化。對應：P8（國中：理化 光學；進階：透鏡成像公式）
