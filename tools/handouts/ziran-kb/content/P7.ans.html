P7　波動與聲音

P7-01 (A) 相鄰波峰與波谷相距 \lambda/2，故 \lambda = 0.50\ \mathrm{m}；每秒 4 個波峰通過，f = 4.0\ \mathrm{Hz}；v = f\lambda = 2.0\ \mathrm{m/s}。(E) 誤以 0.25 m 為波長；(C) 為 f/\lambda；(D) 為 \lambda/f；(B) 為無意義的相加。
P7-02 (A)(C)(E) (A) 超聲波為聲波，屬力學波。(C) 地震 S 波為在岩石中傳播的力學波。(E) 水面波靠水傳遞。(B)(D) 無線電波與 X 射線皆為電磁波，可在真空中傳播。
P7-03 (A)(C)(D) (A) 波傳遞能量。(B) 質點只在平衡位置附近振動，不隨波前進。(C) 頻率由波源決定，換介質不變。(D) 同介質波速固定，\lambda = v/f，頻率加倍則波長減半。(E) 波速由介質決定，與頻率無關。
P7-04 (D) 同一音符基頻相同（A、E 相同），相同響度即振幅相近（B），同一空氣中聲速相同（C）。音色取決於諧音組成，表現為波形不同。
P7-05 (E) 聲強級差 30 dB，I_甲/I_乙 = 10^{30/10} = 10^3 = 1000。(B) 誤把分貝差當倍數；(C) 為 20 dB 的倍數。
P7-06 (B) 聲音來回所需時間 1.2 s，d = vt/2 = 340\times1.2/2 = 204\ \mathrm{m}。(D) 忘記除以 2。
P7-07 (B)(C)(E) (B) 由反射微波的頻移得車速。(C) 由紅血球反射超聲波的頻移得血流速率。(E) 光譜線紅移、藍移即都卜勒效應。(A) 聲納測深是利用回波時間，與頻移無關。(D) 光纖通訊利用全反射。
P7-08 (C) 固定端反射，反射脈波倒立；同一介質中波速、寬度不變，無能量損失時振幅不變。
P7-09 (A) 頻率由音叉決定不變，\lambda \propto v。v_{10} = 331 + 6 = 337\ \mathrm{m/s}，v_{30} = 331 + 18 = 349\ \mathrm{m/s}，349/337 \approx 1.036，波長變長約 3.6%。(D) 誤以攝氏溫度比 3 倍計算。
P7-10 (A)(B)(D) 波向 +x 傳。(A) 波峰處質點速度為零。(B) Q 在下坡段，波形右移後該處位移增大，向上運動。(C) S 在上坡段，向下運動。(D) R 在波谷，回復力指向平衡位置，加速度向上。(E) 質點只上下振動，不沿 x 方向移動。
P7-11 (D) 由 y-t 圖讀得週期 T = 0.40\ \mathrm{s}（振幅 3 cm 為干擾資訊）。\lambda = vT = 5.0\times0.40 = 2.0\ \mathrm{m}。(E) 為 v/T；(A) 為 T/v；(B) 誤以 0.1 s（四分之一週期）為週期；(C) 誤以 0.2 s（半週期）為週期。
P7-12 (B)(D) (A) 反射脈波仍在細繩中，波速不變，寬度與入射脈波相同。(B) 透射波一律正立。(C) 頻率由波源決定，兩繩相同。(D) 由快介質到慢介質，反射波倒立。(E) 進入慢介質，脈波變窄。
P7-13 (B) \sin\theta_2 = \sin\theta_1\cdot\lambda_2/\lambda_1 = 0.5\times2.0/3.0 = 1/3。(E) 誤把波長比倒置：0.5\times1.5 = 0.75；(A) 誤乘 1/3。
P7-14 (A)(C)(E) 路程差範圍 0 \le \Delta < 4.0\ \mathrm{cm}。(A) 中垂線 \Delta = 0，為腹線。(B) 腹線 \Delta = 0, 1.5, 3.0，共 1 + 2\times2 = 5 條。(C) 節線 \Delta = 0.75, 2.25, 3.75，共 6 條。(D) \Delta = 9.0 - 6.75 = 2.25 = 1.5\lambda，為節線上的點。(E) 波長變 0.75 cm，節線 \Delta = 0.375, 1.125, 1.875, 2.625, 3.375，共 10 條，增加。
P7-15 (E) 拍頻 3 表示待測頻率為 437 或 443 Hz。黏土使頻率降低：若原為 443 Hz，降低後接近 440 Hz，拍頻變小（如 441 Hz 時為 1）；若原為 437 Hz，降低後更遠離 440 Hz，拍頻應變大。故為 443 Hz。(A) 未考慮黏土使頻率降低的方向。
P7-16 (B)(C)(D)(E) 3 個腹點即 n = 3，\lambda = 2L/3 = 0.80\ \mathrm{m}（B 正確）。v = f\lambda = 150\times0.80 = 120\ \mathrm{m/s}（A 錯，180 m/s 為誤用 \lambda = 1.2\ \mathrm{m}）。相鄰節點相距 \lambda/2 = 0.40\ \mathrm{m}（C）。基頻 150/3 = 50\ \mathrm{Hz}（D）。v \propto \sqrt{F}，張力 4 倍則波速 2 倍，同模式頻率 300 Hz（E）。
P7-17 (B) 閉管 f_n = (2n-1)v/(4L) = (2n-1)\times340/3.4 = (2n-1)\times100\ \mathrm{Hz}，即 100、300、500、700 Hz……只有奇數倍。200 Hz 為偶數倍，不會共鳴。
P7-18 (A)(C)(D) (A) 接近時頻率升高。(B) 行車路線與觀察者有垂直距離，接近過程中速度在視線方向的分量逐漸變小，頻率逐漸降低（仍高於原頻率），並非升高。(C) 最近點附近視向分量由接近迅速轉為遠離，頻率迅速下降。(D) 司機與警笛相對靜止、空氣靜止，頻率不變。(E) 無風時聲速相對地面不變。
P7-19 (C) 聲強加倍，\beta = 70 + 10\log2 \approx 73\ \mathrm{dB}。(E) 誤將分貝直接相加；(D) 誤以加倍為 +10 dB。
P7-20 (A) 距離 10 倍，聲強變 1/100，聲強級減少 10\log100 = 20\ \mathrm{dB}，得 60 dB。(B) 誤以聲強與距離成反比；(E) 誤以分貝與距離成反比。
P7-21 (B)(D)(E) (A) 同一介質中各頻率聲速相同。(B) v = \sqrt{\gamma RT/M}，氦的莫耳質量小，聲速大（約為空氣中的 3 倍）。(C) 溫度不變時 P/\rho 不變，聲速不變。(D) 鋼中約 5900 m/s。(E) 頻率不變、水中聲速較大，波長變長。
P7-22 (D) 繞射明顯的條件是開口或障礙物尺度與波長相近。語音波長約 0.1 m 至數公尺，光波長約 10^{-7}\ \mathrm{m} 量級。(A) 繞射與速率無直接關係；(B) 橫波同樣會繞射（光的單狹縫繞射即為例）；(C)(E) 非主因。
P7-23 (A)(B)(E) (A) \lambda' = (v - v_s)/f = 306/900 = 0.34\ \mathrm{m}。(B) f' = v/\lambda' = 340/0.34 = 1000\ \mathrm{Hz}。(C) 觀察者運動：f' = 900\times(340+34)/340 = 990\ \mathrm{Hz}，與 1000 Hz 不同。(D) 聲速相對靜止空氣恆為 340 m/s，與波源運動無關。(E) 後方 f' = 900\times340/(340+34) \approx 818\ \mathrm{Hz}。
P7-24 (C) 汽車先作為接近的觀察者接收，頻率約 f(1 + u/c)；再作為接近的波源反射，頻率再乘約 (1 + u/c)。u \ll c 時 \Delta f \approx 2uf/c = 2\times30\times2.40\times10^{10}/(3.00\times10^8) = 4800\ \mathrm{Hz}。(B) 漏乘 2（只算一次頻移）；(D) 多乘 2。
P7-25 (B)(C)(D) (A) 超音速飛行期間震波錐面持續掃過地面，沿途都聽得到音爆。(B) \sin\theta = v/v_s = 1/1.5 = 2/3。(C) 飛機在正上方時錐面尚未到達觀察者，須稍後才聽到。(D) v_s 愈大，\sin\theta 愈小，圓錐愈尖。(E) 聲速由空氣溫度決定，震波為波前疊加所致。
P7-26 (E) 開管 f_0 = v/(2L)，共鳴頻率為 f_0, 2f_0, 3f_0, \ldots。封閉後基頻 v/(4L) = f_0/2，共鳴頻率為 0.5f_0, 1.5f_0, 2.5f_0, \ldots（半整數倍）。整數與半整數無交集，故沒有共同頻率。(D) 只符合閉管；(A)(B)(C) 只符合開管。

P7-33 參考答案：(1) 弦上有 3 個節點（兩端與中點，x = 0、0.30 m、0.60 m）與 2 個腹點（x = 0.15 m、0.45 m）；實線在左半向上、右半向下，虛線相反（同圖 P7-15 的 n = 2）。(2) n = 2 時 L = \lambda，\lambda = 0.60\ \mathrm{m}，v = f\lambda = 200\times0.60 = 120\ \mathrm{m/s}。(3) 基頻 f_1 = f_2/2 = 100\ \mathrm{Hz}（或 v/(2L) = 120/1.2 = 100\ \mathrm{Hz}）。評分要點：節點含兩端、腹點位置正確；波速與基頻計算正確。
P7-34 參考答案：(1) \lambda = v/f = 1540/(5.0\times10^6) \approx 3.1\times10^{-4}\ \mathrm{m}（約 0.31 mm）。(2) 來回時間 65 μs，深度 d = vt/2 = 1540\times65\times10^{-6}/2 \approx 0.050\ \mathrm{m} = 5.0\ \mathrm{cm}。(3) 頻率愈高，波長愈短，可分辨較小的構造，解析度較佳；但超聲波在組織中的衰減隨頻率增加，可探測深度較淺。故淺層器官多用較高頻率，深部器官用較低頻率。
P7-35 參考答案：(1) 晴朗無風的夜晚，地面輻射冷卻，近地面空氣較冷、上方較暖，形成逆溫（氣溫隨高度增加）。(2) 聲速隨溫度升高而增加，上方聲速較大。斜向上傳播的聲波，波前上半部前進較快、下半部較慢，波前向下偏轉，聲線向聲速較小的地面方向彎曲（類似由快介質進入慢介質時偏向法線），斜向上的聲線因而彎回地面，遠處仍可接收到，聲音傳得較遠。示意圖：地面上的聲源發出多條向上斜射的聲線，呈向下彎的弧線落回遠處地面（同圖 P7-11）。白天地面較熱、上方較冷，聲線向上彎，遠處地面不易聽到。
