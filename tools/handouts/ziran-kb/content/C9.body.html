C9　氧化還原

本單元範圍：氧化還原的定義與氧化數、氧化劑與還原劑、金屬活性序列、化學電池、電解與電鍍（進階）、腐蝕與防鏽、漂白與消毒。電池材料與能源議題見 C11；酸鹼中和見 C8。

本單元的核心工具

  • 判斷：氧化數有升有降者為氧化還原反應。
  • 指認：氧化數升高者被氧化，為還原劑；氧化數降低者被還原，為氧化劑。
  • 計量：還原劑失去的電子總數＝氧化劑得到的電子總數（電子守恆）。
  • 強弱：較強氧化劑＋較強還原劑 → 較弱還原劑＋較弱氧化劑。

一、氧化還原定義的演進

三種定義由窄到寬：得失氧 → 得失電子 → 氧化數升降。

考題一律以氧化數判斷最保險。

1. 得失氧：拉瓦節的燃燒理論

  • 18 世紀流行燃素說：可燃物含「燃素」，燃燒時燃素逸出。此說無法解釋金屬煅燒後質量增加，支持者甚至假設燃素具有負質量。
  • 拉瓦節（Antoine-Laurent Lavoisier，1743–1794）以密閉容器與精密天平進行定量實驗，1777 年提出不需燃素的燃燒理論：燃燒與煅燒是物質與空氣中「最適於呼吸的部分」化合。他將此氣體命名為 oxygène（希臘文「生成酸者」），因他誤以為所有酸都含氧。
  • 早期定義：物質與氧化合稱為氧化；含氧化合物失去氧稱為還原。例：\ce{2Mg + O2 -> 2MgO}（Mg 被氧化）；\ce{CuO + H2 ->[\Delta] Cu + H2O}（CuO 被還原）。
  • 擴充：有機化學常用「得氫為還原、失氫為氧化」，如乙醇脫氫生成乙醛為氧化。

2. 得失電子：廣義定義（課綱定義）

  • 20 世紀初電子的角色確立後，定義擴充為：失去電子為氧化，獲得電子為還原。
  • 鈉在氯氣中燃燒，沒有氧參與，仍為氧化還原：\ce{2Na + Cl2 -> 2NaCl}。拆成半反應：氧化半反應 \ce{Na -> Na+ + e-}；還原半反應 \ce{Cl2 + 2e- -> 2Cl-}。
  • 電子不能憑空產生或消失，故氧化與還原必同時發生，且失去與獲得的電子數相等。電子守恆是計量的依據

3. 共價化合物的問題與氧化數

\ce{H2 + Cl2 -> 2HCl} 生成共價分子，電子並未完全轉移，只是共用電子對偏向 Cl。為統一處理離子與共價物質，引入氧化數：假設異種原子間的鍵結電子全歸電負度較大者，原子所帶的「假想電荷」。以氧化數表述的定義：氧化數升高為氧化，降低為還原。此定義涵蓋前兩個定義。

升、失、氧（還原劑）；降、得、還（氧化劑）

氧化數升高 → 失去電子 → 被氧化 → 該物為還原劑；反之為氧化劑。

  • 氧化與還原是同一反應的兩面，不存在只有氧化而無還原的反應。
  • 「被氧化」指該物質本身失去電子；「氧化劑」指使他物被氧化的物質，其本身被還原。
  • 有元素態物質參與的反應不一定是氧化還原，例如 \ce{3O2 -> 2O3}（同素異形體互變，氧化數皆為 0）。

學測常給一組反應式，要求選出氧化還原反應，誘答多為有單質但氧化數不變（\ce{3O2 -> 2O3}）或無單質但有電子轉移（\ce{Fe^3+} 與 \ce{I-}）的反應。

深究　燃素說為何被取代

  • 關鍵證據是質量：金屬煅燒後的「金屬灰」（今稱氧化物）比原金屬重；在密閉容器中煅燒，容器總質量不變，而容器內空氣體積減少。拉瓦節以「金屬與空氣的一部分化合」同時解釋增重與空氣減少，並以質量守恆作為化學的基本原則（見 C5）。
  • 普利士力（Joseph Priestley）1774 年加熱氧化汞得到助燃的氣體，但他以「去燃素空氣」解釋；舍勒（Carl Wilhelm Scheele）更早製得此氣體，發表較晚。同一實驗事實可有不同的理論詮釋，理論的取捨取決於能否一致解釋全部的定量數據。
  • 「氧化」一詞沿用至今，但已與氧脫鉤：氟使氧氧化（\ce{OF2} 中 O 為 +2），氧在此反而是被氧化的一方。

二、氧化數

1. 定義與規則

定義：將化合物中異種原子間的鍵結電子全部歸給電負度較大的原子，同種原子間的鍵結電子平分，此時原子所帶的電荷數即為其氧化數。氧化數為記帳用的形式值，以「+2」「−1」表示，可為分數（平均值）。不等於實際電荷

規則內容示例
1. 元素態氧化數為 0\ce{Na}、\ce{O2}、\ce{O3}、\ce{S8}、\ce{P4} 中各原子皆為 0
2. 單原子離子氧化數＝離子電荷\ce{Fe^3+} 為 +3，\ce{S^2-} 為 −2
3. 總和中性化合物各原子氧化數總和為 0；多原子離子總和等於離子電荷\ce{SO4^2-}：x + 4(-2) = -2，S 為 +6
4. 氟與金屬F 在化合物中恆為 −1；1 族金屬 +1，2 族金屬 +2，Al 為 +3\ce{CaF2}：Ca +2、F −1
5. 氫通常 +1；與活性金屬形成的氫化物中為 −1\ce{NaH}、\ce{CaH2}、\ce{LiAlH4} 中 H 為 −1
6. 氧通常 −2；過氧化物 −1；超氧化物 -\frac{1}{2}（進階）；\ce{OF2} 中 +2\ce{H2O2}、\ce{Na2O2}、\ce{BaO2} 中 O 為 −1；\ce{KO2} 中 O 為 -\frac{1}{2}

規則衝突時的優先順序：F ＞ 1、2 族金屬 ＞ H ＞ O。例：\ce{OF2} 中 F 先定為 −1，O 只能是 +2；\ce{NaH} 中 Na 先定為 +1，H 只能是 −1。

2. 常見計算

物質待求原子算式氧化數
\ce{KMnO4}Mn1 + x + 4(-2) = 0+7
\ce{K2Cr2O7}Cr2 + 2x + 7(-2) = 0+6
\ce{Fe3O4}Fe（平均）3x + 4(-2) = 0+\frac{8}{3}（實為 1 個 Fe2+ 與 2 個 Fe3+）
\ce{S4O6^2-}S（平均）4x + 6(-2) = -2+2.5
\ce{NH4NO3}N分兩離子計：\ce{NH4+}、\ce{NO3-}−3 與 +5
\ce{LiCoO2}Co1 + x + 2(-2) = 0+3
  • \ce{NH4NO3}、\ce{NH4NO2} 這類含兩種氮的化合物，平均值（+1、0）不能反映實際的電子得失，須分開計算。
  • 平均氧化數可為分數；個別原子的氧化數依結構而定（例如 \ce{S2O3^2-} 平均 +2，兩個 S 的環境不同）。
  • 氧化數與離子電荷寫法不同：氧化數寫「+2」，離子電荷寫「2+」（\ce{Fe^2+}）。

氧化數計算常與新材料結合命題，如鋰電池正極 \ce{LiCoO2}、\ce{LiFePO4}（Fe 為 +2）、半導體材料。先固定 Li、O、F 等「確定值」，再求未知原子。

3. 氧化數梯與物種的角色

  • 元素的最高氧化數通常等於其最外層價電子數（主族元素），如 N +5、S +6、Cl +7；最低氧化數為「價電子數 − 8」，如 N −3、S −2、Cl −1。
  • 處於最高氧化數的物種（\ce{HNO3}、\ce{H2SO4} 中的 S、\ce{MnO4-}）只能得電子，作氧化劑；處於最低者（\ce{NH3}、\ce{H2S}、\ce{I-}）只能作還原劑；居中者（\ce{SO2}、\ce{H2O2}、\ce{Fe^2+}、\ce{NO2}、\ce{Cl2}）視反應對象而定。

中間價態「兩面人」：SO2、H2O2、Fe2+、NO2、Cl2。

遇強氧化劑 → 當還原劑；遇強還原劑 → 當氧化劑。

深究　有機物中碳的氧化數與「氧化程度」

以 C 與 H、O 的電負度判定：C—H 鍵電子歸 C，C—O 鍵電子歸 O。單碳化合物：\ce{CH4} −4、\ce{CH3OH} −2、\ce{HCHO} 0、\ce{HCOOH} +2、\ce{CO2} +4。二碳化合物的碳平均氧化數：乙醇 \ce{C2H5OH} −2 → 乙醛 \ce{CH3CHO} −1 → 乙酸 \ce{CH3COOH} 0。由此可知醇 → 醛 → 酸為逐步氧化，與「失氫、得氧」的說法一致。生物的細胞呼吸將葡萄糖（C 平均 0）氧化為 \ce{CO2}（+4），每個碳失去 4 個電子，電子最後交給 \ce{O2}；光合作用則把 \ce{CO2} 還原為醣類，所需電子來自水，釋出的 \ce{O2} 來自水分子（跨科連結 B2）。

三、氧化劑與還原劑

1. 定義

名稱本身的變化氧化數對他物的作用
氧化劑得到電子，被還原降低使他物氧化
還原劑失去電子，被氧化升高使他物還原

\ce{Fe2O3 + 3CO ->[\text{高溫}] 2Fe + 3CO2}示例：高爐煉鐵。Fe +3 → 0，Fe2O3 為氧化劑；C +2 → +4，CO 為還原劑。

\ce{MnO2 + 4HCl(濃) ->[\Delta] MnCl2 + Cl2 + 2H2O}示例：實驗室製氯氣。Mn +4 → +2，MnO2 為氧化劑；4 個 HCl 中只有 2 個的 Cl 由 −1 升為 0，其餘 2 個的 Cl 仍為 −1（提供酸性並形成鹽）。

4. 強弱比較

  • 自發的氧化還原反應：較強氧化劑 ＋ 較強還原劑 → 較弱還原劑 ＋ 較弱氧化劑。強制弱即反應物中的氧化劑強於產物中的氧化劑，反應物中的還原劑強於產物中的還原劑。
  • 一物質的氧化力越強，其還原產物（共軛還原態）的還原力越弱。例：F2 氧化力最強，F− 幾乎無還原力；Li 還原力極強，Li+ 幾乎無氧化力。
  • 鹵素置換：\ce{Cl2 + 2Br- -> 2Cl- + Br2}；\ce{Br2 + 2I- -> 2Br- + I2}；反向不發生。

階梯圖用法：左欄（氧化劑）在上、右欄（還原劑）在下，兩者可自發反應。

即「左上配右下」。

5. 自身氧化還原（歧化）

定義：同一物質中同種元素的原子，部分氧化數升高、部分降低。常見於氧化數居中的物種。

  • \ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}：Cl 由 0 變為 −1 與 +1；工業製漂白水。
  • \ce{2H2O2 -> 2H2O + O2}：O 由 −1 變為 −2 與 0；MnO2 或過氧化氫酶可催化。
  • \ce{3NO2 + H2O -> 2HNO3 + NO}：N 由 +4 變為 +5 與 +2；與酸雨、硝酸工業有關（見 C11）。

反方向的情形（不同氧化數的同種元素生成居中氧化數）稱為逆歧化（學術名詞亦作「歸一反應」），例：\ce{NaClO + 2HCl -> NaCl + Cl2 + H2O}，Cl 由 +1 與 −1 變為 0，即漂白水與鹽酸類清潔劑混用產生氯氣的原因。居家安全常考

深究　同一物質為何有時是氧化劑、有時是還原劑

H2O2 中 O 為 −1，可降為 −2（作氧化劑），也可升為 0（作還原劑）。遇較強的還原劑（I−、Fe2+）時作氧化劑：\ce{H2O2 + 2I- + 2H+ -> I2 + 2H2O}；遇更強的氧化劑（酸性 MnO4−）時作還原劑：\ce{2MnO4- + 5H2O2 + 6H+ -> 2Mn^2+ + 5O2 + 8H2O}。「氧化劑」「還原劑」是反應中的角色，並非物質固定的屬性；判斷時須看同一反應中氧化數的實際變化。

四、氧化還原反應式的平衡與計量（進階）

1. 半反應法（酸性溶液）

  1. 寫出氧化與還原兩個半反應的主要物種。
  2. 平衡 O、H 以外的原子。
  3. 以 \ce{H2O} 平衡 O；以 \ce{H+} 平衡 H。
  4. 以電子平衡電荷。
  5. 兩半反應乘上適當倍數使電子數相等，相加並消去相同項。
  6. 檢查：原子數與總電荷兩邊相等。

\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}　\ce{Fe^2+ -> Fe^3+ + e-}示例：兩半反應，後者乘 5 相加得 \ce{MnO4- + 5Fe^2+ + 8H+ -> Mn^2+ + 5Fe^3+ + 4H2O}；電荷兩邊皆為 +17。

鹼性溶液：先依酸性步驟平衡，再於兩邊加入與 H+ 等量的 OH−，使 H+ 與 OH− 合為 H2O。

2. 氧化數法

求出氧化劑每單位氧化數的總降低量與還原劑的總升高量，取最小公倍數決定係數，再以觀察法平衡其餘原子。

\ce{3Cu + 8HNO3(稀) -> 3Cu(NO3)2 + 2NO + 4H2O}示例：Cu 0 → +2（升 2），N +5 → +2（降 3）；Cu 與被還原的 N 為 3 : 2。8 個 HNO3 中只有 2 個被還原，其餘 6 個提供 NO3−。

\ce{Cu + 4HNO3(濃) -> Cu(NO3)2 + 2NO2 + 2H2O}示例：濃硝酸的還原產物為 NO2（N 降 1），故 Cu 與被還原的 N 為 1 : 2。

3. 電子守恆與氧化還原滴定

n_{\text{還原劑}} \times a = n_{\text{氧化劑}} \times b

n：莫耳數　a：每單位還原劑失去的電子數　b：每單位氧化劑獲得的電子數（＝氧化數變化量 × 該原子個數）

  • 過錳酸鉀滴定：以硫酸酸化，MnO4− 每個得 5 個電子；終點時微過量的 MnO4− 使溶液呈淡紫紅色且維持不褪，不需另加指示劑。
  • 不以鹽酸酸化：Cl− 會被 MnO4− 氧化，使滴定體積偏大；不以硝酸酸化：硝酸本身為氧化劑，干擾結果。
  • 常見被滴定物：Fe2+（每個失 1 個電子）、H2C2O4（每分子失 2 個電子）、H2O2（每分子失 2 個電子）。
  • 碘滴定（進階）：以澱粉為指示劑，I2 與 S2O32− 反應：\ce{I2 + 2S2O3^2- -> 2I- + S4O6^2-}，可測定維生素 C 或漂白水的有效氯。

氧化還原滴定為學測計算題常客：MnO4− 得 5e−、Cr2O72− 得 6e−、Fe2+ 失 1e−、H2C2O4 與 H2O2 各失 2e−，背熟可直接列式。

  • 一個 \ce{Cr2O7^2-} 含 2 個 Cr，每個降 3，共得 6 個電子；只算 3 個是常見錯誤。
  • \ce{H2C2O4} 中 2 個 C 各由 +3 升為 +4，每分子失 2 個電子。
  • 參與反應的酸不一定全部被還原（如稀硝酸 8 個中只有 2 個），計算「被還原的硝酸」時須區分。

五、金屬活性序列

活性＝失去電子的傾向＝作為還原劑的強度。

位置越前，金屬越易被氧化，其離子越難被還原。

定義：依金屬在水溶液中失去電子形成陽離子的難易排列的順序，稱為金屬活性序列（又稱離子化傾向）。常用序列：

K ＞ Na ＞ Ca ＞ Mg ＞ Al ＞（C）＞ Zn ＞ Fe ＞ Ni ＞ Sn ＞ Pb ＞（H）＞ Cu ＞ Hg ＞ Ag ＞ Pt ＞ Au

鉀鈉鈣鎂鋁，（碳）鋅鐵鎳錫鉛，（氫）銅汞銀鉑金

1. 由序列可推論的反應

  • 與水：K、Na、Ca 在常溫與水反應生成氫氣與氫氧化物，如 \ce{2Na + 2H2O -> 2NaOH + H2}；Mg 與熱水緩慢反應；Zn、Fe 在高溫下與水蒸氣反應，如 \ce{3Fe + 4H2O(g) ->[\text{高溫}] Fe3O4 + 4H2}。
  • 與非氧化性酸（稀鹽酸、稀硫酸）：排在 H 之前者可被 H+ 氧化而放出氫氣：\ce{Zn + 2H+ -> Zn^2+ + H2}；Cu、Ag、Au 不反應。
  • 與氧化性酸：Cu、Ag 可溶於硝酸或熱濃硫酸，此時氧化劑為 \ce{NO3-} 或 \ce{H2SO4} 分子，產物為 NO、NO2 或 SO2，不產生氫氣。Au、Pt 只溶於王水（濃鹽酸與濃硝酸體積比 3 : 1）。
  • 金屬置換：活性大的金屬可把活性小的金屬離子還原成金屬：\ce{Zn + Cu^2+ -> Zn^2+ + Cu}、\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}（銅樹、銀樹實驗）。反向不發生。
  • Na 放入 CuSO4 溶液不會析出銅：Na 先與水反應生成 NaOH 與 H2，NaOH 再與 Cu2+ 生成藍色 Cu(OH)2 沉澱。
  • Al 雖排在 Fe 之前，鋁製品在空氣中卻耐腐蝕：表面生成緻密的 Al2O3 薄膜阻隔內部（見八）。活性大≠易腐蝕
  • Fe、Al 遇冷的濃硝酸或濃硫酸會鈍化：表面生成緻密氧化層而停止反應，故濃硫酸可用鐵槽儲運。
  • 鉀、鈉、鈣的先後依判準不同：以標準還原電位排列為 K ＞ Ca ＞ Na；以與水反應的劇烈程度，Na 較 Ca 劇烈（Ca(OH)2 溶解度小）。各教材排序略有出入，依所用教材為準；此細節非學測重點。

2. 活性與金屬的冶煉

金屬自然界存在形式工業製法
K、Na、Ca、Mg、Al化合物（離子極難還原）電解熔融化合物，如鋁以電解溶於熔融冰晶石的 Al2O3 製得
Zn、Fe、Sn、Pb氧化物、硫化物以焦炭或 CO 還原（硫化物先焙燒成氧化物）

人類使用金屬的先後大致與活性相反：金、銀、銅最早，鐵次之，鋁直到 1886 年霍爾（Charles Martin Hall）與埃魯（Paul Héroult）各自發明電解法後才得以大量生產。活性越大，越晚被大量利用

學測常以「金屬片放入鹽類溶液是否有變化」的實驗結果，推論未知金屬的活性順序；也常考金屬片質量增減（析出金屬與溶出金屬的莫耳質量不同）。

深究　鋰的還原力為何最強

鋰的第一游離能（約 520 kJ/mol）比鈉、鉀、銫都大，在氣相中最不易失去電子；然而在水溶液中，Li 的標準還原電位（−3.04 V）卻比 K（−2.93 V）更負。原因在於水溶液中的反應包含三步：金屬原子化（吸熱）、游離（吸熱）、氣態離子水合（放熱）。Li+ 半徑最小、電荷密度最大，水合時放出的能量特別多，足以抵消較大的游離能。因此「活性序列」描述的是水溶液中的行為，與氣相的游離能趨勢不同；大學普通化學以玻恩—哈伯循環與吉布斯自由能處理此問題。

六、化學電池

1. 原理

  • 化學電池（伽凡尼電池）：把自發的氧化還原反應拆成兩個半反應，分置兩處，使電子經外電路由還原劑流向氧化劑，將化學能轉換為電能。
  • 電子流出的一極為負極（陽極），發生氧化；電子流入的一極為正極（陰極），發生還原。陽極的定義是發生氧化的電極，電池與電解皆同，故電池的負極即陽極、正極即陰極。
  • 電路須形成迴路：電子走導線，離子走溶液（鹽橋）。

陽氧陰還（陽極氧化、陰極還原），電池、電解皆適用

2. 鋅銅電池（丹尼爾電池）

1836 年丹尼爾（John Frederic Daniell，1790–1845）以分隔的兩種溶液改良伏打電堆，避免氫氣泡附著電極使電流衰減，可長時間提供穩定電流，曾廣泛用於電報。

鹽橋三功能：導通離子、維持兩杯電中性、避免兩溶液直接混合。

拿掉鹽橋 → 斷路，電流為零。

  • 負極（陽極）：\ce{Zn(s) -> Zn^2+(aq) + 2e-}，鋅片質量減少，Zn2+ 增加。
  • 正極（陰極）：\ce{Cu^2+(aq) + 2e- -> Cu(s)}，銅片質量增加，藍色變淡。
  • 全反應：\ce{Zn(s) + Cu^2+(aq) -> Zn^2+(aq) + Cu(s)}；標準狀態電壓 1.10 V。
  • 鹽橋（如 KNO3 洋菜凍）：陰離子 NO3− 移向負極槽（中和增加的 Zn2+），陽離子 K+ 移向正極槽（補充減少的 Cu2+）。鹽橋所用的鹽不可與兩槽離子沉澱或反應。
  • 電池符號（進階）：\ce{Zn | Zn^2+ || Cu^2+ | Cu}，單線表相界，雙線表鹽橋；負極寫左。
  • 電子不經過溶液與鹽橋；溶液中只有離子移動。
  • 鋅片減少的質量（65.4 g/mol）與銅片增加的質量（63.5 g/mol）不相等；轉移相同電子數時兩者莫耳數相等。
  • 鋅片若直接浸入 CuSO4，反應在鋅表面直接發生，化學能轉為熱，無電流輸出。

3. 標準還原電位與電池電壓（進階）

  • 以標準氫電極（\ce{2H+ + 2e- <=> H2}，1 M H+、1 atm H2、25 °C）為 0 V，其他半反應寫成還原式所測得的電位稱標準還原電位 E^\circ（數值見圖 C9-4）。
  • E^\circ 越大，氧化態越易得電子（氧化力越強）；越小，還原態越易失電子（還原力越強）。
E^\circ_{\text{電池}} = E^\circ_{\text{正極（還原）}} - E^\circ_{\text{負極（氧化）}}

E^\circ：標準還原電位（V）。E^\circ_{\text{電池}} > 0 表示反應在標準狀態下自發。電位為強度性質，半反應乘以係數時 E^\circ 不變。

E^\circ = 0.80 - (-0.76) = 1.56\ \mathrm{V}示例：鋅銀電池，\ce{Zn + 2Ag+ -> Zn^2+ + 2Ag}；Ag+ 的半反應乘 2，電位仍為 0.80 V。

學測電池題多以裝置圖命題：指認正負極、寫半反應、判斷電子流向與鹽橋離子移動方向、比較電極質量變化。給定電位表時，以「正極電位減負極電位」求電壓。

  • 乾電池：1866 年勒克朗社（Georges Leclanché）發明以 NH4Cl 溶液為電解質的濕電池；1886 年加斯納（Carl Gassner）改為糊狀電解質，成為乾電池。鋅筒本身是負極，用久變薄可能漏液。正極反應的實際產物複雜，高中以 Mn +4 → +3 的簡化式表示。
  • 鹼性電池：全反應可簡寫為 \ce{Zn + 2MnO2 -> ZnO + Mn2O3}；鋅以粉末增加表面積，可輸出較大電流。
  • 鉛蓄電池：1859 年普朗特（Gaston Planté）發明，第一種可充電電池。放電：\ce{Pb + PbO2 + 2H2SO4 -> 2PbSO4 + 2H2O}。兩極都生成難溶的 PbSO4 而質量增加，硫酸被消耗、溶液密度下降，可由密度判斷殘電量。汽車用 12 V 電池為 6 個單電池串聯。放電：兩極皆增重
\begin{aligned} \text{負極（陽極）：}&\ \ce{Pb + SO4^2- -> PbSO4 + 2e-} \\ \text{正極（陰極）：}&\ \ce{PbO2 + 4H+ + SO4^2- + 2e- -> PbSO4 + 2H2O} \end{aligned}
  • 鋰電池與鋰離子電池：鋰是最輕的金屬且還原力最強，故單位質量儲存的能量高、電壓高。「鋰一次電池」以鋰金屬為負極，不可充電；「鋰離子電池」中鋰以 Li+ 的形式在兩極的層狀結構間嵌入、脫出（搖椅式電池），不含鋰金屬。放電時 Co 由 +4 還原為 +3。
  • 2019 年諾貝爾化學獎頒給古迪納夫（John B. Goodenough）、惠廷漢（M. Stanley Whittingham）、吉野彰（Akira Yoshino），表彰鋰離子電池的發展：惠廷漢於 1970 年代以 TiS2 為正極；古迪納夫於 1980 年改用鈷氧化物使電壓提高至約 4 V；吉野彰於 1985 年以碳材料取代鋰金屬負極，1991 年商品化。
  • 電解液不能用水：電池電壓超過水的分解電壓（理論 1.23 V），且鋰與水劇烈反應，故用鋰鹽的有機溶液，也因此有可燃、過熱起火的風險。

深究　電壓、能量與「沒電」的本質

  • 電池做的電功 W = nFE（n：轉移電子莫耳數，F = 96485\ \mathrm{C/mol}，法拉第常數）。大學化學以 \Delta G^\circ = -nFE^\circ 連結電位與自由能：鋅銅電池每莫耳 Zn 反應可提供最多 2 \times 96485 \times 1.10 \approx 2.12\times10^{5}\ \mathrm{J}。
  • 電壓由反應物種類（與濃度）決定，為強度性質；可提供的總電量（容量）取決於反應物的量，為外延性質。大號與小號乾電池電壓相同，容量不同。
  • 濃度影響電壓（能斯特方程式，進階）：增加反應物濃度或降低生成物濃度，電壓上升，與勒沙特列原理方向一致。放電過程中 [Cu2+] 降低、[Zn2+] 升高，電壓逐漸下降；反應達平衡時電壓為零，即「沒電」。

七、電解與電鍍（進階）

1. 電解

  • 電解：以外加直流電源使非自發的氧化還原反應發生，將電能轉換為化學能。裝置稱電解槽。
  • 接電源正極者為陽極，發生氧化；接電源負極者為陰極，發生還原。陰離子移向陽極，陽離子移向陰極。
  • 相關名詞定於 1834 年：法拉第（Michael Faraday，1791–1867）發表電解研究時採用 electrode（電極）、electrolyte（電解質）、electrolysis（電解）；anode（陽極）、cathode（陰極）、ion（離子，含 anion、cation）則由惠威爾（William Whewell，1794–1866，一譯休厄爾）應法拉第之請擬定。

2. 電解產物的判斷

水溶液中，水也可能得失電子：陰極上 \ce{2H2O + 2e- -> H2 + 2OH-} 與金屬離子競爭；陽極上 \ce{2H2O -> O2 + 4H+ + 4e-} 與陰離子競爭。

  • 陰極：Cu2+、Ag+ 等位於 H 之後的金屬離子優先還原為金屬；K+、Na+、Ca2+、Mg2+、Al3+ 的水溶液，由水還原生成 H2。
  • 陽極（惰性電極如石墨、鉑）：I−、Br− 優先氧化；Cl− 濃度高時生成 Cl2；SO42−、NO3− 不被氧化，由水氧化生成 O2。
  • 陽極若為活性金屬（如 Cu），電極本身優先被氧化溶解。

3. 電鍍與電解精煉

  • 電鍍：待鍍物接負極（陰極），鍍層金屬接正極（陽極），電解液含鍍層金屬的離子。陽極溶出的離子補充陰極析出的量，溶液濃度大致不變。
  • 鍍件須先除油、除鏽；電流過大時鍍層粗糙、附著不良。
  • 銅的電解精煉：粗銅作陽極、純銅薄片作陰極；比銅活潑的雜質（Zn、Fe、Ni）氧化成離子留在溶液，比銅不活潑的雜質（Ag、Au、Pt）不溶而沉積為陽極泥，可回收貴金屬。

4. 法拉第電解定律（進階）

Q = It,\qquad n_{e^-} = \frac{Q}{F},\qquad n_{\text{產物}} = \frac{n_{e^-}}{z}

Q：電量（C）　I：電流（A）　t：時間（s）　F：法拉第常數，1 mol 電子的電量，96485\ \mathrm{C/mol}（題目常取 96500）　z：生成 1 個產物粒子所需的電子數

Q = 2.00 \times 965 = 1930\ \mathrm{C}，\ n_{e^-} = 0.0200\ \mathrm{mol}示例：2.00 A 通電 965 s。可析出 Cu 0.0100 mol（0.635 g），或 Ag 0.0200 mol（2.16 g）。串聯的電解槽通過相同電量。

電解題的學測考法：判斷兩極產物與溶液酸鹼性變化（常配合指示劑顏色）、電鍍裝置接法、電量與產物量的換算。陷阱：把「陽極」與「正極」在電池與電解中的對應弄反。

深究　電解 NaCl 水溶液為何陰極得不到鈉

Na+ 的還原電位（−2.71 V）遠低於水的還原（中性時約 −0.41 V），故水優先得電子產生 H2；若要得到金屬鈉，須電解無水的熔融 NaCl。陽極上，依標準電位 O2（+1.23 V）應比 Cl2（+1.36 V）易生成，但水氧化成 O2 在電極上需要額外的電壓（過電位），濃食鹽水中主要產物為 Cl2。實際電解所需電壓都高於理論值，差額轉為熱能。氯鹼工業以離子交換膜分隔兩極，防止 Cl2 與 NaOH 反應。

八、腐蝕與防鏽

1. 鐵的腐蝕

  • 腐蝕：金屬與環境中的物質發生氧化還原而損耗。鐵生鏽須同時有氧氣與水；電解質（鹽分）、酸性、高溫使生鏽加快。
  • 鐵的腐蝕是電化學過程，鐵表面形成許多微小的電池：
\begin{aligned} \text{陽極區：}&\ \ce{Fe -> Fe^2+ + 2e-} \\ \text{陰極區：}&\ \ce{O2 + 2H2O + 4e- -> 4OH-} \\ \text{後續：}&\ \ce{Fe^2+ + 2OH- -> Fe(OH)2}，\ \ce{4Fe(OH)2 + O2 + 2H2O -> 4Fe(OH)3} \end{aligned}

Fe(OH)3 部分脫水成紅褐色的鐵鏽 Fe2O3·xH2O。鐵鏽疏鬆多孔、易剝落，無法保護內部的鐵。

對照實驗變因：甲（無水）、乙（無氧）、丙（水＋氧）、丁（水＋氧＋鹽）。

甲丙比 → 水的必要；乙丙比 → 氧的必要；丙丁比 → 電解質加速。

鐵釘生鏽對照實驗是學測探究題的常見情境：辨識操縱變因、應變變因與控制變因、說明煮沸蒸餾水與油層的目的（去除並隔絕溶氧）、無水氯化鈣的目的（乾燥劑）。

深究　缺氧處反而被腐蝕：差異充氣電池

在鐵面上滴一滴鹽水，數小時後液滴中央的鐵被腐蝕成凹坑，鐵鏽環出現在中央與邊緣之間。液滴邊緣與空氣接觸、溶氧多，O2 在此還原（陰極區）；中央溶氧少，成為陽極區，鐵在此氧化；電子經鐵內部由中央流向邊緣。此現象由伊文斯（Ulick R. Evans，1889–1980）於 1920 年代以實驗證實，稱為差異充氣腐蝕，可解釋鐵柱埋入土中或水中的部分、鉚釘縫隙、油漆下方等缺氧處腐蝕特別嚴重。

2. 防鏽方法

方法原理示例
隔絕氧與水塗層阻隔油漆、塗油、包覆塑膠、搪瓷

  • 鍍鋅鐵刮傷：Zn 比 Fe 活潑，Zn 成為陽極先被氧化，鐵受保護。
  • 鍍錫鐵刮傷：Fe 比 Sn 活潑，裸露的 Fe 成為陽極，大面積的錫成為陰極，鐵腐蝕比未鍍層時更快。馬口鐵多用於食品罐內壁，因錫無毒且不易被食物中的酸侵蝕。刮傷後：鍍鋅保護、鍍錫加速
  • 不同金屬直接接觸並有電解質時，活性大者加速腐蝕（伽凡尼腐蝕），如鐵管與銅管直接相接。
  • 保護性氧化膜：Al 的 Al2O3、不鏽鋼的 Cr2O3 緻密附著；銅表面久置生成綠色的鹼式碳酸銅 \ce{Cu2(OH)2CO3}（銅綠）：\ce{2Cu + O2 + CO2 + H2O -> Cu2(OH)2CO3}，亦有保護作用。

九、漂白、消毒與生活中的氧化還原

1. 漂白

有色物質的顏色來自分子中可吸收可見光的結構（發色團，多為共軛雙鍵）。漂白劑以氧化或還原破壞此結構，使其不再吸收可見光。

類別漂白劑作用特點
氧化型NaClO（漂白水）、HClO、Cl2(aq)HClO 氧化發色團不可逆；不宜用於絲、毛等蛋白質纖維與有色衣物
氧化型H2O2、過碳酸鈉、O3氧化發色團產物為水、氧；過碳酸鈉用於含氧漂白劑
還原型SO2、亞硫酸氫鈉、連二亞硫酸鈉還原發色團產物久置可能再被空氣氧化而部分回色；用於紙漿、羊毛
  • 漂白水的製法：\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}（自身氧化還原）。ClO− 在水中部分形成 HClO，HClO 為主要的氧化殺菌成分。
  • 漂白水不可與酸性清潔劑（含 HCl）混用：\ce{NaClO + 2HCl -> NaCl + Cl2 + H2O}，產生有毒氯氣；也不可與含氨的清潔劑混用，會生成有刺激性的氯胺。

2. 消毒

  • 自來水加氯消毒：\ce{Cl2 + H2O <=> HCl + HClO}，HClO 氧化微生物的細胞成分；出水保留少量餘氯，可防止輸水過程再受汙染。
  • 臭氧、二氧化氯也用於水處理；臭氧分解快，無持續殺菌力。
  • 雙氧水（約 3%）用於傷口清潔：組織中的過氧化氫酶催化 \ce{2H2O2 -> 2H2O + O2}，產生氣泡。
  • 75% 酒精使蛋白質變性而殺菌，不屬於氧化還原；紫外線殺菌破壞核酸，亦非氧化劑作用。

漂白水＋潔廁劑 → 氯氣；漂白水＋氨水 → 氯胺：兩者都不能混

3. 生活中的其他氧化還原

  • 抗氧化劑：維生素 C、維生素 E、亞硫酸鹽（食品添加物）本身易被氧化，可保護食品中的油脂與色素；削皮蘋果褐變（酵素催化多酚氧化）可用檸檬汁延緩。
  • 脫氧劑與暖暖包：鐵粉在食鹽水、活性碳存在下迅速氧化，消耗包裝內的氧氣，或放出熱量供保暖；原理與鐵生鏽相同，食鹽為電解質，活性碳助氧化。
  • 呼氣酒精檢測（早期化學式）：酸性 K2Cr2O7 將乙醇氧化為乙酸，顏色由橙變綠：\ce{2Cr2O7^2- + 3C2H5OH + 16H+ -> 4Cr^3+ + 3CH3COOH + 11H2O}。現行執法用的呼氣酒精測試器多採電化學式（燃料電池式）感測器，乙醇在感測元件的電極上被氧化，產生的電流與呼氣中的酒精濃度成正比；另有紅外線吸收式。
  • 生物體：細胞呼吸氧化葡萄糖；血紅素中的 Fe2+ 攜氧；光合作用水被氧化放出 O2（B2）。
  • 冶金：高爐煉鐵（CO 還原 Fe2O3）、鋁熱反應焊接鐵軌。

學測生活化學題常以漂白水標示、清潔劑混用警語、食品包裝脫氧劑、暖暖包成分表為情境，要求判斷氧化劑與還原劑或寫出產生的有毒氣體。

例題精解

原子量：H 1.0、C 12.0、O 16.0、Na 23.0、S 32.1、Mn 54.9、Fe 55.8、Cu 63.5、Zn 65.4、Ag 107.9、Pb 207.2；F = 96500\ \mathrm{C/mol}。

例題 1　求下列畫記原子的氧化數：(1) Na2S2O3 中 S（平均）；(2) CH3COOH 中 C（平均）；(3) K2FeO4 中 Fe；(4) N2H4 中 N。

  1. 先固定確定值：Na、K 為 +1，H 為 +1，O 為 −2。
  2. (1) 2(+1) + 2x + 3(-2) = 0，x = +2。
  3. (2) 2x + 4(+1) + 2(-2) = 0，x = 0。
  4. (3) 2(+1) + x + 4(-2) = 0，x = +6。(4) 2x + 4(+1) = 0，x = -2。

陷阱：平均氧化數為 0 不代表每個 C 都是 0（乙酸中甲基碳 −3、羧基碳 +3）；K2FeO4 中 Fe 為少見的 +6，不能憑「鐵只有 +2、+3」作答。

例題 2　實驗室以 \ce{MnO2 + 4HCl -> MnCl2 + Cl2 + 2H2O} 製氯氣。取 8.70 g MnO2（式量 87.0）與足量濃鹽酸完全反應，求：(1) 氧化劑與還原劑；(2) 生成 Cl2 的莫耳數；(3) 被氧化的 HCl 莫耳數。

  1. Mn：+4 → +2，MnO2 為氧化劑；Cl：−1 → 0（僅一部分），HCl 為還原劑。
  2. n(\ce{MnO2}) = 8.70 / 87.0 = 0.100\ \mathrm{mol}，生成 Cl2 0.100 mol。
  3. 每個 Cl2 含 2 個被氧化的 Cl，被氧化的 HCl 為 0.200 mol（參與反應的 HCl 為 0.400 mol）。

陷阱：把參與反應的 0.400 mol 全算成被氧化；另 0.200 mol 的 Cl 留在 MnCl2 中，氧化數未變。

例題 3　已知 \ce{2Fe^3+ + Cu -> 2Fe^2+ + Cu^2+} 與 \ce{Fe + Cu^2+ -> Fe^2+ + Cu} 皆可自發。(1) 排出 Fe3+、Fe2+、Cu2+ 的氧化力順序；(2) 判斷 Fe3+ 溶液中加入鐵粉是否反應。

  1. 第一式：氧化劑 Fe3+ ＞ 產物中的氧化劑 Cu2+。
  2. 第二式：氧化劑 Cu2+ ＞ 產物中的氧化劑 Fe2+。故 Fe3+ ＞ Cu2+ ＞ Fe2+。
  3. Fe3+ 為三者中最強的氧化劑，Fe 的還原力強於 Cu，故反應：\ce{2Fe^3+ + Fe -> 3Fe^2+}（逆歧化）。

陷阱：誤以為同元素之間不會反應。保存 FeSO4 溶液時加入鐵釘，即利用此反應把被空氣氧化生成的 Fe3+ 還原回 Fe2+。

例題 4　以半反應法平衡酸性溶液中的反應：\ce{Cr2O7^2- + I- -> Cr^3+ + I2}。

  1. 還原：\ce{Cr2O7^2- -> 2Cr^3+}；補 O：+7\ce{H2O}；補 H：左加 14\ce{H+}；補電荷：左加 6\ce{e-}。
  2. 氧化：\ce{2I- -> I2 + 2e-}，乘 3。
  3. 相加：\ce{Cr2O7^2- + 6I- + 14H+ -> 2Cr^3+ + 3I2 + 7H2O}。
  4. 檢查電荷：左 -2 - 6 + 14 = +6，右 2 \times 3 = +6。

陷阱：Cr2O72− 有 2 個 Cr，得 6 個電子；只寫 3 個電子會使 I− 係數少一半。

例題 5　取 25.0 mL 雙氧水樣品，以硫酸酸化後用 0.0200 M KMnO4 滴定，達終點時用去 18.0 mL。求 H2O2 的體積莫耳濃度。

  1. 電子數：MnO4− → Mn2+ 得 5e−；H2O2 → O2 失 2e−。
  2. n(\ce{MnO4-}) = 0.0200 \times 0.0180 = 3.60\times10^{-4}\ \mathrm{mol}。
  3. 電子守恆：n(\ce{H2O2}) \times 2 = 3.60\times10^{-4} \times 5，n(\ce{H2O2}) = 9.00\times10^{-4}\ \mathrm{mol}。
  4. [\ce{H2O2}] = 9.00\times10^{-4} / 0.0250 = 0.0360\ \mathrm{M}。

陷阱：H2O2 在此為還原劑；若誤用其作氧化劑時的半反應（得 2e−），電子數雖同為 2，但產物寫錯會在平衡式中出錯。

例題 6　將鐵片放入足量 CuSO4 溶液中，一段時間後取出、洗淨、乾燥，鐵片質量增加 0.770 g（設析出的銅全附著於鐵片）。求析出銅的質量。

  1. 反應：\ce{Fe + Cu^2+ -> Fe^2+ + Cu}，每莫耳反應質量增加 63.5 - 55.8 = 7.7\ \mathrm{g}。
  2. 反應莫耳數 0.770 / 7.7 = 0.100\ \mathrm{mol}。
  3. 析出銅 0.100 \times 63.5 = 6.35\ \mathrm{g}（同時溶去鐵 5.58 g）。

陷阱：把增加的質量直接當成析出的銅。若換成鋅片，因 Zn（65.4）比 Cu 重，片子質量反而減少。

例題 7　由 Zn|Zn2+(1 M) 與 Ag|Ag+(1 M) 組成電池，鹽橋含 KNO3。已知 E^\circ(\ce{Zn^2+/Zn}) = -0.76\ \mathrm{V}、E^\circ(\ce{Ag+/Ag}) = +0.80\ \mathrm{V}。(1) 標準電壓；(2) 外電路通過 0.0200 mol 電子時兩極質量變化；(3) 鹽橋中 K+ 的移動方向。

  1. Ag+ 電位較高，銀極為正極；鋅極為負極。E^\circ = 0.80 - (-0.76) = 1.56\ \mathrm{V}。
  2. 鋅極：溶出 Zn 0.0100 mol，減少 0.0100 \times 65.4 = 0.654\ \mathrm{g}。
  3. 銀極：析出 Ag 0.0200 mol，增加 0.0200 \times 107.9 = 2.16\ \mathrm{g}。
  4. K+ 移向正極（銀）槽，補充減少的 Ag+。

陷阱：計算電壓時把 0.80 乘 2；電位為強度性質，係數不影響電位。

例題 8　鉛蓄電池放電時外電路通過 0.200 mol 電子，求負極與正極的質量變化及消耗的 H2SO4 莫耳數（PbSO4 式量 303.3，PbO2 式量 239.2）。

  1. 負極：\ce{Pb -> PbSO4}，每 2 mol 電子增加 SO4 一單位（96.1 g）；0.100 mol × 96.1 = 9.61 g（增加）。
  2. 正極：\ce{PbO2 -> PbSO4}，每單位增加 303.3 - 239.2 = 64.1\ \mathrm{g}；0.100 mol × 64.1 = 6.41 g（增加）。
  3. 全反應每轉移 2 mol 電子消耗 2 mol H2SO4，故消耗 0.200 mol。

陷阱：以為負極「被氧化溶解」而質量減少；PbSO4 難溶，附著於極板上，兩極皆增重。

例題 9　以石墨為電極電解 CuSO4 水溶液，並另以銅為電極電解 CuSO4 水溶液。比較兩者的陽極產物與溶液變化。

  1. 兩者陰極皆為 \ce{Cu^2+ + 2e- -> Cu}。
  2. 石墨陽極：SO42− 不被氧化，水被氧化：\ce{2H2O -> O2 + 4H+ + 4e-}；全反應 \ce{2CuSO4 + 2H2O -> 2Cu + O2 + 2H2SO4}，藍色變淡、pH 下降。
  3. 銅陽極：\ce{Cu -> Cu^2+ + 2e-}，陽極溶解量等於陰極析出量，[Cu2+] 與顏色不變。

陷阱：未考慮電極材料。活性金屬陽極會優先被氧化。

例題 10　AgNO3(aq) 與 CuSO4(aq) 兩電解槽串聯（皆用鉑電極），通電後第一槽陰極析出 1.08 g Ag。求第二槽陰極析出的銅質量與陽極產生的 O2 莫耳數。

  1. 串聯時通過的電量相同。n(\ce{Ag}) = 1.08 / 107.9 = 0.0100\ \mathrm{mol}，電子 0.0100 mol。
  2. Cu：0.0100 / 2 = 5.00\times10^{-3}\ \mathrm{mol}，質量 5.00\times10^{-3} \times 63.5 = 0.318\ \mathrm{g}。
  3. O2：每 1 mol O2 需 4 mol 電子，0.0100 / 4 = 2.50\times10^{-3}\ \mathrm{mol}。

陷阱：誤以為兩槽析出的金屬莫耳數相同；相同的是電子莫耳數。

例題 11　鋼製船殼浸於海水中，欲以犧牲陽極法保護，應在船殼上焊接下列何種金屬塊：Mg、Zn、Cu、Sn？說明原因，並指出需定期處理的事項。

  1. 犧牲陽極須比鐵活潑：Mg、Zn 可用；Cu、Sn 比鐵不活潑，反而使鐵成為陽極、加速腐蝕。
  2. Zn 或 Mg 被氧化（陽極），鐵船殼成為陰極，表面進行 O2 的還原。
  3. 金屬塊逐漸消耗，須定期檢查並更換。

陷阱：以「越耐腐蝕越好」選 Cu 或 Sn。保護靠的是活性較大的金屬代為氧化。

迷思概念對照

誤氧化反應一定有氧參與。

正失去電子（氧化數升高）即為氧化，如 \ce{2Na + Cl2 -> 2NaCl} 中 Na 被氧化，無氧參與。

誤氧化劑在反應中被氧化。

正氧化劑使他物氧化，本身得電子而被還原，氧化數降低。

誤有元素態物質參與的反應都是氧化還原反應。

正\ce{3O2 -> 2O3} 中氧化數皆為 0，不是氧化還原；判斷依據為氧化數是否改變。

誤氧化數就是原子實際帶的電荷。

正氧化數是假設鍵結電子全歸電負度大者的形式值；H2O 中 O 的實際部分電荷遠小於 2。

誤電池中電子經由溶液與鹽橋回到負極。

正電子只在導線與電極中移動；溶液與鹽橋中由離子移動傳導電流。

誤電池的負極是陰極。

正電池的負極發生氧化，稱陽極；電解槽中接電源正極者才是陽極。兩者共通點：陽極必氧化。

誤電池的電壓與電極大小、電解液體積成正比。

正電壓由反應種類與濃度決定；電極與溶液的量影響的是容量與可持續的時間。

誤半反應乘以係數後，標準電位也要乘以相同係數。

正電位為強度性質，係數改變時 E^\circ 不變。

誤鋁比鐵活潑，所以鋁製品比鐵製品更容易腐蝕。

正鋁表面的 Al2O3 緻密附著，阻止內部繼續氧化；鐵鏽疏鬆，無保護作用。

誤鍍錫鐵刮傷後，錫仍能保護鐵。

正Fe 比 Sn 活潑，刮傷處 Fe 成為陽極，腐蝕反而加快；鍍鋅鐵刮傷才有犧牲保護。

誤銅不與任何酸反應。

正銅不與稀鹽酸、稀硫酸反應，但可溶於硝酸與熱濃硫酸，產物為 NO、NO2 或 SO2，不產生 H2。

誤鐵只要接觸空氣就會生鏽。

正鐵生鏽須同時有氧氣與水；乾燥空氣中的鐵幾乎不生鏽。

誤75% 酒精與漂白水同樣以氧化作用殺菌。

正酒精使蛋白質變性，非氧化還原；漂白水以 HClO 的氧化作用殺菌。

誤漂白水與鹽酸類潔廁劑混用，清潔力更強。

正兩者反應產生有毒的 Cl2：\ce{NaClO + 2HCl -> NaCl + Cl2 + H2O}，嚴禁混用。

誤電解 NaCl 水溶液可在陰極得到金屬鈉。

正水比 Na+ 易還原，陰極產生 H2；製鈉須電解熔融 NaCl。

誤鋰離子電池的負極含有金屬鋰。

隨著電動車市場的蓬勃發展，鋰離子電池受到廣泛的使用，但受限於鋰元素取得不易，因此，新興的鋁離子電池之開發相當受到矚目。常見的鋁離子電池之作用原理，是利用電解液中的 X 離子，在金屬鋁（甲電極）與多層結構的石墨（\ce{C_{n}}）（乙電極）兩電極之間的移動，來充放電能，放電電壓可達約 2V，充電速度快，且循環壽命高。常見的鋁離子電池放電時，甲、乙兩電極的反應如下：（原子量：Al＝27）

乙電極：\ce{C_{n}[AlCl4] + e- -> C_{n} + AlCl4-}　（式 2）

答案：(D)

  1. (A) 甲極（Al）放出電子、發生氧化，是負極（陽極），錯。(B) 乙極得到電子，發生還原，是正極（陰極），錯。

精選 5　臺南一中 114 學年度（K08-10）

高鐵電池是一種新型可充電電池，與普通高能量電池相比，該電池能長時間保持穩定的放電電壓，高鐵電池的總反應式如下：
\ce{3Zn + 2K2FeO4 + 8H2O <=>[\text{放電}][\text{充電}] 3Zn(OH)2 + 2Fe(OH)3 + 4KOH}
下列敘述何者錯誤？
(A) 放電時負極反應為 \ce{Zn + 2OH- -> Zn(OH)2 + 2e-}(B) 充電時陽極反應為 \ce{Fe(OH)3 + 5OH- -> FeO4^2- + 4H2O + 3e-}(C) 放電時，每轉移 3 mol 電子，正極有 1 mol \ce{K2FeO4} 被氧化(D) 放電時，正極附近溶液的鹼性增強(E) 放電時，Zn 為陽極。

答案：(C)

  1. 氧化數：Zn 0→+2（失 2e⁻，被氧化）；Fe +6→+3（得 3e⁻，被還原）。
  2. (A) 放電負極（陽極）Zn 被氧化，鹼性中生成 \ce{Zn(OH)2}，原子與電荷皆平衡。正確。
  3. (B) 充電時正極接電源正極成為陽極，\ce{Fe(OH)3} 被氧化回 \ce{FeO4^2-}。驗算：O 左 3＋5＝8、右 4＋4＝8；H 左 8、右 8；電荷左 −5、右 -2-3=-5。正確。
  4. (C) 放電時 \ce{K2FeO4} 在正極被還原，每 1 mol 得 3 mol 電子。數量對，「被氧化」錯。本項錯誤。
  5. (D) 正極反應 \ce{FeO4^2- + 4H2O + 3e- -> Fe(OH)3 + 5OH-}，生成 \ce{OH-}，鹼性增強。正確。
  6. (E) 放電時 Zn 發生氧化，為陽極（負極）。正確。

考點：可充電電池的電極反應、氧化數　對應：C9

陽極氧化、陰極還原；放電時負極＝陽極，充電時接電源正極的電極＝陽極。

精選 6　高雄中學 111 學年度（K18-15）

以兩根不同的金屬插入檸檬中，並以導線接通，如圖所示，有關此電池的敘述，下列何者正確？
(A) 以銅和銀為電極組合時不放電(B) 電池放電是利用中和原理(C) 在甲處打入少量碳酸鈉溶液，則電流逐漸變大(D) 若以鎂代替鋅，量得電流值變小。

答案（本書解）：(A)（命題者預期之答案；嚴格而言本題無完全正確的選項，見說明）　〔原卷化學科選擇題第 5 題〕

  1. 鋅銅檸檬電池：鋅活性大，為負極（陽極），\ce{Zn -> Zn^2+ + 2e-}；電子經導線流到銅，檸檬汁中的 \ce{H+} 在銅表面得電子：\ce{2H+ + 2e- -> H2}。電池放電是氧化還原反應，(B) 錯。
  2. (C) 錯：碳酸鈉與檸檬汁中的酸反應（\ce{CO3^2- + 2H+ -> CO2 + H2O}），消耗正極所需的 \ce{H+}，電流應變小。
  3. (D) 錯：鎂的活性大於鋅，與銅的活性差距更大，電壓較高，電流變大。
  4. (A)：銅與銀的活性都小於氫，在命題者採用的模型（負極金屬須能與酸中的 \ce{H+} 反應）中，兩者都不與檸檬汁的酸反應，故「不放電」，本書判讀此為預期答案。

原題瑕疵：實際上任兩種不同金屬插入電解質都有電位差。銅、銀組合時，活性較大的銅為負極，正極可由溶解於果汁中的氧氣得電子（\ce{O2 + 4H+ + 4e- -> 2H2O}），會有很小的電壓與電流（遠小於鋅銅組合），嚴格說「不放電」並不正確。國中課本也以「兩種活性不同的金屬」作為電池兩極的條件。本題 (A) 宜改為「電壓很小」，或改用「兩極皆為銅片時不放電」。

考點：化學電池原理、金屬活性與電壓　對應：C9（國中：理化電池）
