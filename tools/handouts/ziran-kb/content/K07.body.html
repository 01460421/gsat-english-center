K07-01十九世紀末至二十世紀初是人類對原子結構認識非常重要的年代。其中湯姆森(J. J. Thomson)與拉塞福（Ernest Rutherford）是兩位原子結構發展史上非常重要的科學家，兩位科學家之實驗結果推翻了十九世紀初時道耳吞（John Dalton）所提出原子說中所提到「原子不可分割」的概念。湯姆森與拉塞福分別依據其實驗結果提出兩種原子模型：湯姆森—葡萄乾布丁模型（plum pudding model）；拉塞福—行星模型（planetary model）。雖然今日科學界所知之原子結構與兩位科學家所提出之原子模型相差甚遠，但兩位科學家之研究成果於原子結構發展史上依然佔有不可磨滅之地位。關於湯姆森與拉塞福之相關科學成就的敘述，下列何者正確？（3 分）
(A)湯姆森之陰極射線管實驗（cathode ray tube experiment）可得知在電場的環境下，陰極射線會產生偏折(B)湯姆森利用陰極射線實驗可成功證明原子中具有帶負電荷的粒子與帶正電荷的粒子，且兩者是均勻分佈的(C)湯姆森陰極射線實驗可得知每個負電荷粒子的電量約為 1.602\times10^{-19} 庫侖(D)拉塞福金箔散射實驗（gold foil experiment）發現幾乎所有的 α 粒子均可直線穿透金箔，但有極少數 α 粒子發生極大角度的散射故可得知質子的存在(E)拉塞福的金箔散射實驗亦可得知原子中有不帶電荷之粒子存在。

答案：(A)

  1. (A) 正確。湯姆森（1897 年）讓陰極射線通過兩平行板間的電場，射線偏向正極板，證明它由帶負電的粒子組成；再配合磁場偏轉測出粒子的荷質比 e/m。
  2. (B) 錯。陰極射線實驗只證明有帶負電的粒子（電子）。「正電荷均勻分布、電子嵌在其中」是湯姆森為了解釋原子呈電中性而提出的模型，不是實驗證明的結果。
  3. (C) 錯。湯姆森只測得荷質比，電子電量是密立坎（Robert Millikan）以油滴實驗（1909 年起）測得。
  4. (D) 錯。金箔實驗的結論是原子中有一個體積很小、集中大部分質量、帶正電的原子核，不是「質子」。質子是拉塞福在 1917–1919 年以 α 粒子撞擊氮原子核時發現的。
  5. (E) 錯。中子不帶電，不受 α 粒子的電力作用，金箔實驗看不出；中子由查兌克（James Chadwick）於 1932 年發現。

考點：原子模型的演進與各實驗的結論。　對應：C1、P5（國中：理化 原子結構）

誤把「實驗觀察」與「據此提出的模型」混為一談。實驗只給出證據（偏轉、散射角度分布），模型是科學家對證據的解釋。

K07-02定溫定壓下，物質生成時所儲存於其中的能量，稱為「熱含量」。化學反應中，科學家以「所有生成物的熱含量總和」減去「所有反應物的熱含量總和」，表達化學反應前後的熱含量變化，稱為化學反應的「反應熱（ΔH）」。已知反應熱具有加成性，亦即一反應式若可由數個反應式相加所得，則此反應式的反應熱可由這數個反應式的反應熱相加求得。
在 1 大氣壓、25℃下，已知相關反應方程式與其反應熱如下所列：
\ce{2H2(g) + O2(g) -> 2H2O}(\ell)\qquad \Delta H = -571.6\ \mathrm{kJ}
\ce{H2(g) + O2(g) -> H2O2}(\ell)\qquad \Delta H = -187.8\ \mathrm{kJ}
於相同條件下，取 10 克液態過氧化氫分解產生氧氣與液態水，發現過程中共放出 9.8 kJ 的能量，則過氧化氫的分解百分率為何？（原子量：H＝1.0、O＝16.0）（3 分）
(A) 17%(B) 25%(C) 34%(D) 42%(E) 51%。

答案：(C)

\Delta H_{\text{目標}} = \sum (\text{各步驟反應式乘上係數後的} \Delta H)

反應式乘以 n 倍，ΔH 也乘 n；反應式反寫，ΔH 變號。

  1. 目標反應：\ce{H2O2(l) -> H2O(l) + 1/2O2(g)}。
  2. 組合：第一式除以 2 得 \ce{H2 + 1/2O2 -> H2O}，\Delta H = -285.8\ \mathrm{kJ}；第二式反寫得 \ce{H2O2 -> H2 + O2}，\Delta H = +187.8\ \mathrm{kJ}。兩式相加：
    \Delta H = -285.8 + 187.8 = -98.0\ \mathrm{kJ/mol}
  3. 放熱 9.8 kJ，分解的 \ce{H2O2} 為 \frac{9.8}{98.0} = 0.100\ \mathrm{mol}，質量 0.100 \times 34.0 = 3.40\ \mathrm{g}。
  4. 分解百分率 \frac{3.40}{10} \times 100\% = 34%。

考點：赫斯定律、反應熱與物量的比例。　對應：C7、C5

誤把第二式的 −187.8 kJ 直接當作分解熱，得 9.8/187.8 mol。分解是生成的逆反應，還要再接上「氫燃燒成水」的那一步。

K07-03右圖為某處的地層剖面示意圖，已知地層 1～7 是連續沉積的地層，且地層 3 中發現了漸新馬的化石，地層 5 則發現了中新馬的化石，下列關於此處地形地質的敘述何者有誤？（2 分）
(A)山丘位在向斜構造的頂部(B)由河谷走向山丘頂，沿途經過的地層越來越老(C)此地的地層因擠壓而產生褶皺(D)河谷兩岸不易發生順向坡的滑動災害。

答案：(B)

  1. 先定新老：漸新馬（漸新世）比中新馬（中新世）古老，地層 3 比地層 5 老；又是連續沉積，依疊置定律地層 1 最老、7 最年輕。
  2. 河谷下方地層 1 在中心、2、3 向兩側彎下包住它，核心最老 → 背斜。山丘下方地層 7 在中心、6、5 等向下彎成碗狀包住它，核心最年輕 → 向斜。(A) 正確：山丘位在向斜上（谷在背斜、山在向斜，稱地形倒置）。
  3. (B) 有誤：由河谷（出露地層 1、2）走向山丘頂（地層 7），經過的地層越來越新。
  4. (C) 正確：背斜與向斜都是岩層受水平擠壓形成的褶皺。
  5. (D) 正確：河谷位於背斜軸部，兩岸地層由軸部向外（向山丘方向）傾斜，坡面則朝向河谷，坡向與層面傾向相反，屬逆向坡，不易發生沿層面下滑的順向坡滑動。

考點：疊置定律、指準化石、背斜與向斜的判讀、順向坡與逆向坡。　對應：E6、E10

誤以「地勢高＝背斜」判斷。褶皺的判斷依據是地層的新老分布（背斜核心老、向斜核心新），與地形高低無必然關係；背斜軸部岩層受張裂較易侵蝕，常反而成谷。

K07-04不考慮大氣影響及地表環境的差異，春分當天的正午時刻，北緯 60 度地區地面接受陽光的能量為 n（單位：W/m2），則赤道地區的地面接收能量應為多少？（2 分）

答案：(C)

  1. 春分太陽直射赤道，正午太陽仰角 h = 90^\circ - \phi：赤道 90°，北緯 60° 為 30°。

    \frac{I_{\text{赤道}}}{I_{60^\circ}} = \frac{\sin 90^\circ}{\sin 30^\circ} = \frac{1}{1/2} = 2

考點：太陽仰角與單位面積日照能量。　對應：E2（國中：地球科學 四季成因）

誤用 \cos 60^\circ 與 \cos 0^\circ 時角度取錯，或用 \tan。接收量正比於仰角的正弦，也就是正比於入射方向與鉛直線夾角的餘弦。

  1. t 秒時小球在 O 點右方 x = v_0t、下方 y = \frac{1}{2}gt^2。影子在 O 與小球的連線延長到牆上的點。
  2. 相似三角形：影子在 O 下方的深度
    Y = y\cdot\frac{L}{x} = \frac{\frac{1}{2}gt^2}{v_0t}L = \frac{gL}{2v_0}\,t
    Y 與 t 成正比 → 影子做等速運動（向下）。
  3. 速率 \frac{gL}{2v_0} = \frac{10\times20}{2\times5} = 20\ \mathrm{m/s}，與時間無關，1 秒時亦為 20 m/s。（小球 4 秒後撞牆，1 秒時仍在空中。）

考點：水平拋射、光的直線傳播與相似形。　對應：P2、P4（進階：拋體運動）

誤以為影子跟著小球做等加速度運動。點光源在拋出點時，小球愈往下落，與光源的水平距離也愈大，兩效應相除後恰為等速。

延伸：若光源改為無限遠處射來的水平平行光，影子在牆上的高度與小球相同，就變成自由落體的等加速度運動。

K07-32已知將鐵粉加入硫酸銅水溶液中可發生氧化還原反應。兩種可能發生的反應方程式如下所示：（化學反應方程式係數尚未平衡）

請列出計算或推理過程，並說明你的理由。（2 分）
（式量或原子量：\ce{CuSO4}＝160.0、Cu＝63.5、Fe＝55.8）

參考答案：式(2)，\ce{CuSO4(aq) + Fe(s) -> FeSO4(aq) + Cu(s)}

  1. 反應物的物量：\ce{CuSO4} 0.500 \times 0.08770 = 0.04385\ \mathrm{mol}；Fe \frac{2.00}{55.8} = 0.03584\ \mathrm{mol}。產物 Cu \frac{2.27}{63.5} = 0.0357\ \mathrm{mol}。
  2. 若依式(1) 平衡後為 \ce{3CuSO4 + 2Fe -> Fe2(SO4)3 + 3Cu}：0.03584 mol Fe 需 \ce{CuSO4} 0.0538 mol，超過現有的 0.04385 mol，\ce{CuSO4} 為限量試劑，應得 Cu 0.04385 mol = 0.04385\times63.5 = 2.78\ \mathrm{g}，與 2.27 g 不符。
  3. 若依式(2) \ce{CuSO4 + Fe -> FeSO4 + Cu}（係數皆為 1）：Fe 0.03584 mol 少於 \ce{CuSO4}，Fe 為限量試劑，應得 Cu 0.03584 mol = 0.03584\times63.5 = 2.28\ \mathrm{g}，與實驗值 2.27 g 吻合（Cu 與 Fe 的物量比約 1：1）。
  4. 結論：反應為式(2)，鐵被氧化成 \ce{Fe^2+}。

考點：限量試劑、由產量判斷反應式、氧化還原反應式平衡。　對應：C5、C9

誤沒有先找限量試劑，直接以 \ce{CuSO4} 的物量算銅。兩式的限量試劑不同，一定要分別判斷。

補充：\ce{Fe^3+} 的氧化力比 \ce{Cu^2+} 強，若生成 \ce{Fe^3+}，它會再與銅反應（\ce{2Fe^3+ + Cu -> 2Fe^2+ + Cu^2+}），所以鐵與銅離子反應的產物是 \ce{Fe^2+}。

參考答案：讀數緩慢增加，之後趨於定值

  1. 罩內的空氣含有氧氣與水氣。鐵在空氣中會緩慢氧化生鏽：
    \ce{4Fe + 3O2 + 2$x$H2O -> 2Fe2O3*$x$H2O}
    鐵棒把罩內空氣中的氧與水結合到自己身上。
  2. 密閉罩內的總質量守恆，但天平只秤秤盤上的物體。原本懸浮在罩內空氣中的氧與水，一部分變成鐵鏽留在秤盤上，秤盤上的質量增加，讀數緩慢增加。
  3. 罩內的氧氣與水氣有限，消耗到一定程度（尤其水氣不足時）生鏽速率趨近於零，讀數最後趨於定值。
  4. 規模估計：罩內每 10 L 空氣約含 2.7 g 氧氣，足以使讀數在 0.0001 g 的精度下明顯上升。

評分要點：讀數增加（並可說明趨於定值）；原因為鐵與罩內氧氣、水氣反應生鏽，秤盤上物質質量增加；說明密閉系統總質量守恆但天平只量秤盤上的部分。

考點：質量守恆的適用範圍（系統的選取）、鐵的腐蝕。　對應：C9、C5

誤回答「密閉系統質量守恆，讀數不變」。守恆的是整個罩內系統的總質量，天平量的只是秤盤上的鐵棒與秤量紙，氣體中的成分轉移到秤盤上，讀數就會改變。

延伸：嚴格來說，罩內氧氣減少會使空氣密度略降，鐵棒受的空氣浮力也略減，同樣使讀數略增；但此效應遠小於生鏽增加的質量。

    5\times5 - 4\times2 = 17
    共 17 個羥基。
