X6-01 (C) 考點：數量級估算（P1）。
\dfrac{8\times10^{-6}\ \mathrm{m}}{1\times10^{-10}\ \mathrm{m}} = 8\times10^{4}。8 大於 \sqrt{10}\approx3.16，進位為 10^{5}，選 (C)。(B) 為未進位的誤判；(A)(D)(E) 為 μm 或 nm 換算錯誤（1\ \mu\mathrm{m} = 10^{-6}\ \mathrm{m}，1\ \mathrm{nm} = 10^{-9}\ \mathrm{m}）。
X6-02 (D) 考點：v–t 圖面積與斜率（P2）。
各段面積：0–4 s：\tfrac12\times4\times12 = 24\ \mathrm{m}；4–10 s：6\times12 = 72\ \mathrm{m}；10–13 s（v 降至 0）：\tfrac12\times3\times12 = 18\ \mathrm{m}；13–14 s：-\tfrac12\times1\times4 = -2\ \mathrm{m}。
路程 24+72+18+2 = 116\ \mathrm{m}，(D) 正確；位移 24+72+18-2 = 112\ \mathrm{m}，(C) 錯。
(A) 10–14 s 斜率固定 (-4-12)/4 = -4\ \mathrm{m/s^2}，第 13 s 速度為零但加速度不為零。(B) 13 s 時 v 由正變負，方向反轉。(E) 0–4 s 加速度 3 m/s²，小於 4 m/s²。
X6-03 (A)(D)(E) 考點：視重與牛頓第二定律（P3）。人重 mg = 600\ \mathrm{N}，N - mg = ma。
0–2 s：a = (720-600)/60 = +2\ \mathrm{m/s^2}（向上），由靜止開始，故向上加速，(A) 對；第 2 s 速度 4 m/s。
2–8 s：N = mg，a = 0，以 4 m/s 等速上升，(B) 錯。
8–10 s：a = (480-600)/60 = -2\ \mathrm{m/s^2}，向上減速；重力仍為 600 N，磅秤讀數減小是正向力變小，(C) 錯。第 10 s 速度 4-2\times2 = 0，(D) 對。
上升距離：4 + 4\times6 + 4 = 32\ \mathrm{m}（第一、三段各 \tfrac12\times2\times4 = 4\ \mathrm{m}），(E) 對。
陷阱：讀數 480 N 是「視重」，誤把視重當重力即選 (C)。
X6-04 (D) 考點：萬有引力提供向心力、表面重力（P4）。
圓軌道：\dfrac{GMm}{r^2} = m\dfrac{4\pi^2 r}{T^2}，得 M = \dfrac{4\pi^2 r^3}{GT^2}\propto \dfrac{r^3}{T^2}。r 為 2 倍、T 相同，M_X = 8M_E。
表面重力 g = \dfrac{GM}{R^2}：g_X = g\times\dfrac{8}{2^2} = 2g。
陷阱：(E) 只算質量比、忽略半徑；(B) 誤用 M\propto r^2。
X6-05 (E) 考點：點電荷電場疊加（P5）。
兩電荷之間（0 < x < 2）：+9q 的電場向右（遠離正電荷），−4q 的電場也向右（指向負電荷），不可能抵消；(B) 錯。x < 0：離 +9q 較近且其電量較大，+9q 的電場恆較強，不可能為零；(A) 錯。電場為零之點須在電量較小的 −4q 外側。
x > 2：\dfrac{k(9q)}{x^2} = \dfrac{k(4q)}{(x-2)^2}，3(x-2) = 2x，x = 6\ \mathrm{cm}。
陷阱：(B) x = 1.2 cm 是 3(x-2) = -2x 的另一根，落在兩電荷之間，該處兩電場同向，不合；(C) 誤以為電場與距離成反比（9/x = 4/(x-2)）；(D) 套用「+4q 與 −q 時零電場點在 x = 2d」的結論。
X6-06 (B)(D) 考點：冷次定律、能量守恆（P6）。
(A) 錯：N 極上方的磁場向上（由 N 極發出），圓環接近 N 極時，通過圓環向上的磁通量增加，感應電流的磁場須向下，由上往下看為順時針。
(B) 對：磁鐵外部的磁力線進入 S 極，S 極下方的磁場向上（指向 S 極）；圓環在下方遠離時，向上的磁通量減少，感應磁場須向上，由上往下看為逆時針。
(C) 錯：圓環中心在磁鐵中點時，通過圓環的磁通量最大，變化率為零，感應電流約為零。
(D) 對：感應電流總是反抗相對運動（來拒去留）：接近時受斥力、遠離時受吸力，兩者對圓環都是向上的力。
(E) 錯：部分位能經感應電流轉為電能，最後成為圓環的熱。
X6-07 (A) 考點：行進波的波形平移與質點振動（P7）。
\lambda = 4\ \mathrm{m}，T = \lambda/v = 2.0\ \mathrm{s}，0.5 s 為 T/4，波形向 +x 平移 1 m。原在 x = 0 的平衡位置（其左側為波谷）移至 x = 1 m，故 P 位移為零。
波向 +x 傳播時，P 的下一刻位移等於其左側鄰點此刻的位移；P 左側為負位移，故 P 向下運動。也可由「波峰經 T/4 回到平衡位置，接著向下」判斷。
(B) 誤判振動方向；(C)(D) 誤以為經過半週期或未經變化；(E) 位移判斷錯誤。
X6-08 (B)(C)(D) 考點：折射率、全反射（P8）。
(A) 錯：玻璃對藍光的折射率較大，藍光在玻璃中較慢（色散）。
(B) 對：頻率由光源決定；v = c/n 變小，\lambda = v/f 變短。
(C) 對：\sin\theta_c = 1/1.50，\theta_c \approx 41.8^{\circ}；45° 大於臨界角，發生全反射。光沿半徑射入弧面時垂直入射，不偏折，故 θ 即平面處的入射角。
(D) 對：v = 3.00\times10^{8}/1.50 = 2.00\times10^{8}\ \mathrm{m/s}。
(E) 錯：\sin\theta_c = 1.33/1.50 = 0.887，\theta_c\approx 62.5^{\circ}，比 41.8° 大。
X6-09 (B) 考點：光電效應（P11）。
光子能量 E = hc/\lambda = 1240/248 = 5.00\ \mathrm{eV}；K_{\max} = 5.00 - 3.70 = 1.30\ \mathrm{eV}，截止電壓 1.30 V，(B) 對；(A) 誤把光子能量當截止電壓。
(C)(E) 錯：光強度只影響單位時間射出的光電子數目（光電流），不影響最大動能與截止電壓。
(D) 錯：1240/400 = 3.10\ \mathrm{eV}，小於功函數 3.70 eV，無光電子射出。
X6-10 (E) 考點：平均原子量（C1）。設 \ce{^{11}X} 占 x：10(1-x) + 11x = 10.8，x = 0.80。(A) 為 \ce{^{10}X} 的百分率。（硼的兩種同位素即接近此比例。）
X6-11 (C)(E) 考點：分子極性與分子間作用力（C3）。
(A) 錯：\ce{NH3} 為角錐形，極性；\ce{BF3} 為平面三角形，鍵的極性互相抵消，非極性。
(B) 錯：HF 分子間有氫鍵，沸點反常地高；分子量較小反而使分散力較弱。
(C) 對：C=O 為極性鍵，直線形分子使偶極抵消。
(D) 錯：乙醇分子間有氫鍵（沸點約 78 °C），二甲醚（\ce{CH3OCH3}）無 O–H 鍵（沸點約 −25 °C），相差甚大。
(E) 對：兩者都是碳原子以共價鍵連成的網狀結構；石墨層內有可移動的未定域電子。
X6-12 (E) 考點：理想氣體方程式、分壓（C4）。
容器內最後共 0.100+0.0500 = 0.150\ \mathrm{mol}，T = 400 K：P = \dfrac{nRT}{V} = \dfrac{0.150\times0.082\times400}{2.00} = 2.46\ \mathrm{atm}。
誘答：(B) 為起始壓力 1.23 atm；(C) 為 127 °C 時氦的分壓 1.64 atm；(A) 為氖的分壓 0.82 atm；(D) 誤用 300 K 計算總壓（1.85 atm）。
X6-13 (D) 考點：限量試劑（C5）。
n(\ce{C3H8}) = 4.40/44.0 = 0.100\ \mathrm{mol}，n(\ce{O2}) = 12.8/32.0 = 0.400\ \mathrm{mol}。完全燃燒 0.100 mol 丙烷需 0.500 mol 氧氣，氧氣不足，為限量試劑。
n(\ce{CO2}) = 0.400\times\tfrac35 = 0.240\ \mathrm{mol}，質量 0.240\times44.0 = 10.6\ \mathrm{g}。
陷阱：(E) 13.2 g 是以丙烷計算的結果。

X6-15 (C) 考點：位能圖（C7）。

X6-16 (C) 考點：酸鹼混合的 pH（C8）。
n(\ce{H+}) = 50.0\times0.100 = 5.00\ \mathrm{mmol}，n(\ce{OH-}) = 50.0\times0.0600 = 3.00\ \mathrm{mmol}，剩餘 \ce{H+} 2.00 mmol，體積 100 mL：[\ce{H+}] = 0.0200\ \mathrm{M}，\mathrm{pH} = 2 - \log2 = 1.70。
陷阱：(B) 忘了總體積變為 100 mL（0.040 M）；(A) 未扣除中和量；(E) 誤以為酸鹼混合即中性。
X6-17 (A)(C)(E) 考點：鋅銅電池（C9）。

X6-18 (E) 考點：界面活性劑（C10）。
(A) 錯：肥皂與 \ce{Ca^2+}、\ce{Mg^2+} 生成難溶的脂肪酸鈣、鎂（皂垢），去汙力降低。(B) 錯：常見合成清潔劑多為陰離子型（如烷基苯磺酸鈉）。(C) 錯：皂化產物為脂肪酸鈉（肥皂）與甘油。(D) 錯：方向相反，親油端伸入油汙、親水端朝外向水。(E) 對。
X6-19 (D)(E) 考點：細胞構造與運輸（B1）。
(A) 錯：許多細菌在細胞膜上進行電子傳遞，可行有氧呼吸。(B) 錯：動物細胞在低張溶液中吸水膨脹，甚至破裂；原生質分離見於具細胞壁的細胞置於高張溶液。(C) 錯：鈉鉀幫浦逆濃度梯度運送離子，屬主動運輸，消耗 ATP。(D) 對：此為內共生學說的證據之一。(E) 對：胰島素為蛋白質，由高基氏體包裝成囊泡，以胞吐分泌。
X6-20 (E) 考點：光反應與碳反應的關聯（B2）。
黑暗中光反應停止，ATP 與 NADPH 迅速耗盡。PGA 還原為三碳糖需 ATP 與 NADPH，此步驟受阻，PGA 累積而增加；RuBP 的再生也需 ATP，因此停止，但 RuBP 仍持續與 \ce{CO2} 結合（碳固定不直接需要光反應產物）而被消耗，故 RuBP 減少。
陷阱：(D) 誤以為黑暗使所有碳反應中間產物都減少。
X6-21 (D) 考點：減數分裂 DNA 含量曲線（B3）。

X6-24 (C) 考點：轉錄、轉譯與突變（B6）。

X6-28 (A) 考點：星等、距離與光度（E1）。

X6-29 (A) 考點：正午太陽仰角（E2）。
正午太陽仰角 h = 90^{\circ} - |\phi - \delta|，|22.0^{\circ} - 23.4^{\circ}| = 1.4^{\circ}，h = 88.6^{\circ}。太陽直射點（北緯 23.4°）在該地以北，故太陽位於北方天空。

X6-40 (A) 考點：酵母菌的醣類利用、長條圖判讀（B2、X2）。

X6-53 參考答案：（a）E = 0.0287\times931.5 \approx 26.7\ \mathrm{MeV}（1 分）
（b）1.0 g 氫含 6.02\times10^{23} 個氫原子，可完成 \dfrac{6.02\times10^{23}}{4} = 1.505\times10^{23} 次淨反應（1 分）；E = 1.505\times10^{23}\times26.7\times1.60\times10^{-13} \approx 6.43\times10^{11}\ \mathrm{J}（1 分）。
