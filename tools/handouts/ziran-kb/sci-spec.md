# 《學測自然知識庫》撰寫規格（每位撰稿人必讀）

## 這套書是什麼

一套印成 PDF 的學測自然考科全科參考書，由「學測英文中心」製作。站主的要求是「頂級備考系統」：讀者是目標頂標、滿級分的高中生與資優班、科學班學生；課本與學校講義上的基礎他們都看過，這套書要給的是**市售最完整參考書的完整度**，加上**大學普通科學入門教材的深度**，以及大量高鑑別度的原創題目。

全套五冊、47 個單元，分配見 `/tmp/claude-0/zhw/sci/sci-units.md`（先讀完整份，特別是自己的單元列與「分工界線」）。課綱學習內容原文摘錄在 `/tmp/claude-0/zhw/sci/req.txt`。

## 查證（最重要）

你有網路搜尋工具（先用 ToolSearch 載入 `select:WebSearch`；若有 WebFetch 也可以用）。學生會照著背，寫錯一個常數、一個年代、一個名詞，就會被學起來。

1. **名詞**：依臺灣高中教科書通行譯名與國家教育研究院「樂詞網」學術名詞。例：粒線體、高基氏體、溶體、核糖體、內質網；莫耳、體積莫耳濃度；克卜勒、惠更斯、馬克士威、都卜勒、拉塞福、查兌克、門得列夫、阿瑞尼斯、孟德爾、摩根、華生與克里克；中央氣象署（2023 年 9 月由中央氣象局改制，敘述現況一律用「中央氣象署」）。不用大陸用語（質量數 OK；「信息、軟件、硅、熵增、激光、衍射、矢量、標量、勢能、熱力學溫度」改為「資訊、軟體、矽、熵增加、雷射、繞射、向量、純量、位能、絕對溫度（克氏溫標）」）。
2. **常數與數據**：依 CODATA、NIST、IUPAC、國際天文聯合會（IAU）公布值；臺灣在地資料（地震、颱風、能源結構、核電廠狀態、氣候統計）查中央氣象署、經濟部能源署、核能安全委員會等官方網站的**最新**資料，並寫明資料年份。查不到可靠來源的數字不寫。
3. **科學史**：人物、年代、實驗內容逐條查證；各說不一者採臺灣高中課本通行之說，必要時註「一說」。不寫流傳但不實的軼事（例如伽利略在比薩斜塔丟球的故事要註明「史料存疑」）。
4. **觀念正確**：遇到常見的課本簡化說法（例如「電子繞核運轉像行星」「光合作用的氧來自二氧化碳」），寫明正確觀念與簡化的範圍。
5. **記下來源**：把用到的主要網頁記在 `/tmp/claude-0/zhw/sci/work/單元代號.sources.json`，格式 `[{"item": "條目", "url": "網址", "note": "查了什麼"}]`，至少 20 筆。
6. **絕對不收**：歷屆試題原題（含改幾個數字的近似題）、官方參考答案與評分原則、出版社教科書與參考書的題目與圖。可以說「此為學測常見考點」，但題目一律自己出。

## 深度：每個知識點寫三層

1. **基礎**：定義、定律、公式、必背整理表（精簡帶過）。
2. **進階**（主體）：易混辨析、迷思概念、條件與適用範圍、圖表判讀、跨單元與跨科連結、題型與解題步驟、學測常見陷阱類型。
3. **深究**：背後的原理與推導（例如由萬有引力推導克卜勒第三定律、由惠更斯原理推導折射定律、由能階差推算譜線波長、由哈溫平衡推算基因頻率）、科學史上的爭論與實驗的關鍵設計、與大學課程的銜接。用 `<div class="tip">` 開頭寫「深究　標題」，或用獨立小節。

超出必修的內容標「（進階）」，不刪。

## 測驗

- 題數照分配表；基礎三成、進階五成、挑戰兩成；多選題四成以上；至少 2 組題組（含圖表、實驗或閱讀情境，題組題號照流水號，題組前用 `<p>` 寫情境，情境可附圖）；至少 3 題非選擇題（簡答、計算、作圖說明，仿學測混合題）。
- 全部原創；測驗題不可與本單元例題使用相同的情境、數據或答案。題目要有鑑別力：誘答選項是「觀念不完整的人會選的」，不要一眼可刪；計算題的數字要算過，答案唯一。
- 四選一答案平均分布（五選一的單選亦同）；多選題每個選項都能明確判斷，正確選項分散在各個字母，不可集中在 (A) 或固定組合。
- 解答逐一說明每個選項，點出誘答陷阱；計算題寫出完整算式；挑戰題附解題步驟。
- **每一題自己算一遍**再交稿。答案錯一題，整本書的可信度就沒了。

## 文風：參考書語體

照 `/tmp/claude-0/zhw/style.md` 的原則（該檔例子是國文，原則一樣適用）：條目化、客觀、精煉、有術語。不對讀者喊話（不用「你」「我們」「同學」，不用勸導的祈使句），不寫導覽式開場，不寫格言與對句，不用「不是……而是……」，不用比喻說理（科學類比可用，但要寫明類比的限制），不刻意湊三，不口語，不寫「本站」。固定用語：定義、定律、公式、條件、適用、注意、辨析、補充、示例、例題、解題步驟、陷阱、深究。

## 格式：只寫 HTML 片段

不寫 `<html>`、`<head>`、`<style>`、行內 style、emoji、Markdown。只用下列標籤與 class：

- 單元外框 `<section class="unit" id="P3">…</section>`；標題 `<h2>P3　牛頓運動定律與常見的力</h2>`（一個單元只有一個 h2）、`<h3>`、`<h4>`。
- `<p>`、`<ul>`、`<ol>`、`<li>`、`<br>`、`<sub>`、`<sup>`。
- `<strong>`：黃色螢光筆，只標關鍵詞與結論。`<em>`：紅色波浪線，標易錯處。學名、基因名等需斜體者用 `<span class="sci">Homo sapiens</span>`（不要用 em）。
- 框：`<div class="key">`（重點整理）、`<div class="tip">`（延伸補充、深究）、`<div class="warn">`（易錯提醒）。
- 誤正對照：`<p class="bad"><span class="mark">誤</span>……</p>`、`<p class="good"><span class="mark">正</span>……</p>`。
- 例子或引文：`<p class="eg"><span class="en">主句</span><span class="zh">說明</span></p>`。
- 表格：`<table class="t"><thead><tr><th>…</th></tr></thead><tbody><tr><td>…</td></tr></tbody></table>`，不超過 6 欄。
- **公式**（LaTeX，由 KaTeX 排版，支援 mhchem 的 `\ce{}`）：
  - 行內：`<span class="m">F = ma</span>`；獨立一行：`<div class="mb">v^2 = v_0^2 + 2a\Delta x</div>`。
  - LaTeX 裡的 `<`、`>`、`&` 要寫成 `&lt;`、`&gt;`、`&amp;`（例如 `<span class="m">a &lt; b</span>`；對齊環境用 `\begin{aligned} … &amp;= … \end{aligned}`）。
  - 物理量用斜體（LaTeX 預設），單位用 `\mathrm{}`，數值與單位之間用 `\ `：`<span class="m">9.8\ \mathrm{m/s^2}</span>`。科學記號 `3.00\times10^{8}`。
  - 化學式與反應式一律用 `\ce{}`：`<span class="m">\ce{H2SO4}</span>`、`<div class="mb">\ce{CaCO3(s) -> CaO(s) + CO2(g)}</div>`、可逆 `<=>`、離子 `\ce{Fe^3+}`、`\ce{SO4^2-}`。
  - 簡單的單一符號或文字下標可直接用 `<sub>`（如 v<sub>0</sub>），但含運算的一律用公式。
  - 不支援的指令會讓檢查失敗；常用：`\frac \sqrt \vec \Delta \propto \approx \times \cdot \le \ge \ne \pm \circ \text{} \mathrm{} \left( \right) \begin{aligned}`。
- **圖**（自己畫的 SVG 示意圖）：

  ```html
  <figure class="fig"><svg viewBox="0 0 420 220" width="420">
    <defs><marker id="P3-ar" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto"><path d="M0,0 L10,5 L0,10 z" fill="#c2410c"/></marker></defs>
    <line x1="20" y1="180" x2="400" y2="180" stroke="#1f2a44" stroke-width="2"/>
    <text x="210" y="200" font-size="15" text-anchor="middle">水平面</text>
  </svg><figcaption>圖 P3-1　說明文字</figcaption></figure>
  ```

  - 只能用 svg、g、line、polyline、polygon、path、circle、ellipse、rect、text、tspan、defs、marker、title；不可用 style、href、image、foreignObject、script。用屬性設定顏色與線寬。
  - `<svg>` 一定要有 viewBox；width 不超過 640（版心約 680 px）。兩張並排用 `<figure class="fig half">`，各 width 不超過 320。
  - **所有 id 以單元代號開頭**（如 `P3-ar`、`P3-g1`），全書同一份 HTML，id 重複會互相干擾。
  - 配色：線與文字 `#1f2a44`；主色 `#2f6fb5`（淺 `#cfe3f8`）；強調紅 `#c2410c`；綠 `#2e8b57`（淺 `#c9ebd7`）；橙 `#d9772b`（淺 `#fbdcbd`）；紫 `#7a5cc2`；灰 `#94a3b8`（淺 `#e2e8f0`）。字級 font-size 13–16；SVG 內文字不能用 LaTeX，下標可用 `<tspan baseline-shift="sub" font-size="11">0</tspan>`。
  - 圖要正確：座標軸要標物理量與單位，箭頭方向、比例關係、圖中數值與正文一致。示意圖未依比例者在圖說註明「示意圖，未依比例」。
  - 每單元至少 8 張圖（物理、地科建議 12 張以上）：受力圖、運動圖、波形、光路、電路與磁場、能階圖、溶解度曲線、能量圖、滴定曲線、分子結構、細胞與胞器、分裂各期、譜系、親緣樹、地球內部、板塊邊界剖面、天球、天氣圖示意、等值線、探究實驗裝置等。題目的圖也算。
  - 圖號：`圖 P3-1`、`圖 P3-2`……依序；題目裡的圖用 `圖 P3-題1`……或直接在題幹說「如右圖」。
- **測驗題**：

  ```html
  <h4 class="exset">基礎題（10 題）</h4>
  <div class="ex" id="P3-01"><span class="exid">P3-01</span>題幹……
  <div class="opts"><span>(A) ……</span><span>(B) ……</span><span>(C) ……</span><span>(D) ……</span><span>(E) ……</span></div></div>
  ```

  多選題在題幹最後註明「（多選）」。題組：先寫 `<p><strong>第 21–23 題為題組</strong></p>` 與情境段落（可附圖），再依序列題。非選擇題在題目後加 `<div class="lines" data-n="2"></div>`（行數 1–2）。題號連續，從 01 起。
- 解答檔：

  ```html
  <section class="ans-unit" id="ans-P3"><h3>P3　牛頓運動定律與常見的力</h3>
    <div class="ans"><span class="exid">P3-01</span> (B) <span class="why">說明……</span></div>
  </section>
  ```

  選擇題答案一律寫成題號後接 `(B)`，多選寫 `(A)(C)(E)`；非選擇題寫「參考答案：……」。

## 版面：參考書風的手寫筆記（站主要求「排版如參考書，非常精美，手寫筆記及重點」）

全書字體是手寫風的芫荽體，排出來像畫過重點、寫過筆記的參考書。除了螢光筆 `<strong>`、紅色波浪線 `<em>` 與三種框，**每一頁都要善用下列手寫筆記元素**（樣張見 `/tmp/claude-0/zhw/sci/tmp/demo/P3.body.html`，排出來的樣子見同資料夾 `pg-1.png`，先用 Read 看一次）：

| 元素 | 寫法 | 用途與份量 |
|---|---|---|
| 紅筆旁註 | `<span class="hand">質量＝慣性的量度</span>`（藍筆加 `blue`；箭頭朝上加 `up`；不要箭頭加 `no`） | 句末補一句老師式的提點，10 字左右；每頁 1–3 處 |
| 手繪圈選 | `<span class="circle">同方向</span>` | 圈出關鍵的二三字（方向、條件、例外）；每頁 1–3 處 |
| 紅筆框選 | `<span class="box">1 N = 1 kg·m/s²</span>` | 框出要背的短結論、單位換算 |
| 藍筆底線 | `<span class="ul">……</span>` | 次要重點 |
| 旁註筆記 | `<div class="note"><p>……</p><p>……</p></div>`，放在要搭配的段落**之前** | 靠右浮動的藍筆筆記欄（約版心四成寬），寫 2–4 行補充、聯想、背法；每 1–2 頁一則 |
| 公式卡 | `<div class="formula" data-t="牛頓第二定律"><div class="mb">…</div><p>符號說明…</p></div>` | 每個重要公式都用公式卡，`data-t` 寫公式名稱；卡內附符號與單位說明 |
| 口訣 | `<div class="mnem"><p>……</p></div>` | 粉紅便利貼；有口訣、記憶法時用 |
| 學測考點 | `<div class="exam"><p>……</p></div>` | 印章框，寫該知識點在學測的考法與陷阱；每節至少一則 |
| 例題 | `<div class="example"><p>題目……</p><div class="sol"><ol class="steps"><li>步驟一</li><li>步驟二</li></ol><p>陷阱：……</p></div></div>` | 「例題精解」一律用此格式；步驟用 `ol.steps`（自動畫圈號） |
| 解題步驟 | `<ol class="steps"><li>…</li></ol>` | 任何需要步驟的地方 |

- 圖的 SVG 內可以加紅筆手寫註記：`<text … fill="#d64545" transform="rotate(-4 x y)">合力 = F − f</text>`，配合紅色箭頭指向圖中重點，像老師在圖上補註。
- 元素要用在真正的重點上，份量照上表；不要整頁都是框。正文仍以條目、表格、公式為主體。
- 原來的「例題精解」改用 `div.example` 格式（取代 key 或 eg）。
