V2　字首、字根、字尾

學測要認得的單字有好幾千個，但其中很多字是用同一批「零件」組成的。transport、export、portable、support 是四個字，核心卻只有一個：port（搬運）。這個單元整理 40 個字首、60 個字根、30 個字尾，例字以參考詞彙表 6 級以內的字為主。學完之後，你要會三件事：

  • 猜：詞彙題和閱讀測驗遇到生字，拆開來推出大概的意思。
  • 背：同一個字根的字放在一起背，一次記一串。
  • 變：文意選填看字尾分詞性；混合題填空把字改成正確的詞性。

一、拆字的方法

長字 ＝ 字首 ＋ 字根 ＋ 字尾

  • 字首管方向：正或反、進或出、前或後、多或少。
  • 字根管核心意思：走、拿、看、說、做。
  • 字尾管詞性：名詞、動詞、形容詞、副詞。

拆字四步驟

  1. 從後面切下字尾，先知道詞性。
  2. 從前面切下字首，知道方向。
  3. 中間剩下的是字根，給它一個核心意思。
  4. 把幾段的意思接起來，代回句子，修成通順的中文。
生字拆法字面意思 → 字義
invisiblein（不）＋ vis（看）＋ ible（可…的）看不見的
reconstructionre（再）＋ con（一起）＋ struct（建造）＋ ion（名詞）再蓋起來 → 重建
overpopulationover（過度）＋ popul（人民）＋ ation（名詞）人太多 → 人口過剩
indescribablein（不）＋ de（往下）＋ scrib（寫）＋ able（可…的）寫不下來的 → 難以形容的

拆字是「猜」，不是「查」。考場上用它縮小範圍，但要記得三個限制：

  • 字面意思要靠句子修正。priceless ＝ price ＋ less，字面是「沒有價格」，實際意思是「無價的、極珍貴的」，不是「不值錢的」。
  • 同一個字首可能有兩個意思。in- 可以是「不」（incorrect），也可以是「進入」（include）。
  • 不是每個字都能拆。uncle、under、ready、reach、image 的開頭只是剛好長得像字首。字很短，或拆完剩下的部分沒有意義，就不要硬拆。

字首會變形。為了好發音，字首最後一個子音常變成和字根的第一個字母一樣，所以很多字的開頭有兩個相同的子音。看到 acc-、app-、att-、coll-、corr-、ill-、imm-、irr-、opp-、succ-、supp- 這種開頭，把第一個子音還原，就找得到字首。這些字的雙子音也就不會拼錯。

二、字首 40 個

字首依功能分成六組。背的時候一組一起背；意思相對的（進和出、上和下、前和後）放在一起記。

1　否定與相反（8 個）

字首意思例字
un-不；做相反的動作unlock 開鎖、uncover 揭露、unemployment 失業
in-（im-、il-、ir-）不、無independent 獨立的、impossible 不可能的、illegal 違法的
dis-不；相反；除去disagree 不同意、disappear 消失、disadvantage 缺點；劣勢

mis-錯誤、不當misunderstand 誤解、mislead 誤導、misfortune 不幸
anti-（ant-）反對、對抗antibiotic 抗生素、antonym 反義字、antisocial 反社會的；不愛交際的
counter-／contra-相反、對抗counterpart 對應的人或物、contrary 相反的、contradict 反駁；與…矛盾

  • un- 接形容詞是「不…」（unable、unusual、unexpected）；接動詞是「把動作反過來」（unlock、unfold、uncover）。
  • de- 的字常有方向相反的搭檔，成對背：decrease／increase、descend／ascend、detach／attach。

三、字根 60 個

字根是一個字的核心，通常不能單獨成字。同一個字根常有兩三種拼法（mit／miss、scrib／script）：動詞多用前一種，加上 -ion、-ive 的名詞和形容詞多用後一種（permit → permission、describe → description）。下面的表格最右欄示範怎麼拆，括號裡是每一段的意思。

5　會騙人的字尾

下面六個字尾不能只看長相，要多做一步檢查。文意選填分選項時，這些字最容易分錯類。

字尾通常是什麼，哪些字例外怎麼分
-ly通常是副詞。這些是形容詞：friendly、lovely、costly、lonely、lively、likely、deadly、elderly拿掉 -ly，剩下形容詞 → 副詞；剩下名詞（friend、cost）→ 形容詞。lonely 以後的五個不合這條，直接背
-al通常是形容詞。這些是名詞：arrival、proposal、approval、survival、refusal、removal、denial拿掉 -al，剩下名詞（nation）→ 形容詞；剩下動詞（arrive）→ 名詞
-ive通常是形容詞。這些也當名詞：representative 代表、alternative 替代方案、objective 目標、initiative 主動權；倡議、relative 親戚前面有冠詞、後面沒有名詞 → 名詞
-ant／-ent通常是形容詞。這些是指人的名詞：assistant、resident、opponent、immigrant、participant抽象名詞要換成 -ance／-ence：assistant（助理）和 assistance（協助）不同
-ate通常是動詞。這些是形容詞：accurate、appropriate、fortunate、delicate、private；separate 兩種詞性都有看位置：名詞前面、be 動詞後面 → 形容詞
-y通常是形容詞。這些是名詞：discovery、delivery、recovery、injury、difficulty、honesty拿掉 -y，剩下名詞（wealth）→ 形容詞；剩下動詞或形容詞（discover、honest）→ 名詞

五、字尾與詞性：文意選填和混合題怎麼用

文意選填的 10 個選項混著名詞、動詞、形容詞、副詞；混合題的填空要你從文章裡找一個字，必要時改成別的詞性再填。這兩種題目的完整流程在 C1 和 M1，這一節只處理和字尾有關的事：用字尾認詞性、選對字尾、把字拼對。

空格要什麼詞性，看它前後的字：冠詞、所有格、形容詞的後面（後面沒有名詞）→ 名詞；名詞的前面、be 動詞和 become、seem、remain 的後面 → 形容詞；to 和助動詞的後面 → 原形動詞；修飾動詞、形容詞或整個句子 → 副詞。完整的位置表在 M1。

1　詞性看最後一個字尾

字尾可以一層一層疊上去，每加一層，詞性就換一次。所以判斷詞性只看最後一個字尾，前面有幾層都不用管。

單字一層一層加上去詞性
effectivenesseffect（名）→ effective（形）→ effectiveness名詞
modernizationmodern（形）→ modernize（動）→ modernization名詞
internationallynation（名）→ national（形）→ international（形）→ internationally副詞
simplifiedsimple（形）→ simplify（動）→ simplified動詞過去式；過去分詞

從表裡也看得出來：字首改意思，字尾改詞性。national 加上 inter- 之後還是形容詞。常見的例外是 en-（變成動詞）和 a-（變成表示狀態的形容詞或副詞）。

2　文意選填：用字尾分選項

拿到 10 個選項，先在每個選項旁邊標上 n.、v.、adj.、adv.。字尾是最快的線索。假設選項是：

(A) awareness　(B) significantly　(C) reduction　(D) affordable　(E) threaten
(F) diversity　(G) effective　(H) eventually　(I) identified　(J) motivate

  • 名詞（-ness、-tion、-ity）：(A) awareness、(C) reduction、(F) diversity
  • 形容詞（-able、-ive）：(D) affordable、(G) effective
  • 副詞（-ly，拿掉後剩下形容詞）：(B) significantly、(H) eventually
  • 動詞（-en、-ate、-ify）：(E) threaten、(J) motivate 是原形；(I) identified 是過去式或過去分詞

The campaign was launched to raise public ______ of plastic pollution in the ocean.空格在形容詞 public 後面、介系詞 of 前面，要名詞，只剩 (A)(C)(F) 三個。raise awareness of（提高對…的意識）是固定搭配，選 (A)。十選一先變成三選一，這就是分類的用處。

3　混合題：選對字尾

混合題的字形變化分四步：定詞性（看空格的位置）→ 找字（回文章找意思對得上的字，它的詞性常和空格不同）→ 換字尾 → 檢查（名詞看單複數；動詞看時態、主詞單複數、主動被動；最後看拼字）。第三步用下面的方向表。

轉換方向常用字尾例子
動詞 → 名詞-tion／-sion、-ment、-al、-ure、-ance／-encepollute → pollution；achieve → achievement；arrive → arrival；fail → failure；perform → performance
形容詞 → 名詞-ness、-ity、-ce／-cy、-thaware → awareness；diverse → diversity；important → importance；accurate → accuracy；warm → warmth
名詞 → 形容詞-al、-ful、-less、-ous、-y、-icculture → cultural；harm → harmful、harmless；danger → dangerous；wealth → wealthy；science → scientific
動詞 → 形容詞-able、-ive、-ing／-edrely → reliable；create → creative；confuse → confusing、confused
形容詞、名詞 → 動詞-en、-ize、-ify；字首 en-wide → widen；modern → modernize；simple → simplify；large → enlarge
形容詞 → 副詞-lygradual → gradually；easy → easily

Passage: The villagers decided to preserve the old stone bridge because it is historically significant.
Question: The villagers' ______ to keep the bridge shows its historical ______ to the community.第一格在所有格 villagers' 後面，要名詞：decided → decision。第二格在形容詞 historical 後面、介系詞 to 前面，也要名詞：significant → significance。照抄文章裡的 decided 和 significant，兩格都拿不到分。

一個動詞常有兩個名詞：一個是「事」，一個是「人」。compete → competition／competitor、apply → application／applicant、assist → assistance／assistant、employ → employment／employer／employee。先看句意：空格指的是人，才用表示人的字尾；指人的名詞可數，單數前面要有 a／an，複數要加 -s。常考的詞族整理在 M1 的「常考字形變化 40 組」。

4　換字尾時的拼字規則

規則例子注意
結尾是不發音的 e，接母音開頭的字尾時去掉 ecreate → creative、creation；value → valuable接子音開頭的字尾保留 e：achievement、careful。例外：argument、truly
「子音＋y」結尾，把 y 改成 irely → reliable；vary → various、variety；happy → happiness、happily接 -ing 時不改：relying
重音在最後一個音節，結尾是「一個母音字母＋一個子音字母」，接母音開頭的字尾時重複子音occur → occurred、occurrence；begin → beginnerprefer → preferred，但 preference 的重音移到前面，不重複
-ble 變成 -bility（名詞）、-bly（副詞）able → ability；responsible → responsibility、responsiblypossible → possibility、possibly
-ant／-ent 變成 -ance／-ence／-encyimportant → importance；confident → confidence；efficient → efficiency形容詞用 t，名詞用 ce 或 cy
-ate 變成 -ation（動詞變名詞）、-acy（形容詞變名詞）educate → education；accurate → accuracy；private → privacy先去掉 e 或 te 再加字尾
-ify 變成 -ification；-ize 變成 -izationidentify → identification；organize → organization例外：satisfy → satisfaction
-ic 變成 -icallybasic → basically；scientific → scientifically例外：public → publicly

5　動詞變名詞，字根跟著變

第三節說過，同一個字根常有兩種拼法。動詞改成名詞時，字根要換成第二種拼法；這是混合題最容易拼錯的地方。

動詞結尾名詞結尾例子
-mit-missionpermit → permission；admit → admission
-ceed-cesssucceed → success；exceed → excess
-ceive-ceptionreceive → reception；perceive → perception
-scribe-scriptiondescribe → description；prescribe → prescription
-duce-ductionproduce → production；reduce → reduction；introduce → introduction
-clude-clusionconclude → conclusion；exclude → exclusion
-tend-tension／-tentionextend → extension；intend → intention；attend → attention
-cide-cisiondecide → decision
-solve-solutionsolve → solution；resolve → resolution
-sume-sumptionconsume → consumption；assume → assumption
-pose-positioncompose → composition；oppose → opposition（但 expose → exposure、propose → proposal）

四個拼字會變的字，最常寫錯：explain → explanation（少一個 i）、pronounce → pronunciation（少一個 o）、repeat → repetition（ea 變 e）、maintain → maintenance（ai 變 e）。
