G3　助動詞與假設語氣

G3-01 (B) were 後半句 but I am the shortest 說明「再高一點」和現在的事實相反，if 子句用過去式，be 動詞用 were；主要子句的 would try 也是線索。(A) 現在式表示可能發生的條件，和 would try 不配；(C) 現在完成不用在假設語氣的 if 子句；(D) would 不放在 if 子句裡。
G3-02 (A) must have left 地板積水是證據，據此推測昨晚（last night's thunderstorm）發生的事，用 must have p.p.「一定是……了」。(B) must leave 是「必須」，不能推測過去；(C) should leave 是「應該」，和過去時間不合；(D) can't have left 是「不可能沒關窗」，和積水的證據矛盾。
G3-03 (D) had checked 主要子句是 would not have been trapped，時間是 last Saturday，與過去事實相反，if 子句用 had p.p.。(A) 現在式、(B) 過去式都和 would have p.p. 配不起來；(C) would 不放在 if 子句裡。
G3-04 (C) take demanded that 後面的子句用 (should)＋原形動詞，不隨主詞 every kitchen worker 或過去式的 demanded 變化。(A) 加了 -s、(B) 過去式，都是跟著主詞或時態變了；(D) would take 不是這個句型。
G3-05 (B) had visited when she was still alive 是過去的事，而且已經無法改變，wish 後面用 had p.p.。(A) 現在式、(C) 現在完成都沒有退一格；(D) wish … would 是希望以後有所改變，和過去的時間不合。
G3-06 (D) can't have broken 第二句說他整個下午都在練球，還有隊友可以作證，所以花瓶「不可能」是他打破的，用 can't have p.p.。(A)「一定是他打破的」、(C)「可能是他打破的」都和不在場的證明矛盾；(B) should have broken 是「當時該打破卻沒打破」，意思不通。
G3-07 (C) would be studying if 子句 had applied … last year 是過去的條件，主要子句有 now，是現在的結果，屬於混合假設，用 would＋原形（這裡是進行式 would be V-ing）。(B) would have studied 說的是過去的結果，和 now 不合；(A) will 不表示與事實相反；(D) had been studying 不是主要子句的假設形式。
G3-08 (B) took it is high time＋主詞＋過去式，表示「早就該做了」。(A) 現在式、(C) 現在完成、(D) 未來式都不合這個句型。
G3-09 (A) Should 逗號前後是兩個子句，卻沒有連接詞，可見句首是省略 if 的倒裝；主詞 you 後面是原形 have，只有 Should 可以接：Should you have … = If you should have …（萬一你……）。(B) Had 後面要接過去分詞；(C) Were 後面不能接原形動詞 have；(D) Would 沒有這種代替 if 的用法。
G3-10 (D) had lived Kevin 從沒出過國，「在巴黎住了很多年」不是事實，as if 後面要退一格；for years 表示已經持續一段時間，原本是現在完成，退一格成 had p.p.。(A) lives 不能和 for years 連用，也把它說成了事實；(B) will live、(C) would live 都不表示「已經住了很多年」。
