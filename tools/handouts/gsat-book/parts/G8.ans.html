G8　副詞子句、連接詞與轉折語

G8-01 (B) Despite 空格後面 the heavy traffic on the highway 是名詞片語，沒有動詞，要用介系詞；意思是「儘管」，和後面的 still 呼應。(A) Although、(C) Because 是連接詞，後面要接子句；(D) However 是副詞，後面要接完整的句子，不能只接名詞。
G8-02 (C) because 空格後面 the weather forecast said … 有主詞和動詞，是子句，用連接詞 because。(A) because of、(B) due to 是介系詞，只能接名詞；(D) therefore 是副詞，不能連接兩個子句，而且因果方向也反了。
G8-03 (C) unless 「除非出示學生證，否則不能進考場」，unless＝if … not。(A) if、(B) once 會變成「出示學生證就不能進考場」，(D) because 變成「因為出示學生證所以不能進」，邏輯都不通。
G8-04 (A) so 空格後面是形容詞 powerful，再接 that 子句表示結果，用 so … that。(B) such 後面要有名詞（such a powerful film）；(C) very 不和 that 子句搭配；(D) too 的句型是 too … to V。
G8-05 (D) Once 「一旦新圖書館啟用，學生就不必再…」，用 Once；子句用現在式 opens 代替未來式。(A) Until（直到）、(C) Unless（除非）代進去邏輯都不通；(B) During 是介系詞，不能接子句。
G8-06 (C) However 前一句說優點（安靜、不排廢氣），這一句說缺點（充電要好幾個小時），是轉折。空格在句號後面、逗號前面，要用轉折語。(A) Although 是連接詞，後面不能加逗號；(B) Therefore 表因果、(D) Moreover 表補充，邏輯不合。
G8-07 (A) so that 空格後面是子句（the students … could see），而且寫大字的目的是讓後排看得清楚，用 so that；子句裡的 could 也是線索。(B) in order to 後面接原形動詞；(C) because of、(D) despite 是介系詞，不能接子句。
G8-08 (D) planting not A but B 的兩邊要平行：not by building … but by planting …；介系詞 by 後面也要接 V-ing。(A) 原形、(B) 不定詞、(C) 過去分詞都不能放在介系詞 by 後面。
G8-09 (B) it is 句首已經有連接詞 Although，主要子句不能再加連接詞。(A) but、(C) so 都是多出來的連接詞，(C) 的邏輯也不對；(D) however 是副詞，放在這裡同樣重複了 Although 的意思，標點也不對。
G8-10 (A) otherwise 「要記得存檔，否則可能失去幾小時的成果」，分號後面、逗號前面用轉折語 otherwise。(B) therefore（因此）、(C) moreover（此外）邏輯不通；(D) unless 是連接詞，後面不能加逗號，句中也已經有 if 子句。
